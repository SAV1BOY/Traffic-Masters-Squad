# Metric Definitions

## Purpose
Standard definitions for all metrics used across the traffic squad.

## Cost Metrics
| Metric | Definition | Formula |
|--------|-----------|---------|
| CPC | Cost per click | Spend / Clicks |
| CPM | Cost per 1,000 impressions | (Spend / Impressions) x 1,000 |
| CPA | Cost per acquisition | Spend / Conversions |
| CPL | Cost per lead | Spend / Leads |
| CAC | Customer acquisition cost | Total acquisition spend / New customers |
| nCAC | New customer acquisition cost | Prospecting spend / New customers |

## Performance Metrics
| Metric | Definition | Formula |
|--------|-----------|---------|
| CTR | Click-through rate | (Clicks / Impressions) x 100 |
| CVR | Conversion rate | (Conversions / Clicks) x 100 |
| ROAS | Return on ad spend | Revenue / Ad Spend |
| ROI | Return on investment | (Revenue - Total Cost) / Total Cost |
| AOV | Average order value | Revenue / Orders |
| LTV | Lifetime value | Avg revenue per customer over lifetime |

## Engagement Metrics
| Metric | Definition | Formula |
|--------|-----------|---------|
| Hook Rate | 3-second video views / impressions | (3s Views / Impressions) x 100 |
| VTR | View-through rate | (Completed Views / Impressions) x 100 |
| Frequency | Avg times each person saw the ad | Impressions / Reach |
| Engagement Rate | Interactions / impressions | (Engagements / Impressions) x 100 |

## Efficiency Metrics
| Metric | Definition | Formula |
|--------|-----------|---------|
| LTV:CAC | Lifetime value to acquisition cost | LTV / CAC |
| Payback Period | Months to recover CAC | CAC / Monthly revenue per customer |
| Contribution Margin | Revenue minus variable costs | Revenue - COGS - Ad Spend |
| MER | Marketing efficiency ratio | Total Revenue / Total Marketing Spend |
