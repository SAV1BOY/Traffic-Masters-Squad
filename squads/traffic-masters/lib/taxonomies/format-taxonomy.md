# Format Taxonomy

## Purpose
Classification system for ad creative formats across platforms.

## Format Categories

### 1. Static Image
- **1.1 Single Image** — One image with text overlay
- **1.2 Infographic** — Data visualization or process
- **1.3 Quote Card** — Testimonial or statement
- **1.4 Product Shot** — Product-focused image
- **1.5 Meme/Native** — Platform-native style image

### 2. Video
- **2.1 Talking Head** — Person speaking to camera
- **2.2 Screen Capture** — Software demo or walkthrough
- **2.3 B-Roll + Voiceover** — Footage with narration
- **2.4 Animation/Motion** — Animated explainer
- **2.5 UGC Style** — Phone-shot, authentic feel
- **2.6 Professional Production** — High production value
- **2.7 Slideshow** — Image sequence with music/text

### 3. Carousel
- **3.1 Story Carousel** — Sequential narrative across cards
- **3.2 Feature Carousel** — One benefit per card
- **3.3 Testimonial Carousel** — Different testimonials per card
- **3.4 Product Carousel** — Different products per card
- **3.5 Before/After Carousel** — Transformation sequence

### 4. Interactive
- **4.1 Poll/Quiz** — Interactive engagement format
- **4.2 Collection Ad** — Immersive product catalog
- **4.3 Lead Form** — In-platform lead capture
- **4.4 Instant Experience** — Full-screen mobile format

### 5. Document (LinkedIn)
- **5.1 PDF Carousel** — Swipeable document pages
- **5.2 Slide Deck** — Presentation format

## Platform-Format Matrix

| Format | Meta | Google | TikTok | YouTube | LinkedIn |
|--------|------|--------|--------|---------|----------|
| Static | Yes | Display | No | No | Yes |
| Video | Yes | YouTube/PMax | Yes | Yes | Yes |
| Carousel | Yes | No | No | No | Yes |
| Document | No | No | No | No | Yes |
