# Creative Card Component

## Purpose
Standardized format for documenting individual ad creatives.

## Card Fields

### Identity
- **Creative ID:** [CRE-XXX]
- **Name:** [Descriptive name]
- **Format:** Static / Video / Carousel / Collection / Document
- **Platform:** Meta / Google / TikTok / YouTube / LinkedIn
- **Asset Link:** [URL to creative file]

### Creative Elements
- **Hook:** First 3 seconds (video) or headline (static)
- **Angle:** Pain / Desire / Proof / Mechanism / Objection
- **Body:** Core message structure
- **CTA:** Call to action text
- **Visual Style:** UGC / Studio / Animated / Screen capture
- **Copy Length:** Short / Medium / Long

### Targeting Context
- **Funnel Stage:** TOFU / MOFU / BOFU
- **Audience:** [Audience description]
- **Offer:** [Associated offer]

### Performance
- **Launch Date:** [Date]
- **Impressions:** [Count]
- **Hook Rate:** [% — video only]
- **CTR:** [%]
- **CPA:** [$]
- **ROAS:** [X]
- **Frequency:** [Avg]

### Lifecycle
- **Status:** Testing / Active / Scaling / Fatigued / Retired
- **Fatigue Date:** [Date when performance declined]
- **Iterations:** [List of creative IDs derived from this]
- **Learnings:** What this creative taught us
