# Test-Then-Scale Pattern

## Purpose
Systematic approach to validating before committing significant budget.

## The Pattern

### Phase 1: Micro-Test ($50-100/day per variant)
- **Duration:** 3-7 days
- **Goal:** Find winning creative/audience combinations
- **Structure:** Multiple small ad sets, each testing one variable
- **Decision Metric:** Primary KPI (CPA, ROAS, CTR)
- **Rule:** Kill losers fast (24-48hrs if clearly losing)

### Phase 2: Validation ($200-500/day)
- **Duration:** 7-14 days
- **Goal:** Confirm winners at moderate spend
- **Structure:** Consolidate winners into fewer ad sets
- **Decision Metric:** CPA stability over 7+ days
- **Rule:** Must achieve target CPA for 5+ consecutive days

### Phase 3: Scale ($500+/day, increasing)
- **Duration:** Ongoing
- **Goal:** Maximize volume at acceptable efficiency
- **Structure:** Follow scaling patterns (vertical + horizontal)
- **Decision Metric:** Marginal CPA (cost of next conversion)
- **Rule:** Scale 20-30% every 3-5 days while CPA holds

## Decision Gates

| Gate | Criteria to Pass | Fail Action |
|------|-----------------|-------------|
| Micro > Validation | Top 20% by CPA, 50+ conversions | Kill or iterate |
| Validation > Scale | CPA at target for 5+ days | Continue testing or iterate |
| Scale continuation | CPA within 1.3x target | Hold or reduce budget |

## Key Principles
1. Never scale unvalidated creative or audiences
2. Learning phase losses are expected — budget accordingly
3. Speed of testing > perfection of each test
4. Document every test result (win or lose)
