# Diminishing Returns Pattern

## Purpose
Recognize and manage the point where additional spend yields declining returns.

## The Pattern

### The Curve
- Initial spend: High marginal ROAS (picking low-hanging fruit)
- Mid spend: Stable ROAS (efficient scaling range)
- High spend: Declining marginal ROAS (diminishing returns)
- Over-spend: Negative marginal ROAS (waste)

### Detection Signals
| Signal | Threshold | Interpretation |
|--------|-----------|---------------|
| Marginal CPA rising | +20% vs average CPA | Approaching ceiling |
| Frequency increasing | >2.5 weekly | Audience saturation |
| CTR declining | -15% WoW | Creative/audience fatigue |
| CPM increasing | +25% MoM | Auction competition/saturation |
| Incremental ROAS < 1x | Below breakeven | Over-spending |

### Response Actions
1. **Audience saturation:** Expand to new audiences or platforms
2. **Creative fatigue:** Refresh creative pipeline
3. **Bid ceiling:** Reduce spend or adjust bid strategy
4. **Platform ceiling:** Diversify to additional platforms
5. **Market ceiling:** Expand geographic or demographic scope

## Optimal Spend Zone
- Target the "efficient frontier" — maximum volume before sharp CPA increase
- Calculate by plotting CPA vs daily spend over 30 days
- The inflection point is your optimal daily budget

## Management Rules
1. Track marginal CPA weekly (last $100 spent CPA vs first $100)
2. Set alerts when marginal CPA exceeds 1.3x average CPA
3. Reallocate budget to underspent platforms/audiences first
4. Accept higher CPA only if LTV justifies it
5. Seasonal demand changes shift the curve — reassess quarterly
