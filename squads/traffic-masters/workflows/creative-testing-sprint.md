# Creative Testing Sprint
> **Type**: Workflow
> **Duration**: 2 weeks (10 business days)
> **Agents involved**: ad-midas, media-buyer, creative-analyst

## Trigger
Monthly creative refresh cycle, declining CTR/hook rates, or new offer launch.

## Steps
1. Research Phase (Day 1-2) → Agent: ad-midas → Framework: Swipe Analysis + Competitor Audit → Output: Testing hypotheses document with 3-5 angles to test
2. Brief Creation (Day 2) → Agent: ad-midas → Framework: Hook-Story-Offer → Output: Creative briefs for each variation with clear variable isolation
3. Production (Day 3-5) → Agent: ad-midas → Framework: Platform Specs Matrix → Output: 8-12 creative variations across formats (static, video, carousel)
4. QA Review (Day 5) → Agent: ad-midas → Framework: Creative Checklist → Output: Approved creatives ready for upload
5. Test Setup (Day 6) → Agent: media-buyer → Framework: Mandalia Testing Structure → Output: A/B test campaigns with isolated variables, equal budget split
6. Data Collection (Day 6-9) → Agent: creative-analyst → Framework: Statistical Significance → Output: Daily data snapshots, confidence intervals tracked
7. Analysis (Day 10) → Agent: creative-analyst → Framework: Winner Identification → Output: Performance report with winning elements identified
8. Iteration Plan → Agent: ad-midas → Framework: Iterate-on-Winner → Output: Next sprint brief using winning elements as base

## Quality Gates
- [ ] Each test isolates only ONE variable (hook, visual, CTA, format)
- [ ] Minimum budget per variation: 2x target CPA
- [ ] Statistical significance reached before calling winner (90%+ confidence)
- [ ] At least 3 angles tested per sprint
- [ ] All creatives comply with platform ad policies
- [ ] Results documented in creative library

## Output
Creative performance report identifying winning hooks, angles, formats.
Updated creative library with performance data.
Next sprint brief based on learnings.

## Testing Variables Priority
1. Hook (first 3 seconds of video / headline)
2. Angle (pain point, desire, social proof, education)
3. Format (static vs video vs carousel)
4. CTA (soft vs hard, text variations)

## Notes
- Never test more than one variable per ad set
- Video hook rate benchmark: 25%+ for cold traffic
- Static CTR benchmark: 1.5%+ for cold, 2.5%+ for warm
- Archive losing creatives with notes on why they failed
