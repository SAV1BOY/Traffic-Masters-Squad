# UGC Production Workflow
> **Type**: Workflow
> **Duration**: 10-14 business days
> **Agents involved**: ad-midas, media-buyer, ads-analyst

## Trigger
Need for authentic, creator-driven content for ad campaigns.

## Steps
1. Brief Creation → Agent: ad-midas → Framework: UGC Brief Template → Output: Detailed brief with talking points, tone, dos/donts, example references
2. Creator Selection → Agent: ad-midas → Framework: Creator Database → Output: 3-5 creators selected matching brand persona and audience demographics
3. Creator Outreach → Agent: ad-midas → Framework: Outreach SOP → Output: Agreements signed, deadlines set, payment terms confirmed
4. Script/Outline Delivery → Agent: ad-midas → Framework: Script Framework → Output: Scripts or outlines sent to creators with hook variations
5. Raw Content Delivery → Agent: ad-midas → Framework: Delivery Checklist → Output: Raw footage received, reviewed for quality and brief adherence
6. Post-Production → Agent: ad-midas → Framework: UGC Edit Style → Output: Edited UGC ads with captions, music, CTAs, and platform-specific cuts
7. Approval Review → Agent: ad-midas → Framework: Brand + Policy Check → Output: Final approval on all UGC ads
8. Rights Documentation → Agent: ad-midas → Framework: Usage Rights → Output: Content usage rights documented and filed
9. Testing Launch → Agent: media-buyer → Framework: UGC Testing Protocol → Output: UGC ads launched in testing structure against polished creatives

## Quality Gates
- [ ] Brief clearly communicates brand voice and key messages
- [ ] Creators match target audience demographics
- [ ] Usage rights secured for all platforms and durations needed
- [ ] Raw content meets minimum quality standards (audio, lighting, framing)
- [ ] Captions added to all video content
- [ ] Policy compliance verified (disclosures, claims)
- [ ] Multiple hook variations produced per creator

## Output
Library of UGC ad assets ready for testing.
Creator performance database updated with results.
Usage rights documentation filed.

## UGC Content Types
- Testimonial: Real customer sharing experience
- Unboxing: Product reveal with genuine reactions
- Tutorial: How-to or demonstration
- Day-in-the-life: Product integration into daily routine
- Problem-solution: Before/after narrative

## Notes
- UGC typically outperforms polished ads for cold traffic by 20-40%
- Always get written content usage agreements before production
- Brazilian creators: ensure proper NF for payments
- Rotate creators every 2-3 months to prevent audience fatigue
- Keep a rated creator database for quick re-engagement
