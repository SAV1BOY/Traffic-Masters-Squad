# Monthly Growth Review
> **Type**: Workflow
> **Duration**: 2 business days (prep + meeting)
> **Agents involved**: Analyst, Strategist, Media Buyer, Squad Lead

## Trigger
Last business week of each month, or first week of the new month.

## Steps
1. Data Collection → Agent: Analyst → Framework: Multi-Source Pull → Output: Consolidated data from all platforms, GA4, CRM, and revenue systems
2. Metric Analysis → Agent: Analyst → Framework: MoM + YoY Comparison → Output: Performance tables with month-over-month and year-over-year deltas
3. Cohort Review → Agent: Analyst → Framework: Cohort Analysis → Output: Customer quality metrics (LTV, retention, payback period by acquisition source)
4. Creative Performance → Agent: Media Buyer → Framework: Creative Leaderboard → Output: Top/bottom performing creatives with fatigue indicators
5. Budget Efficiency → Agent: Analyst → Framework: Marginal CPA Analysis → Output: Diminishing returns analysis, optimal spend zones identified
6. Channel Mix Review → Agent: Strategist → Framework: Attribution Model Comparison → Output: Channel contribution analysis (last-click vs data-driven vs incrementality)
7. Insight Synthesis → Agent: Strategist → Framework: GECO Summary → Output: 3-5 key insights with recommended actions
8. Presentation Prep → Agent: Squad Lead → Framework: Executive Summary → Output: Slide deck or report for stakeholders
9. Decision Meeting → Agent: All → Framework: Growth Council → Output: Approved plan for next month with budget allocation
10. Plan Documentation → Agent: Strategist → Framework: Monthly Plan Template → Output: Next month's plan with OKRs, budget, and test calendar

## Quality Gates
- [ ] All data sources reconciled (variance under 5%)
- [ ] Every channel reviewed with clear ROI assessment
- [ ] Creative performance ranked and documented
- [ ] Budget efficiency curve analyzed
- [ ] Next month plan has specific, measurable goals
- [ ] Stakeholder presentation reviewed before meeting

## Output
Monthly performance report with insights and recommendations.
Approved plan for the following month.
Updated budget allocation across channels and campaigns.

## Notes
- Compare against industry benchmarks from reference/industries/
- Flag any channel approaching diminishing returns
- Include qualitative insights (market changes, competitor moves)
- Brazilian context: account for seasonal patterns (Carnaval, Black Friday BR)
