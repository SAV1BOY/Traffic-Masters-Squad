# Cross-Squad Handoff Workflow
> **Type**: Workflow
> **Duration**: 1-3 business days per handoff
> **Agents involved**: traffic-chief, ad-midas (Cross-squad: Copy Squad Lead, Brand Squad Lead)

## Trigger
Campaign requires assets from other squads: copy from Copy Squad, brand guidelines from Brand Squad.

## Steps
1. Request Initiation → Agent: traffic-chief → Framework: Handoff Brief → Output: Formal request with scope, deadline, specs, and context
2. Copy Squad Handoff → Agent: Copy Squad Lead → Framework: Ad Copy Delivery → Output: Primary text, headlines, descriptions in all required variations and languages
3. Brand Squad Handoff → Agent: Brand Squad Lead → Framework: Brand Asset Package → Output: Brand guidelines, logos, color codes, fonts, tone of voice document
4. Asset Review → Agent: ad-midas → Framework: Integration Check → Output: Received assets verified against brief requirements
5. Feedback Loop → Agent: traffic-chief → Framework: Revision Protocol → Output: Feedback delivered with specific, actionable revision requests
6. Final Delivery → Agent: All Squads → Framework: Final Handoff → Output: All assets finalized, approved, and stored in shared asset library
7. Integration → Agent: ad-midas → Framework: Creative Assembly → Output: Assets integrated into campaign creatives and ad copy
8. Cross-Squad Debrief → Agent: traffic-chief → Framework: Process Improvement → Output: Notes on what worked and what to improve in handoff process

## Quality Gates
- [ ] Brief clearly defines all requirements with examples
- [ ] Deadlines agreed upon by all squads before work begins
- [ ] Copy matches traffic squad's audience temperature and angle
- [ ] Brand assets are current version (not outdated)
- [ ] All assets delivered in required formats and sizes
- [ ] Revision turnaround within 24 hours
- [ ] Final assets stored in centralized location

## Output
Complete asset package from supporting squads.
Documented handoff process with timelines.
Updated cross-squad collaboration notes.

## Handoff Templates
- Copy Request: audience, angle, tone, CTA, character limits, number of variations
- Brand Request: formats needed, usage context, platform destinations
- Creative Request: specs, references, deadline, testing plan

## Notes
- Always provide context: who is the audience, what stage of funnel, what platform
- Use shared project management tool for tracking handoff status
- Build in 2-day buffer for revisions
- Maintain a shared calendar of campaign launches across squads
- Quarterly cross-squad alignment meeting to improve collaboration
