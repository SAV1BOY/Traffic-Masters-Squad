# New Account Onboarding Workflow
> **Type**: Workflow
> **Duration**: 5-7 business days
> **Agents involved**: traffic-chief, pixel-specialist, media-buyer, performance-analyst

## Trigger
New client signed or new ad account to be managed.

## Steps
1. Access Setup → Agent: traffic-chief → Framework: Access Checklist → Output: All platform accesses granted (ad accounts, analytics, CRM, landing pages)
2. Discovery Call → Agent: traffic-chief → Framework: Client Intake Form → Output: Completed brief with goals, audience, history, assets, constraints
3. Historical Audit → Agent: performance-analyst → Framework: Account Audit Lite → Output: Summary of past 90 days performance (if data exists)
4. Competitive Research → Agent: traffic-chief → Framework: Ad Library + SimilarWeb → Output: Competitor landscape analysis with creative examples
5. Strategy Document → Agent: traffic-chief → Framework: GECO → Output: Initial strategy with objectives, audiences, channels, budget, timeline
6. Tracking Setup → Agent: pixel-specialist → Framework: Tracking Setup Workflow → Output: All tracking verified and documented
7. Account Build → Agent: media-buyer → Framework: Campaign Structure SOP → Output: Campaigns built with proper naming, targeting, creatives
8. Internal Review → Agent: traffic-chief → Framework: Launch QA → Output: Full review of setup before go-live
9. Client Approval → Agent: traffic-chief → Framework: Client Sign-off → Output: Strategy and setup approved by client
10. Launch → Agent: media-buyer → Framework: Soft Launch Protocol → Output: Campaigns live at initial budget

## Quality Gates
- [ ] All platform accesses confirmed and working
- [ ] Client brief complete with no open questions
- [ ] Historical data reviewed (if available)
- [ ] Strategy approved by client
- [ ] Tracking fully validated
- [ ] Naming conventions applied consistently
- [ ] Budget matches agreed allocation
- [ ] Emergency contacts and escalation paths documented

## Output
Fully onboarded account ready for management.
Strategy document, tracking documentation, and campaign structure archived.
Client communication cadence established.

## Notes
- Brazilian clients: verify CPF/CNPJ and NF requirements upfront
- Set realistic expectations: first 2-4 weeks are learning phase
- Establish reporting cadence (weekly updates, monthly reviews)
- Create shared workspace for client collaboration
