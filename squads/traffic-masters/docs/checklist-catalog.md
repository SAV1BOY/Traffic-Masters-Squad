## 1. Pre-Launch Checklist

**Trigger:** Before activating any new campaign
**Owner:** Launch Agent
**Estimated Time:** 30-45 minutes

### Campaign Settings
- [ ] Campaign objective matches business goal
- [ ] Campaign name follows naming convention
- [ ] Start and end dates are correct
- [ ] Budget amount and type (daily/lifetime) are correct
- [ ] Bid strategy is appropriate for campaign maturity and data volume
- [ ] Campaign spending limits are set (if applicable)

### Ad Set / Ad Group Settings
- [ ] Audience targeting matches the strategy document
- [ ] Geographic targeting is correct
- [ ] Age, gender, and demographic settings are intentional
- [ ] Placement selections are appropriate (or properly set to auto)
- [ ] Scheduling/dayparting is configured (if applicable)
- [ ] Exclusions are applied (existing customers, converters, employees)
- [ ] Frequency caps are set (if applicable)
- [ ] Ad set name follows naming convention

### Ad / Creative Settings
- [ ] Ad copy is approved and proofread
- [ ] Creative assets meet platform specifications (dimensions, file size, duration)
- [ ] Destination URLs are correct and working
- [ ] UTM parameters are properly configured
- [ ] CTA button is appropriate for the objective
- [ ] Ad name follows naming convention
- [ ] Preview reviewed on all placements (mobile, desktop, stories, feed)

### Tracking & Measurement
- [ ] Conversion pixel/tag is firing correctly on destination pages
- [ ] Conversion events are mapped to the correct campaign objective
- [ ] UTM parameters verified in Google Analytics / analytics tool
- [ ] Attribution window is configured correctly
- [ ] Any server-side tracking (CAPI) is confirmed active

### Final Verification
- [ ] Campaign structure aligns with the approved strategy
- [ ] All assets are registered in the campaign registry
- [ ] Stakeholders have been notified of launch timing
- [ ] Monitoring plan is in place for first 72 hours

## 2. Account Audit Checklist

**Trigger:** New account onboarding or quarterly health review
**Owner:** Diagnostics Agent
**Estimated Time:** 2-4 hours

### Account Structure
- [ ] Campaign count and organization reviewed
- [ ] Naming conventions assessed for consistency
- [ ] Duplicate or overlapping campaigns identified
- [ ] Campaign-to-objective alignment verified
- [ ] Inactive campaigns reviewed for archive/deletion

### Audience Health
- [ ] Audience sizes reviewed for viability
- [ ] Audience overlap analyzed (inter-campaign)
- [ ] Exclusion lists reviewed for completeness
- [ ] Retargeting windows assessed for appropriateness
- [ ] Lookalike seed quality evaluated

### Creative Health
- [ ] Creative diversity assessed (formats, hooks, angles)
- [ ] Fatigue indicators checked (frequency, CTR trends)
- [ ] Creative age distribution reviewed
- [ ] Ad relevance / quality scores reviewed
- [ ] Platform-specific best practices compared

### Budget & Bidding
- [ ] Budget allocation vs. performance efficiency reviewed
- [ ] Bid strategies assessed for appropriateness
- [ ] Learning phase status checked across ad sets
- [ ] Pacing accuracy reviewed
- [ ] Wasted spend identified (low-performing, overlapping)

### Tracking & Attribution
- [ ] Pixel/tag implementation verified
- [ ] Conversion events firing correctly
- [ ] Attribution settings documented
- [ ] Platform vs. analytics discrepancy measured
- [ ] UTM consistency audited

### Performance Benchmarks
- [ ] KPIs compared against targets
- [ ] KPIs compared against industry benchmarks
- [ ] Trend analysis (30/60/90-day) completed
- [ ] Top and bottom performers identified
- [ ] Actionable findings prioritized by impact

## 3. Creative Review Checklist

**Trigger:** Before publishing any new ad creative
**Owner:** Creative Strategist Agent
**Estimated Time:** 15-20 minutes per creative

- [ ] Creative matches the approved brief
- [ ] Brand guidelines are followed (colors, fonts, logo usage)
- [ ] Copy is proofread for spelling, grammar, and accuracy
- [ ] Claims are substantiated and compliant
- [ ] CTA is clear and appropriate for funnel stage
- [ ] Visual quality meets platform standards
- [ ] Text-to-image ratio is within platform guidelines (if applicable)
- [ ] Creative is optimized for primary placement
- [ ] Mobile preview reviewed
- [ ] Accessibility considerations addressed (contrast, readability)
- [ ] Landing page experience is consistent with ad message
- [ ] Creative is logged in the creative registry

## 4. Tracking Audit Checklist

**Trigger:** Account onboarding, tracking discrepancies, platform changes
**Owner:** Tracking Agent
**Estimated Time:** 1-2 hours

- [ ] Pixel/tag present on all relevant pages
- [ ] Standard events firing correctly (page view, add to cart, purchase, lead, etc.)
- [ ] Custom events configured and firing
- [ ] Event parameters passing correct values (value, currency, content ID)
- [ ] Server-side tracking (CAPI) configured and deduplicating with client-side
- [ ] Cross-domain tracking configured (if applicable)
- [ ] Cookie consent implementation verified
- [ ] UTM parameters consistent across all active campaigns
- [ ] Google Analytics goals/conversions aligned with platform events
- [ ] Data layer implementation verified (if using GTM)
- [ ] Platform-reported vs. analytics-reported conversion discrepancy measured
- [ ] Attribution windows documented per platform

## 5. Weekly Optimization Checklist

**Trigger:** Every weekly optimization cycle (recommended: Mondays)
**Owner:** Optimization Agent
**Estimated Time:** 1-2 hours per account

- [ ] Review all active campaigns against KPI targets
- [ ] Check budget pacing (on track, over, under)
- [ ] Identify top and bottom performers (campaigns, ad sets, ads)
- [ ] Pause underperforming ads below threshold
- [ ] Check frequency and fatigue indicators
- [ ] Review search term / keyword reports (Google/Bing)
- [ ] Update negative keyword lists (if applicable)
- [ ] Review audience performance and overlap
- [ ] Assess bid strategy performance
- [ ] Check for ad disapprovals or policy issues
- [ ] Review landing page performance (conversion rate, bounce rate, load time)
- [ ] Document actions taken in the optimization log
- [ ] Update campaign registry with any changes

## 6. Monthly Review Checklist

**Trigger:** End of each calendar month
**Owner:** Reporting Agent
**Estimated Time:** 2-3 hours

- [ ] Compile performance data for the full month
- [ ] Compare actuals vs. targets for all primary KPIs
- [ ] Calculate month-over-month and year-over-year trends
- [ ] Identify top-performing campaigns, audiences, and creatives
- [ ] Identify underperforming areas with root cause notes
- [ ] Review budget utilization and pacing accuracy
- [ ] Update benchmarks with latest data
- [ ] Prepare executive summary
- [ ] Draft recommendations for next month
- [ ] Finalize and distribute report to stakeholders
- [ ] Archive monthly data snapshot

## 7. Budget Change Checklist

**Trigger:** Before any budget change exceeding 20%
**Owner:** Budget Agent
**Estimated Time:** 20-30 minutes

- [ ] Current performance baseline documented
- [ ] Marginal efficiency analysis completed (for increases)
- [ ] Learning phase impact assessed
- [ ] Projected impact on KPIs calculated
- [ ] Change amount and timing documented
- [ ] Stakeholder approval obtained (if required)
- [ ] Monitoring plan established for post-change period
- [ ] Rollback criteria defined
- [ ] Change logged in decisions registry

## 8. Audience Setup Checklist

**Trigger:** Creating any new audience segment
**Owner:** Audience Agent
**Estimated Time:** 15-20 minutes

- [ ] Audience definition documented (source, criteria, size)
- [ ] Audience name follows naming convention
- [ ] Exclusions applied (existing customers, recent converters, etc.)
- [ ] Overlap with existing audiences assessed
- [ ] Minimum audience size threshold met
- [ ] Privacy and data compliance verified
- [ ] Audience registered in the audience registry
- [ ] Refresh schedule established (for dynamic audiences)

---

## 9. Scaling Readiness Checklist

**Trigger:** Before scaling any campaign beyond 30% budget increase
**Owner:** Scaling Agent
**Estimated Time:** 30-45 minutes

- [ ] Campaign has at least 50 conversions in the past 7 days
- [ ] CPA/ROAS has been stable (within 15% variance) for 14+ days
- [ ] Campaign has exited learning phase
- [ ] Creative inventory is sufficient (minimum 3 active winners)
- [ ] Audience headroom exists (potential reach > 3x current reach)
- [ ] Landing page can handle increased traffic
- [ ] Tracking is verified and accurate
- [ ] Budget increase plan is phased (max 20-30% per increment)
- [ ] Efficiency monitoring thresholds defined
- [ ] Rollback plan documented

## 10-15: Additional Checklists

### 10. Post-Launch Monitoring Checklist
**Trigger:** First 72 hours after campaign activation
- [ ] Ads are delivering (impressions confirmed within 4 hours)
- [ ] Spend pacing is within expected range
- [ ] No ad disapprovals
- [ ] Tracking is recording conversions
- [ ] Early metrics (CTR, CPC) are within acceptable ranges
- [ ] Landing page is functioning correctly
- [ ] No abnormal audience behavior

### 11. Creative Rotation Checklist
**Trigger:** When fatigue indicators are triggered
- [ ] Fatigue confirmed (CTR decline > 20%, frequency > threshold)
- [ ] New creative assets are ready and approved
- [ ] Phased rotation plan established (don't pause all at once)
- [ ] Winning elements preserved in new variations
- [ ] Performance data from retiring creative archived

### 12. Platform Migration Checklist
**Trigger:** Moving campaigns between platforms
- [ ] Current performance baseline documented
- [ ] Platform-specific requirements reviewed
- [ ] Creative assets adapted to new platform specs
- [ ] Tracking configured on new platform
- [ ] Audience equivalents built on new platform
- [ ] Naming conventions adapted

### 13. Compliance Review Checklist
**Trigger:** Regulated industry ads (health, finance, legal)
- [ ] Claims verified and substantiated
- [ ] Required disclaimers included
- [ ] Industry-specific regulations reviewed
- [ ] Platform-specific policies for the category checked
- [ ] Legal/compliance team sign-off obtained

### 14. Reporting Quality Checklist
**Trigger:** Before sending any client-facing report
- [ ] All data points verified for accuracy
- [ ] Calculations and percentages double-checked
- [ ] Consistent terminology used throughout
- [ ] Report period is clearly stated
- [ ] Insights are actionable, not just descriptive
- [ ] Formatting is professional and consistent

### 15. Experiment Design Checklist
**Trigger:** Before launching any A/B test
- [ ] Hypothesis is clearly stated
- [ ] Single variable isolated
- [ ] Success metric defined
- [ ] Minimum sample size calculated
- [ ] Test duration estimated
- [ ] Statistical significance threshold set (typically 95%)
- [ ] Holdout/control properly configured
- [ ] Test registered in experiments registry
