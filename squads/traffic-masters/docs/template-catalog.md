## 1. Weekly Performance Report

**Usage Context:** Delivered every week to clients or internal stakeholders
**Audience:** Account managers, marketing directors, CMOs
**Cadence:** Weekly (typically Monday or Tuesday)

### Structure
```
1. Executive Summary (3-5 sentences)
   - Overall performance vs. targets
   - Key wins
   - Key concerns

2. KPI Scorecard
   - Table: Metric | This Week | Last Week | WoW Change | Target | Status
   - Metrics: Spend, Impressions, Clicks, CTR, CPC, Conversions, CPA, Revenue, ROAS

3. Campaign-Level Performance
   - Top performers with commentary
   - Underperformers with diagnosis and action

4. Creative Performance
   - Top 3 ads by primary KPI
   - Creative fatigue alerts

5. Key Actions Taken This Week
   - Bulleted list of optimizations performed

6. Priorities for Next Week
   - Bulleted list of planned actions

7. Appendix (optional)
   - Detailed data tables
```

## 2. Monthly Performance Report

**Usage Context:** Comprehensive end-of-month review
**Audience:** Clients, leadership, stakeholders
**Cadence:** Monthly (first week of the following month)

### Structure
```
1. Executive Summary
   - Monthly performance narrative
   - Top 3 highlights
   - Top 3 areas of focus

2. KPI Dashboard
   - Table: Metric | This Month | Last Month | MoM Change | Target | YTD
   - Full metric set including efficiency and volume metrics

3. Channel Performance
   - Performance by platform/channel
   - Channel contribution analysis

4. Campaign Performance
   - Campaign-by-campaign breakdown
   - Winner/loser analysis with root causes

5. Audience Performance
   - Segment-level performance comparison
   - Audience health indicators (frequency, saturation)

6. Creative Performance
   - Format performance comparison
   - Hook/angle analysis
   - Creative lifecycle status

7. Budget Analysis
   - Spend vs. plan
   - Pacing accuracy
   - Efficiency by spend tier

8. Trend Analysis
   - 3-month trend charts for primary KPIs
   - Seasonality context

9. Test Results
   - Summary of tests run this month
   - Key learnings

10. Recommendations
    - Prioritized list of recommended actions for next month
    - Strategic considerations

11. Appendix
    - Detailed data tables
    - Methodology notes
```

## 3. Quarterly Business Review

**Usage Context:** Strategic quarterly review with senior stakeholders
**Audience:** C-suite, VPs, senior marketing leadership
**Cadence:** Quarterly

### Structure
```
1. Quarter in Review
   - Performance narrative (business-level, not tactical)
   - Key achievements
   - Key challenges

2. KPI Performance vs. Business Goals
   - Quarterly targets vs. actuals
   - YTD progress toward annual goals

3. Strategic Analysis
   - Channel mix effectiveness
   - Audience strategy evolution
   - Creative strategy performance
   - Competitive landscape changes

4. Investment Analysis
   - ROI by channel and campaign type
   - Marginal efficiency analysis
   - Budget utilization assessment

5. Test & Learn Summary
   - Major tests and outcomes
   - Strategic implications of learnings

6. Market & Competitive Context
   - Industry trends affecting performance
   - Competitive activity summary

7. Strategic Plan for Next Quarter
   - Objectives and KPI targets
   - Planned initiatives
   - Budget recommendations
   - Risk factors and mitigation

8. Appendix
   - Detailed data
   - Methodology
```

## 4. Campaign Brief

**Usage Context:** Planning a new campaign or campaign initiative
**Audience:** Internal team, agents, stakeholders

### Structure
```
1. Campaign Overview
   - Campaign name and ID
   - Business objective
   - Campaign objective
   - Budget and timeline

2. Target Audience
   - Primary audience definition
   - Secondary audiences
   - Exclusions

3. Messaging Strategy
   - Key value proposition
   - Primary message
   - Supporting messages
   - Tone and voice guidance

4. Channel & Platform Strategy
   - Platforms and placements
   - Format requirements
   - Budget split by channel

5. Creative Requirements
   - Number and types of assets needed
   - Specifications per platform
   - Key visual and copy direction

6. KPIs & Success Criteria
   - Primary KPI and target
   - Secondary KPIs
   - Reporting cadence

7. Timeline
   - Key milestones and deadlines

8. Tracking & Measurement
   - Attribution model
   - Tracking requirements
   - UTM structure
```

## 5. Creative Brief

**Usage Context:** Briefing creative production for ad assets
**Audience:** Creative team, designers, videographers

### Structure
```
1. Project Overview
   - Campaign name and context
   - Number of assets needed
   - Formats and specifications

2. Audience Profile
   - Who are we talking to?
   - What do they care about?
   - Where are they in the journey?

3. Key Message
   - Single most important takeaway
   - Supporting proof points

4. Creative Direction
   - Visual style guidance
   - Mood and tone
   - Reference examples / swipe file links

5. Copy Direction
   - Headline/hook direction
   - Body copy themes
   - CTA

6. Technical Requirements
   - Dimensions and file formats
   - Duration (for video)
   - Platform-specific requirements

7. Deliverables & Timeline
   - Asset list
   - Draft due date
   - Final due date
   - Review and approval process
```

## Usage Guidelines

1. **Select the right template** — Match the template to the communication need and audience
2. **Customize, don't copy** — Templates are starting frameworks; adapt sections to fit the specific context
3. **Maintain consistency** — Use the same template structure across all accounts for comparability
4. **Version control** — When modifying a template, update the version and document changes
5. **Populate fully** — Incomplete templates lose their value; fill every relevant section
