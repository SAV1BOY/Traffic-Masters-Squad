# Workflow Guide

## Purpose
Define daily, weekly, and monthly workflows for the traffic squad.

## Daily Workflow
1. **Morning Check (15 min)**
   - Review spend pacing across platforms
   - Check for guardrail breaches
   - Note any policy violations or delivery issues
   - Post daily check-in to Slack

2. **Optimization Window (30-60 min)**
   - Adjust bids/budgets based on pacing
   - Pause underperforming creatives (decision rules)
   - Review search term reports (Google)
   - Check frequency and fatigue signals

3. **End of Day (10 min)**
   - Log any decisions made in decisions-log
   - Note observations for weekly review

## Weekly Workflow
1. **Monday:** Review prior week scorecard, plan the week
2. **Tuesday-Thursday:** Optimization, creative launches, testing
3. **Friday:** Compile weekly scorecard, update registries
4. **Weekly Review Meeting:** Performance, tests, next week plan

## Monthly Workflow
1. **Week 1:** Month-end close, monthly report
2. **Week 2:** Strategic review, budget recommendation
3. **Week 3:** Creative pipeline planning
4. **Week 4:** Competitive analysis, experiment planning

## Quarterly Workflow
- Full account audit
- Strategy refresh
- Budget reallocation review
- Maturity score assessment
- Goal setting for next quarter

## Key Artifacts Updated
| Cadence | Artifact |
|---------|----------|
| Daily | Decisions log, campaign adjustments |
| Weekly | Scorecard, experiment updates |
| Monthly | Full report, budget review, lessons learned |
| Quarterly | Strategy doc, maturity score, audit |
