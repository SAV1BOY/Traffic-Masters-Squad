# Framework Selection Guide

## Purpose
How to choose the right framework, pattern, or component for each situation.

## Campaign Structure
| Situation | Recommended Framework |
|-----------|----------------------|
| New account, small budget | CBO Consolidated (lib/patterns/campaign-structure-patterns.md) |
| Mature account, scaling | Funnel-Based Structure |
| Creative testing phase | Testing Structure |
| Multi-market expansion | Geo/Market Split |

## Scaling
| Situation | Recommended Pattern |
|-----------|-------------------|
| Winning creative, stable CPA | Vertical Scaling (budget increase) |
| Audience saturation | Horizontal Scaling (new audiences) |
| Platform ceiling | Cross-Platform Synergy |
| First scaling attempt | Test-Then-Scale |

## Budget Allocation
| Situation | Recommended Framework |
|-----------|----------------------|
| Standard operation | 70-20-10 Pattern |
| Multiple platforms | Marginal CPA allocation |
| New campaign launch | Test-Then-Scale budget phasing |

## Creative Strategy
| Situation | Recommended Approach |
|-----------|---------------------|
| Winning creative found | Creative Iteration Pattern |
| No winners yet | Hook testing (5 hooks per concept) |
| Creative fatigue | New concept development + iteration |

## Audience Strategy
| Situation | Recommended Component |
|-----------|----------------------|
| New campaign | Cold-to-Hot Pattern |
| Warm audience available | Retargeting Sequence Pattern |
| Audience exhaustion | Horizontal expansion + new platforms |

## How to Use This Guide
1. Identify your current situation
2. Find the matching framework above
3. Navigate to the referenced file
4. Apply the framework to your specific context
