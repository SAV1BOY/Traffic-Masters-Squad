# Swipe File Guide

## Purpose
How to use and contribute to the squad's swipe file collection.

## Swipe File Structure
- `swipe/meta/` — Meta (Facebook/Instagram) ad winners
- `swipe/google/` — Google Ads winners
- `swipe/youtube/` — YouTube ad winners
- `swipe/tiktok/` — TikTok ad winners
- `swipe/linkedin/` — LinkedIn ad winners
- `swipe/angles/` — Messaging angles (cross-platform)
- `swipe/hooks/` — Hook types and examples
- `swipe/funnels/` — Funnel-specific ad sequences
- `swipe/landing-pages/` — Landing page examples
- `swipe/iconic-campaigns/` — Legendary campaigns analyzed

## How to Use Swipe Files
1. **Before writing copy:** Browse relevant platform and angle files
2. **When stuck on hooks:** Check `swipe/hooks/` for inspiration
3. **Planning a funnel:** Review `swipe/funnels/` for stage-by-stage examples
4. **Competitive research:** Cross-reference with `swipe-sources/`

## How to Contribute
1. Find a winning ad (running 90+ days = likely winner)
2. Use the entry template in the relevant file
3. Analyze WHY it works (not just what it says)
4. Tag with angle, hook type, and format
5. Include metrics if available
6. Add to the Update Log at the bottom

## Sources for New Swipe Entries
- See `swipe-sources/` for mining guides
- Meta Ad Library, TikTok Creative Center, Google Transparency
- Competitor monitoring (monthly sweep)
- Personal ad feeds (screenshot winners in the wild)

## Maintenance
- Monthly: Add 5+ new entries per platform
- Quarterly: Archive outdated entries
- Annually: Full swipe file review and reorganization
