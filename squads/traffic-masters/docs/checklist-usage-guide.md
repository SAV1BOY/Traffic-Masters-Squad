# Checklist Usage Guide

## Purpose
How to use the squad's checklists for consistent campaign execution.

## Available Checklists

### Pre-Launch Checklist
- Tracking verified (pixel, events, UTMs)
- Creative approved (scoring rubric passed)
- Copy compliance reviewed
- Audience exclusions set
- Budget and bid strategy confirmed
- Naming conventions applied
- Landing page tested (speed, mobile, conversion)

### Weekly Optimization Checklist
- [ ] Spend pacing review (all platforms)
- [ ] Guardrail status check
- [ ] Creative fatigue scan (frequency, CTR trend)
- [ ] Search term review (Google)
- [ ] Experiment status update
- [ ] Budget reallocation assessment
- [ ] Scorecard compilation

### Monthly Audit Checklist
- [ ] Account structure review
- [ ] Audience overlap analysis
- [ ] Creative performance tier assignment
- [ ] Budget efficiency analysis
- [ ] Tracking health verification
- [ ] Competitive intelligence update
- [ ] Lessons learned documentation

### Campaign Shutdown Checklist
- [ ] Final performance data captured
- [ ] Learnings documented
- [ ] Creative assets archived
- [ ] Audience lists preserved
- [ ] Budget reallocated
- [ ] Registries updated

## How to Use
1. Open the relevant checklist before starting the task
2. Complete each item in order
3. Document any deviations or exceptions
4. Archive completed checklists for reference
