# Reporting Standards

## Purpose
Standards for all traffic performance reports.

## Report Types

### Daily Check-In (Slack)
- Format: 3-5 bullet points
- Content: Pacing, alerts, actions taken
- Audience: Internal team

### Weekly Scorecard
- Format: 1-page structured template
- Content: Metrics table, wins, challenges, next steps
- Audience: Team + marketing manager
- Due: Every Friday

### Monthly Report
- Format: 2-3 pages, structured sections
- Content: Full analysis, strategic insights, recommendations
- Audience: Stakeholders + leadership
- Due: 3rd business day of following month

### Quarterly Review
- Format: Presentation (10-15 slides)
- Content: Strategic review, maturity assessment, planning
- Audience: Leadership + cross-functional
- Due: 2nd week of new quarter

## Data Standards
- Always compare to prior period AND target
- Include absolute numbers AND percentages
- Show trends (WoW, MoM) not just snapshots
- Round to 2 decimal places for percentages
- Use consistent date ranges across metrics

## Visualization Standards
- Line charts for trends over time
- Bar charts for platform/campaign comparisons
- Tables for detailed metric breakdowns
- Green/yellow/red for guardrail status
- Always label axes and include legends

## Distribution
- Automate where possible (Looker Studio, Supermetrics)
- Share via consistent channel (email + dashboard link)
- Archive all reports for historical reference
