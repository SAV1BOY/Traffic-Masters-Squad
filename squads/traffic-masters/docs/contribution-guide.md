# Contribution Guide

## Purpose
How to contribute to and maintain the Traffic Masters Squad knowledge base.

## What to Contribute
- New swipe file entries (winning ads discovered)
- Experiment results and learnings
- Updated benchmarks and metrics
- New patterns or frameworks discovered
- Tool reviews and recommendations
- Process improvements

## Contribution Process
1. Identify the correct file/section for your contribution
2. Follow the existing template format
3. Include supporting data or evidence
4. Add your entry with date stamp
5. Update the relevant registry if applicable

## Quality Standards
- All claims backed by data or documented experience
- Follow naming conventions and formatting standards
- Use standard terminology (see platform-terminology-guide.md)
- Proofread for clarity and accuracy

## File Naming for New Files
- Use lowercase with hyphens: `my-new-file.md`
- Include category prefix where applicable
- Keep names descriptive but concise

## Review Process
- Minor additions (swipe entries, metric updates): Self-review
- New frameworks or patterns: Peer review required
- Structural changes (new directories, reorganization): Squad lead approval

## What NOT to Do
- Modify template structures without team approval
- Delete existing entries without archiving
- Add untested ideas as "proven" patterns
- Include confidential client data without anonymization
- Create duplicate files instead of updating existing ones
