# High-Ticket Application Funnel Ads — Swipe File

## Purpose
Exemplos de ads para cada etapa do funnel de aplicacao para produtos/servicos high-ticket (R$3k+ por venda).

## Estrutura do Funnel

```
TOFU (Awareness) -> MOFU (Lead Magnet/Webinar) -> BOFU (Application/Call)
     |                       |                            |
  Problema visivel    Solucao apresentada          Qualificacao + Venda
```

## Stage 1: TOFU — Authority Building

### Ad Example 1.1 — Founder Story
- **Format:** Video 90s — talking head do fundador
- **Hook:** "Faturei R$0 nos primeiros 8 meses. Hoje: R$4.2M/ano. Aqui esta o que mudou."
- **Body:** Historia pessoal autentica. Turning point claro. Sem pitch direto.
- **CTA:** "Siga para mais conteudo" ou "Comente SIM para receber o material"
- **Objetivo:** Build audience quente para remarketing

### Ad Example 1.2 — Contrarian Take
- **Format:** Static com headline provocativo
- **Hook:** "Escalar trafego pago nao e sobre gastar mais. E sobre gastar diferente."
- **Body:** 3 bullets contrarian que desafiam crencas comuns do mercado
- **CTA:** "Quer saber como? Link na bio" -> Conteudo gratuito
- **Objetivo:** Engagement + audience building

## Stage 2: MOFU — Lead Capture

### Ad Example 2.1 — Webinar Registration
- **Format:** Video 60s — highlights do conteudo do webinar
- **Hook:** "Na quinta-feira vou abrir a tela e mostrar exatamente como estruturamos campanhas de R$500k+/mes"
- **Body:** 3 coisas que vao aprender. Social proof (X alunos, Y resultado). Escassez real de vagas.
- **CTA:** "Reserve sua vaga gratis"
- **Objetivo:** Webinar registrations

### Ad Example 2.2 — Case Study Lead Magnet
- **Format:** Carousel — cada card e uma etapa do case
- **Hook:** "Como a [empresa] saiu de R$80k para R$1.2M/mes em 6 meses"
- **Body:** Card 1: Situacao inicial. Card 2-4: Estrategias aplicadas. Card 5: Resultados. Card 6: CTA
- **CTA:** "Baixe o case study completo com os numeros"
- **Objetivo:** Lead capture qualificado

### Ad Example 2.3 — Free Training Series
- **Format:** Video 45s — preview das aulas
- **Hook:** "3 aulas gratuitas: o sistema completo de trafego para high-ticket"
- **Body:** Agenda de cada aula com beneficio claro. Depoimento rapido de aluno.
- **CTA:** "Acesse as 3 aulas gratis"
- **Objetivo:** Email capture + nurturing via sequencia

## Stage 3: BOFU — Application/Booking

### Ad Example 3.1 — Direct Application (Remarketing)
- **Format:** Video 30s — depoimento de cliente
- **Hook:** "Em 90 dias nosso ROAS foi de 1.8x para 7.2x. Aqui esta minha experiencia..."
- **Body:** Cliente real contando resultado. Especificidade nos numeros.
- **CTA:** "Aplique para uma sessao estrategica"
- **Target:** Webinar attendees + lead magnet downloaders

### Ad Example 3.2 — Objection Handling
- **Format:** Static com FAQ visual
- **Hook:** "As 3 duvidas mais comuns antes de aplicar (e as respostas)"
- **Body:** Pergunta 1: Funciona pro meu nicho? Pergunta 2: Quanto tempo leva? Pergunta 3: E se nao der resultado?
- **CTA:** "Aplique e descubra se faz sentido pra voce"
- **Target:** Leads quentes que nao aplicaram

## Metricas por Stage
| Stage | Metrica Principal | Benchmark High-Ticket |
|-------|-------------------|-----------------------|
| TOFU | CPM, Video Views, Engagement | ThruPlay < R$0.15 |
| MOFU | CPL, Registration Rate | CPL < R$25 (webinar) |
| BOFU | CPA (Application), Show Rate, Close Rate | CPA < 5% do ticket medio |

## Scoring Criteria
| Factor | Weight |
|--------|--------|
| Qualificacao do lead | 30% |
| Authority building | 25% |
| Proof e credibilidade | 25% |
| Funnel coherence | 20% |
