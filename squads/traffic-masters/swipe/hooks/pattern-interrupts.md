# Pattern Interrupt Hooks — Swipe File

## Purpose
Hooks that break the scroll pattern through unexpected elements.

## Categories

### Visual Pattern Interrupts
- Unusual camera angle or framing
- Bold, contrasting colors against feed norms
- Text in unexpected places or sizes
- Physical action (dropping, breaking, throwing)

### Verbal Pattern Interrupts
- "WAIT — before you scroll past this..."
- "I need to tell you something nobody else will."
- "This is going to sound crazy, but..."
- "I got fired for sharing this strategy."

### Structural Pattern Interrupts
- Start mid-sentence or mid-action
- Begin with the result, then rewind
- Open with silence (2s) then sudden start
- Split screen with conflicting visuals

## Rules for Effectiveness
1. Must connect to the ad message (not clickbait)
2. Interrupt should transition naturally to value
3. Test 3-5 pattern interrupts per creative concept
4. Platform-native interrupts outperform cross-platform
