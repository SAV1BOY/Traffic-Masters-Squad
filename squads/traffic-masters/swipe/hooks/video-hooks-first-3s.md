# Video Hooks — First 3 Seconds

## Purpose
Video-specific hooks optimized for the critical first 3 seconds across platforms.

## Visual Hooks (No Words Needed)

| # | Hook | Description |
|---|------|-------------|
| 1 | Product smash | Product being destroyed or stress-tested |
| 2 | Before/after split | Immediate visual transformation |
| 3 | Unusual setting | Product in unexpected environment |
| 4 | Speed ramp | Fast motion that suddenly slows |
| 5 | Face reaction | Strong emotional reaction close-up |

## Audio Hooks

| # | Hook | Description |
|---|------|-------------|
| 1 | Trending sound | Platform-native trending audio clip |
| 2 | Silence break | 1-2s silence then sudden voice/sound |
| 3 | Whisper | Low whisper forces attention |
| 4 | ASMR | Satisfying product sound |

## Text/Caption Hooks

| # | Hook | Description |
|---|------|-------------|
| 1 | Bold claim overlay | Large text with surprising stat |
| 2 | "Watch till the end" | Creates completion commitment |
| 3 | Counter/timer | Countdown or progress element |
| 4 | Subtitle hook | Captions that tease what's coming |

## Platform-Specific Notes
- **Meta:** Visual-first, text overlay essential (85% watch muted)
- **TikTok:** Audio-first, trending sounds boost delivery
- **YouTube:** Verbal hook critical (most watch with sound)
- **LinkedIn:** Professional visual + text overlay combo

## Testing Protocol
1. Create 5 hook variations per concept
2. Same body/CTA, different hooks only
3. Measure hook rate (3s views / impressions)
4. Winner gets scaled, losers inform next batch
