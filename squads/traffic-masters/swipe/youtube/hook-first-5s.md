# Hook — First 5 Seconds Winners — YouTube

## Purpose
Collection of hooks that prevent skips in the critical first 5 seconds.

## Hook Categories

### 1. Pattern Interrupt
- Unexpected visual or statement that breaks autopilot
- Example: "STOP. Don't skip this — it'll save you $10K."

### 2. Bold Claim
- Specific, measurable, surprising statement
- Example: "We grew from $0 to $1M in 73 days using one strategy."

### 3. Curiosity Gap
- Opens a loop the viewer must close
- Example: "There's a reason your ads stopped working last Tuesday."

### 4. Direct Challenge
- Calls out the viewer's current behavior
- Example: "You're still running broad targeting? Here's why that's costing you."

### 5. Visual Hook
- Something visually unusual happens before any words
- Example: Product being destroyed, unexpected setting, split screen

## Winners Catalog

| # | Hook Text / Description | Category | VTR Impact |
|---|------------------------|----------|------------|
| 1 | "Delete your ad account if..." | Challenge | +35% VTR |
| 2 | Product explodes on screen | Visual | +42% VTR |
| 3 | "Nobody's talking about this..." | Curiosity | +28% VTR |

## Anti-Patterns (Hooks That Fail)
1. Starting with brand logo (instant skip)
2. Generic "Hey guys" opening
3. Slow build without early payoff promise
4. Music-only intros longer than 2 seconds
