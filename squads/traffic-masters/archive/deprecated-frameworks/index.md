# Deprecated Frameworks — Archive Index

## Purpose
Archive of frameworks, patterns, or processes that are no longer in active use.

## Why Frameworks Get Deprecated
- Platform changes made the approach obsolete
- Better framework developed and adopted
- Industry shift made the approach less effective
- Too complex/simple for current needs

## How to Deprecate a Framework
1. Document reason for deprecation
2. Move file from active directory to this archive
3. Update any references in active documentation
4. Note the replacement framework (if applicable)
5. Add entry to this index
