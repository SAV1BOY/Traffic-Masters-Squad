# Biggest Ad Account Bans — Lessons Learned

## Purpose
Document common causes of account bans and how to prevent them.

## Common Ban Causes

### 1. Policy Violations (Repeated)
- Making health/income claims without substantiation
- Using before/after images without disclaimers
- Advertising prohibited products or services
- **Prevention:** Pre-launch compliance review, policy-safe language guide

### 2. Circumventing Systems
- Creating new accounts after a ban
- Using cloaking (showing different content to reviewers)
- Misleading redirects or landing pages
- **Prevention:** Never circumvent — resolve the root issue

### 3. Payment Issues
- Disputed charges or chargebacks
- Invalid payment methods
- Unusual spending patterns flagging fraud detection
- **Prevention:** Keep payment info current, gradual spend increases

### 4. User Feedback
- High volume of negative feedback ("Hide ad", "Report")
- Low relevance scores triggering review
- Community Standards violations from user reports
- **Prevention:** Target relevant audiences, monitor feedback metrics

### 5. Automated Detection Errors
- Algorithm falsely flags compliant ads
- New ad format triggers automated review
- Landing page content misinterpreted
- **Prevention:** Appeal promptly with clear documentation

## Recovery Process
1. Read the specific violation notice carefully
2. Identify and remove the offending element
3. Submit appeal with documentation of changes
4. If appeal fails, request manual review
5. As last resort, contact platform representative (if available)

## Prevention Checklist
- [ ] All ads reviewed against policy before launch
- [ ] No prohibited claims in copy or creative
- [ ] Landing pages match ad promises
- [ ] Payment methods valid and current
- [ ] Feedback metrics monitored weekly
