# Past Campaigns — Archive Index

## Purpose
Archive of completed campaigns with performance data and learnings.

## How to Archive a Campaign
1. Export final performance data from platform
2. Create campaign summary using template below
3. Move creative assets to archive storage
4. Update campaigns-registry.yaml status to "archived"
5. Document key learnings in lessons-learned-registry.yaml

## Campaign Archive Template

### [Campaign Name]
- **ID:** CMP-XXX
- **Platform:** Meta / Google / TikTok / YouTube / LinkedIn
- **Duration:** Start date to end date
- **Total Spend:** $X
- **Results:** Conversions, CPA, ROAS
- **Key Learning:** One-sentence summary
- **Assets:** Link to archived creative files
