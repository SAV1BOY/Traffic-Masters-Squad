# Past Creatives — Archive Index

## Purpose
Archive of retired ad creatives with performance history.

## How to Archive a Creative
1. Record final performance metrics
2. Note reason for retirement (fatigue, poor performance, campaign end)
3. Save creative asset file (image/video) to archive storage
4. Update creatives-registry.yaml status to "retired"
5. Link any learnings to lessons-learned registry

## Creative Archive Template

### [Creative Name]
- **ID:** CRE-XXX
- **Format:** Video / Static / Carousel
- **Platform:** Meta / Google / TikTok / YouTube
- **Active Period:** Start to end date
- **Total Spend:** $X
- **Impressions:** X
- **CTR:** X%
- **CPA:** $X
- **Retirement Reason:** Fatigue / underperformance / campaign end / policy
- **Iterations Spawned:** [List of creative IDs that iterated from this]
- **Key Learning:** One-sentence insight
