# Google Search Campaign Build

> **Type**: Task
> **Category**: setup
> **Agents**: Aslam, Media Buyer
> **Frameworks**: Google Search Architecture, SKAG/STAG Strategy
> **Checklists**: google-search-build-checklist
> **Output template**: templates/google-search-build-sheet.md

## Objective
Build Google Search campaigns with proper ad group structure, keyword match types, Responsive Search Ads, bidding strategy, and conversion tracking to capture high-intent search traffic aligned with the keyword research.

## Inputs
- Keyword map with grouped keywords and intent classifications
- Negative keyword list
- Ad copy variations for each ad group theme
- Landing page URLs mapped to keyword groups
- Budget allocation for Google Search
- Conversion tracking setup confirmation

## Steps
1. Create campaign structure: brand, non-brand, competitor segmentation
2. Build ad groups following keyword map groupings with tight thematic relevance
3. Add keywords with appropriate match types: exact, phrase, and broad match per strategy
4. Apply negative keywords at campaign and ad group levels
5. Write Responsive Search Ads with 15 headlines and 4 descriptions per ad group
6. Pin critical headlines to ensure key messages always appear
7. Set up ad extensions: sitelinks, callouts, structured snippets, call, location, price
8. Configure bidding strategy: manual CPC for launch, then transition to target CPA or maximize conversions
9. Set geographic targeting and ad schedule based on business requirements
10. Apply audience signals for observation: in-market, affinity, remarketing lists
11. Configure conversion actions with proper attribution settings
12. Set up campaign-level URL tracking templates for consistent UTM parameters

## Output
Live Google Search campaigns with: documented ad group structure, keyword assignments with match types, RSA copy, extension configurations, bidding settings, negative keyword application, and tracking verification.

## Quality Gate
- Google search build checklist confirms all configuration elements complete
- Aslam validates keyword-to-ad-group relevance and negative keyword coverage
- Conversion tracking verified with test conversions before spending budget

## Duration
4-6 hours for build; 1-2 hours for QA and verification
