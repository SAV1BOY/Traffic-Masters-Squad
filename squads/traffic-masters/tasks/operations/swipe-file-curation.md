# Swipe File Curation

> **Type**: Task
> **Category**: operations
> **Agents**: Creative Analyst, Ad Midas
> **Frameworks**: Swipe File Management, Competitive Intelligence Curation
> **Checklists**: swipe-file-curation-checklist
> **Output template**: templates/swipe-file-index.md

## Objective
Curate and maintain the squad's swipe file by continuously adding new competitive ads, annotating entries with strategic insights, removing outdated examples, and organizing the collection for easy creative reference.

## Inputs
- Existing swipe file from initial competitor mining
- New ads spotted across platforms during daily monitoring
- Ad library tools: Meta Ad Library, TikTok Creative Center, Google Transparency
- Performance data on ads with long run times (indicating winners)
- Industry newsletters and creative roundups
- Team submissions of noteworthy ads encountered

## Steps
1. Review new ads submitted by team members since the last curation session
2. Search ad libraries for new competitor campaigns launched in the past period
3. Screen new entries for quality: only add ads that demonstrate a clear creative insight
4. Annotate each new entry: hook type, angle, offer, format, estimated performance, learning
5. Tag entries by category: hook style, emotional driver, format type, industry, platform
6. Identify and flag ads with exceptionally long run times as proven winners
7. Remove outdated entries: ads no longer running that have been replaced by new versions
8. Update annotations on existing entries if new performance data is available
9. Identify emerging creative trends from the new additions
10. Write a brief trend summary highlighting new patterns or shifts in the competitive landscape
11. Organize the swipe file structure for easy browsing by category, date, or platform
12. Share notable new additions with the squad for creative inspiration

## Output
Updated swipe file with: new annotated entries, updated tags, trend summary, removed outdated items, and organized index for browsing.

## Quality Gate
- Swipe file curation checklist confirms regular cadence maintained
- All entries annotated with required fields
- Ad Midas validates trend summary and notable additions

## Duration
1-2 hours bi-weekly for ongoing curation; more during initial build
