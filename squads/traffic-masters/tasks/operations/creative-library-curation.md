# Creative Library Curation

> **Type**: Task
> **Category**: operations
> **Agents**: Creative Analyst
> **Frameworks**: Asset Management Framework, Creative Taxonomy
> **Checklists**: creative-library-checklist
> **Output template**: templates/creative-library-index.md

## Objective
Curate and maintain the creative asset library with consistent tagging, performance annotations, and organized structure so that any squad member can quickly find, reference, and build upon existing creative assets.

## Inputs
- All creative assets produced: images, videos, copy documents
- Creative performance data from all platforms
- Brand asset library: logos, fonts, templates, guidelines
- Creative analysis reports with winner/loser classifications
- Naming convention documentation
- Storage platform access (Google Drive, Dropbox, DAM tool)

## Steps
1. Audit the current creative library for completeness and organization
2. Define the taxonomy structure: folders by format, angle, platform, campaign, date
3. Establish tagging conventions: angle, hook type, format, platform, performance tier, status
4. Upload any unarchived creative assets with proper naming and tagging
5. Annotate top performers with performance data: CTR, CPA, ROAS, run dates, spend
6. Tag creatives by status: active, paused, retired, ready-to-launch, in-production
7. Link creatives to their briefs and scripts for context and iteration reference
8. Remove duplicate files and consolidate versions to keep the library clean
9. Create a searchable index or catalog document for quick reference
10. Set up a process for new asset intake: how creatives get added to the library
11. Archive retired creatives in a separate location to keep the active library lean
12. Update the library index with current inventory counts and coverage notes

## Output
Creative library index containing: taxonomy structure, tagging guide, searchable catalog, performance annotations on top assets, intake process documentation, and inventory summary by format and status.

## Quality Gate
- Creative library checklist confirms all assets tagged and organized
- Library is searchable and any asset can be found within 2 minutes
- Creative Analyst validates performance annotations are current and accurate

## Duration
4-6 hours for initial curation; 1-2 hours weekly for ongoing maintenance
