## Objective
Create detailed UGC briefs and shot lists for creator content that feels authentic and native to each platform while delivering strategic messaging aligned with campaign angles and hooks.

## Inputs
- Creative strategy with prioritized angles and formats
- Hook and angle bank with UGC-suitable combinations
- ICP and avatar document for creator casting guidance
- Platform-specific format requirements (aspect ratios, durations)
- Brand guidelines and mandatory disclosure requirements
- Examples of successful UGC ads from swipe file

## Steps
1. Define UGC content types needed: testimonial, unboxing, tutorial, day-in-the-life, problem-solution
2. Write creator casting notes: demographics, personality, environment, authenticity markers
3. Create individual briefs per angle-format combination with clear creative direction
4. Write the script outline for each brief: talking points, not word-for-word scripts
5. Build shot lists specifying: shot type, framing, setting, action, duration per shot
6. Define the hook delivery: exact opening line or action for the first 3 seconds
7. Specify B-roll requirements: product shots, lifestyle scenes, screen recordings
8. Include platform-native elements: text overlays, trending sounds, caption style
9. Document mandatory elements: disclosures, CTAs, brand mentions, offer details
10. Provide reference examples from swipe file for each brief type
11. Set technical specifications: resolution, aspect ratio, lighting requirements, audio quality
12. Create a brief review checklist for creator submissions before use in ads

## Output
UGC briefs containing: individual creator briefs per angle, shot lists with timing, casting notes, script outlines, technical specs, reference examples, mandatory elements list, and submission review checklist.

## Quality Gate
- UGC brief checklist confirms all briefs have complete shot lists and talking points
- Each brief includes platform-specific native elements
- Ad Midas validates briefs balance strategic messaging with authentic feel

## Duration
3-5 hours for brief creation; 1-2 hours for review and reference gathering
