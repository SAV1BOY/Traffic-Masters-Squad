# Dynamic Creative Setup

> **Type**: Task
> **Category**: creative
> **Agents**: Traffic Chief, Kusmich, Mandalia
> **Frameworks**: Kusmich Ad Architecture, Dynamic Creative Optimization (DCO) Framework
> **Checklists**: creative-checklist, dco-setup-checklist
> **Output template**: templates/creative-production-document.md

## Objective
Configurar campanhas de Dynamic Creative Optimization (DCO) que combinam automaticamente variações de imagem, vídeo, headline, copy e CTA para encontrar as melhores combinações por segmento de audiência.

## Inputs
- Banco de criativos estáticos e vídeos aprovados
- Variações de headlines, descriptions e CTAs
- Audiências segmentadas para personalização
- Acesso às plataformas de ads (Meta Advantage+, Google Responsive Display)
- Creative brief com messaging por segmento/etapa do funil
- Dados de performance de criativos anteriores

## Steps
1. Definir os elementos variáveis para o teste dinâmico: imagens/vídeos, headlines, descriptions, CTAs
2. Criar no mínimo 5 variações de cada elemento para alimentar o algoritmo de otimização
3. Configurar Dynamic Creative no Meta Ads: ativar a opção no ad set e subir os assets
4. Configurar Responsive Display Ads no Google Ads: subir imagens, logos, headlines e descriptions
5. Criar regras de personalização por audiência quando disponível (feed de produto, geo, device)
6. Definir o fallback creative para casos onde a personalização não se aplica
7. Configurar o tracking granular para medir performance por combinação de elementos
8. Estabelecer o período mínimo de learning phase (7-14 dias) antes de otimizar
9. Definir os KPIs de avaliação por elemento (CTR por headline, CVR por imagem, CPA por CTA)
10. Documentar todas as variações com IDs para rastreabilidade
11. Lançar e monitorar o breakdown de performance por asset nas primeiras 2 semanas

## Output
Campanhas DCO configuradas e lançadas, incluindo: inventário de assets por elemento, configurações documentadas, plano de análise de performance por combinação, e timeline de otimização.

## Quality Gate
- Mínimo de 5 variações por elemento para algoritmo eficiente
- Todos os assets seguindo as specs de cada plataforma
- Tracking configurado para reportar performance por asset individual
- Learning phase respeitada antes de qualquer otimização manual
- Traffic Chief aprova os assets e a estrutura antes do lançamento

## Duration
3-5 horas para setup de DCO; 1-2 horas para QA e lançamento
