# Meta Ad Library — Mining Guide

## URL
https://www.facebook.com/ads/library/

## How to Use for Research

### Search Strategies
1. **By Competitor:** Search brand name, see all active ads
2. **By Keyword:** Search product/service terms
3. **By Page:** Go directly to competitor's page > "Page Transparency"
4. **By Category:** Filter by "Issues, Elections, or Politics" for regulated

### What to Look For
- Ad start date (longevity = working)
- Number of active variations (testing volume)
- Creative format distribution (video vs static vs carousel)
- Copy patterns across variations
- CTA choices
- Platform placement (FB, IG, Messenger, AN)

### Mining Process
1. List top 10 competitors
2. Search each in Ad Library
3. Sort by longest-running ads (these are winners)
4. Screenshot/save ad creative, copy, and CTA
5. Catalog in swipe file with analysis notes
6. Repeat monthly to track creative rotation

## Limitations
- No performance metrics visible
- Only shows active ads (paused/stopped not visible)
- Political/social ads have more transparency
- Some regions may have limited data

## Pro Tips
- Ads running 90+ days are almost certainly profitable
- Multiple variations of same concept = active testing
- Check both mobile and desktop previews
- Note seasonal patterns in competitor ad frequency
