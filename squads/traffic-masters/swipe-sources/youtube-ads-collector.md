# YouTube Ads Collector — Mining Guide

## Methods to Collect YouTube Ads

### 1. Manual Collection
- Watch content in your target niche — note ads that appear
- Use incognito with demographic-matching for targeting
- Screenshot/record ads with timestamps

### 2. Google Ads Transparency Center
- Search advertiser name to see their YouTube ads
- Filter by format (video) and date range

### 3. Competitor Channel Analysis
- Check competitor YouTube channels for unlisted "ad" videos
- Look for videos with high view counts but low subscriber ratio (paid)

### 4. Ad Spy Tools
- VidTao: YouTube ad database with spend estimates
- BigSpy: Cross-platform including YouTube
- PowerAdSpy: Competitive intelligence

## What to Capture
- First 5 seconds (hook — transcribe exactly)
- Ad duration and format (skippable, non-skip, bumper)
- Script structure (3-act, educational, testimonial, demo)
- CTA type and placement (verbal, end card, companion banner)
- Landing page URL
- Estimated run duration (longevity = performance)

## Organization System
1. Save video file or link
2. Transcribe hook and key sections
3. Categorize by angle, format, and industry
4. Rate on hook strength, engagement, CTA clarity
5. Add to platform-specific swipe folder

## Pro Tips
- Ads running 6+ months on YouTube are high performers
- Check companion banner CTR by observing banner quality
- Note which audiences are being targeted (based on content context)
