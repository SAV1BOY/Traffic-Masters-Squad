# Google Ads Transparency Center — Mining Guide

## URL
https://adstransparency.google.com/

## How to Use

### Search Options
- **By Advertiser:** Search company/brand name
- **By Domain:** Search website URL
- **By Topic:** Browse by category
- **Filters:** Region, date range, format (text/image/video)

### What You Can See
- All ads an advertiser has run across Google properties
- Ad format (Search, Display, YouTube, Shopping)
- Regions where ads are shown
- Date range of ad activity
- Creative preview (text, image, video)

## Mining Process
1. List your top 10 competitors
2. Search each in Transparency Center
3. Filter by format to analyze each channel separately
4. For Search: note headline and description patterns
5. For Display: save creative images and note sizes
6. For YouTube: analyze video hooks and scripts
7. Track how frequently they rotate creative

## What to Catalog
- Advertiser name and industry
- Ad formats in use (distribution across channels)
- Key messaging themes and value propositions
- CTA patterns
- Creative refresh frequency
- Geographic targeting patterns

## Limitations
- No performance metrics
- No targeting details
- Only shows ads from verified advertisers
- Historical data limited

## Pro Tips
- Compare competitor ad volume over time for seasonality insights
- Note which competitors invest heavily in YouTube vs Search vs Display
- Cross-reference with Meta Ad Library for full-picture competitive intel
