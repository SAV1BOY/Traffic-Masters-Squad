# Spy Tools Index

## Purpose
Catalog of competitive intelligence and ad spy tools for media buyers.

## Free Tools

| Tool | Platforms | Features |
|------|----------|----------|
| Meta Ad Library | Meta (FB, IG) | Active ads by advertiser |
| Google Ads Transparency | Google (Search, Display, YT) | Advertiser ad history |
| TikTok Creative Center | TikTok | Top ads, trends, insights |
| LinkedIn Ads Tab | LinkedIn | Company active ads |
| BuiltWith | Websites | Tech stack identification |
| SimilarWeb (free tier) | Web | Traffic estimates, sources |

## Paid Tools

| Tool | Platforms | Price Range | Best For |
|------|----------|-------------|----------|
| SpyFu | Google | $39-79/mo | Search competitor keywords |
| SEMrush | Google, Display | $129+/mo | Full competitive suite |
| Adbeat | Display | $249+/mo | Display ad intelligence |
| VidTao | YouTube | $97+/mo | YouTube ad database |
| BigSpy | Multi-platform | $9-99/mo | Cross-platform ad spy |
| PowerAdSpy | Multi-platform | $49+/mo | Ad creative database |
| Pathmatics | Multi-platform | Enterprise | Brand-level spend data |
| iSpionage | Google, Bing | $59+/mo | PPC competitor analysis |

## Tool Selection Guide
- **Ecommerce:** SEMrush + Meta Ad Library + TikTok CC
- **B2B SaaS:** SpyFu + LinkedIn Ads Tab + Google Transparency
- **DTC/CPG:** BigSpy + Meta Ad Library + TikTok CC
- **Agency (multi-client):** SEMrush + BigSpy + VidTao
