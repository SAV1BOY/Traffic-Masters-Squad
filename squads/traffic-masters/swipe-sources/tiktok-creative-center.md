# TikTok Creative Center — Mining Guide

## URL
https://ads.tiktok.com/business/creativecenter/

## Key Features

### Top Ads Dashboard
- Filter by region, industry, objective, duration
- See top-performing ads with engagement metrics
- Sort by likes, CTR, or 6-second view rate

### Trend Discovery
- Trending hashtags, songs, and creators
- Filter by industry vertical
- Shows trend trajectory (rising, peaking, declining)

### Creative Tools
- Video templates and editing tools
- Script generator
- Smart creative features

## Mining Process
1. Filter Top Ads by your industry + region
2. Analyze top 20 ads for patterns (hooks, formats, CTAs)
3. Note trending sounds for potential Spark Ads
4. Check keyword insights for ad copy ideas
5. Save winners to swipe file with annotations
6. Review weekly for new trends

## What to Catalog
- Hook style (first 3 seconds)
- Creator type (UGC / professional / animated)
- Sound choice (trending / original / voiceover)
- Text overlay usage
- CTA approach
- Duration sweet spot by industry

## Pro Tips
- 6-second view rate is the best proxy for hook quality
- Cross-reference Top Ads with organic trending content
- Ads with trending sounds get algorithmic boost
- Native-looking content outperforms polished creative
