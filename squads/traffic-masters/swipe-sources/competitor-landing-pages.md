# Competitor Landing Pages — Mining Guide

## Purpose
How to systematically collect and analyze competitor landing pages.

## Collection Methods

### 1. Click Through Ads
- Click competitor ads from Ad Library / Transparency Center
- Record the final URL and any redirects
- Screenshot full page (desktop + mobile)

### 2. Use Wayback Machine
- archive.org to see historical landing page versions
- Track how they evolve their pages over time

### 3. SimilarWeb / SEMrush
- See top landing pages by traffic volume
- Identify which pages receive paid traffic

## Analysis Framework

| Element | What to Note |
|---------|-------------|
| Headline | Formula, specificity, promise |
| Above the fold | Layout, CTA placement, trust signals |
| Social proof | Type, placement, volume |
| Form/CTA | Fields, button text, color, placement |
| Page length | Short vs long, scroll depth |
| Speed | Load time (Google PageSpeed test) |
| Mobile | Responsive design quality |
| Trust | Badges, guarantees, testimonials |

## Organization System
1. Full-page screenshot (desktop + mobile)
2. URL and date captured
3. Analysis notes using framework above
4. Score on 1-5 for each element
5. Tag by funnel type and industry

## Tools
- GoFullPage (Chrome extension for screenshots)
- BuiltWith (identify tech stack)
- PageSpeed Insights (performance data)
- Hotjar/FullStory (if analyzing your own pages)
