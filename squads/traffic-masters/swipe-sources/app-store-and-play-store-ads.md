# App Store & Play Store Ads — Mining Guide

## Purpose
How to find and analyze app install ad creative and ASO strategies.

## Sources

### Apple Search Ads
- View competitors' App Store product pages
- Note screenshot sequence, preview videos, descriptions
- Ad variations visible through search

### Google Play Store
- Search category rankings for competitor apps
- Analyze store listing screenshots, videos, descriptions
- Note A/B test variations in store listings

### Mobile Ad Networks
- Facebook/Instagram app install ads (via Ad Library)
- TikTok app install ads (via Creative Center)
- In-app ad networks (Unity, ironSource, AppLovin)

## What to Catalog

| Element | Analysis |
|---------|----------|
| App icon | Design, color, brand recognition |
| Screenshots | Sequence, messaging, features shown |
| Preview video | Hook, demo flow, duration |
| Description | First 3 lines (visible before expand) |
| Ratings | Score, review volume, sentiment |
| Ad creative | Hook, format, CTA, platform |

## Mining Process
1. Identify top 10 competitor apps
2. Analyze store listings (screenshots, descriptions, ratings)
3. Search for their ads across Meta, TikTok, YouTube
4. Catalog creative approaches and messaging angles
5. Note which apps are spending most (multiple ad variations)

## Pro Tips
- Screenshot sequence tells the value prop story — analyze the order
- Apps with frequent store listing updates are likely A/B testing
- High review volume + recent reviews = active user acquisition
- Cross-reference app ads with store listing for message match
