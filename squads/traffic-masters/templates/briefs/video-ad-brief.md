# Video Ad Brief

> **Type**: Template
> **Category**: briefs
> **Used by tasks**: video-ad-scripting, creative-production, ugc-coordination

## Purpose
Provides a detailed blueprint for producing a single video ad, including script framework, hook concept, production notes, and platform-specific specs.

## Template

**Style**: [talking-head / voiceover-b-roll / screen-recording / animation / UGC / hybrid]

**Placement**: [feed / stories / reels / in-stream / shorts]

### Duration

## Usage Notes
- One brief per video ad. Variations (different hooks on same body) get separate briefs.
- Reference the creative brief for angle and hook strategy alignment.
- Include rough timing; editors adjust in post-production.

## Example
60-second UGC-style Meta feed ad using ADUCATE framework. Talking-head creator opens with bold stat hook, demonstrates product at kitchen counter, shows before/after, ends with discount CTA.
