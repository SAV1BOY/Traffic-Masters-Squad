## Creative Specifications

### Image Ad
| Spec | Requirement |
|------|------------|
| **Aspect Ratio** | 1.91:1 (landscape) / 1:1 (square) |
| **Resolution** | 1200x628px (1.91:1) / 1200x1200px (1:1) |
| **File Format** | PNG, JPG |
| **Max File Size** | 5MB |

### Video Ad
| Spec | Requirement |
|------|------------|
| **Aspect Ratio** | 16:9 / 1:1 |
| **Duration** | 15s max recomendado (max 2min20s) |
| **File Format** | MP4 |
| **Max File Size** | 1GB |

### Carousel Ad
| Spec | Requirement |
|------|------------|
| **Cards** | 2-6 cards |
| **Aspect Ratio** | 1.91:1 ou 1:1 (uniforme) |
| **Headline por card** | Max 70 caracteres |

## Creative Guidelines para X

### Copy Best Practices
- [ ] Tom conversacional — nao pareca um ad, pareca um tweet
- [ ] Usar primeira pessoa ou opiniao forte (funciona melhor no X)
- [ ] Hashtags: maximo 1-2 relevantes (excesso reduz engagement)
- [ ] Provocar discussao — engagement nos replies amplifica reach
- [ ] Hot takes e opinioes contrarian performam bem nesta plataforma

### Visual Best Practices
- [ ] Imagens com pouco ou nenhum texto overlay
- [ ] Video: hook nos primeiros 3 segundos, legendas obrigatorias
- [ ] Memes e formatos nativos superam creative polido
- [ ] Screenshots e threads visuais tem alto engagement organico

### Targeting Notes
- [ ] Keyword targeting baseado em tweets e interesses
- [ ] Follower lookalikes de accounts relevantes
- [ ] Evento/trending topic targeting quando relevante
- [ ] Retargeting de engagers e website visitors
