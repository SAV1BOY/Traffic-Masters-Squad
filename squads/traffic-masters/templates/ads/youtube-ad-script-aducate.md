# YouTube Ad Script - ADUCATE Framework

> **Type**: Template
> **Category**: ads
> **Used by tasks**: video-ad-scripting, youtube-campaign-creation, creative-production
> **Filled by agents**: copywriter-agent, creative-strategist-agent

## Purpose
Provides a structured script template following the ADUCATE framework for YouTube ads, ensuring each section is timed, purposeful, and optimized for viewer retention and conversion.

## Template

### Script Metadata
**Ad name**: [name following naming convention]
**Target duration**: [60s / 90s / 120s]
**Format**: [talking-head / voiceover / hybrid / animation]
**Skippable**: [yes / no]
**Platform placement**: [in-stream / discovery / shorts / bumper]

### A - Aim [0-5 seconds]
**Objective**: Capture attention and stop the skip. Identify the target viewer.
**Visual**: [describe what the viewer sees]
**Script**: "[Exact words spoken - must call out the audience or create pattern interrupt]"
**Text overlay**: [on-screen text if applicable]
**Hook type**: [question / bold claim / stat / callout / visual interrupt]
**Notes**: This is the most critical section. The viewer decides to skip or stay here.

### D - Difficulty [5-15 seconds]
**Objective**: Present the problem or challenge the viewer faces.
**Visual**: [describe what the viewer sees]
**Script**: "[Exact words spoken - agitate the pain point, make it relatable]"
**Text overlay**: [on-screen text if applicable]
**Emotional target**: [frustration / confusion / fear / dissatisfaction]
**Notes**: Use specific language the audience uses to describe their problem.

### U - Understand [15-25 seconds]
**Objective**: Show empathy. Demonstrate you understand their situation.
**Visual**: [describe what the viewer sees]
**Script**: "[Exact words spoken - validate their experience, show you've been there]"
**Text overlay**: [on-screen text if applicable]
**Bridge statement**: [transition from problem to hope]
**Notes**: Build rapport before introducing the solution. Do not pitch yet.

### C - Credibility [25-35 seconds]
**Objective**: Establish authority and trust to deliver the solution.
**Visual**: [describe what the viewer sees - results, credentials, logos]
**Script**: "[Exact words spoken - credentials, results, social proof]"
**Text overlay**: [on-screen text if applicable - stats, numbers, logos]
**Proof elements**: [testimonials / case studies / certifications / media mentions]
**Notes**: Show, don't just tell. Use visuals to reinforce credibility claims.

### A - Action Plan [35-50 seconds]
**Objective**: Present the solution and how it works in simple steps.
**Visual**: [describe what the viewer sees - product demo, process steps]
**Script**: "[Exact words spoken - Step 1, Step 2, Step 3 framework]"
**Text overlay**: [on-screen text if applicable - numbered steps]
**Steps**:
1. [First step the viewer takes]
2. [Second step]
3. [Third step / result they achieve]
**Notes**: Keep it to 3 steps maximum. Make it feel simple and achievable.

### T - Teach [50-70 seconds]
**Objective**: Deliver a quick win or valuable insight that builds reciprocity.
**Visual**: [describe what the viewer sees]
**Script**: "[Exact words spoken - give a useful tip, framework, or insight]"
**Text overlay**: [on-screen text if applicable]
**Value delivered**: [what the viewer learns that they can use immediately]
**Notes**: This section builds goodwill. The viewer feels they got value even without buying.

### E - Exit [70-90 seconds]
**Objective**: Clear call to action with urgency or incentive.
**Visual**: [describe what the viewer sees - CTA screen, offer details]
**Script**: "[Exact words spoken - specific CTA with clear next step]"
**Text overlay**: [CTA text, URL, offer details]
**CTA type**: [click link / visit URL / sign up / use code / call]
**Urgency element**: [limited time / limited spots / bonus expiring]
**End card**: [subscribe button / video link / website link]

### Stack [Optional - for longer ads]
**Objective**: Recap the full value proposition before final CTA.
**Script**: "[Summary of everything they get + bonuses + guarantee]"
**Notes**: Use only for ads over 90 seconds targeting warm or hot audiences.

### Production Notes
**Pacing**: [fast / medium / conversational]
**Music**: [mood and style]
**B-roll needed**: [list of supplementary footage]
**Graphics needed**: [lower thirds, callouts, transitions]
**Captions**: [required for accessibility]

## Usage Notes
- ADUCATE works best for 60-120 second YouTube in-stream ads.
- The Aim section must be strong enough to survive the 5-second skip window.
- Test multiple Aim sections with the same body to find the best hook.

## Example
A SaaS tool ad: Aim calls out "business owners drowning in spreadsheets," Difficulty describes manual reporting pain, Credibility shows "trusted by 5,000+ companies," Action Plan presents 3-step setup, Teach shares a reporting tip, Exit offers a free trial.
