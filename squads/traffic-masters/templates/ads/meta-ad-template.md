# Meta Ad Template

> **Type**: Template
> **Category**: ads
> **Used by tasks**: ad-copywriting, campaign-setup, creative-testing
> **Filled by agents**: copywriter-agent, media-buyer-agent

## Purpose
Provides a structured format for creating Meta (Facebook and Instagram) ad copy and creative specs, ensuring all required elements are prepared with proper variations for testing.

## Template

### Primary Text (3 Variations)
**Variation A (Short - under 125 characters)**:
[Concise, punchy copy that works above the fold without "see more"]

**Variation B (Medium - 125-250 characters)**:
[Expanded copy with hook + value prop + CTA. Gets partially truncated on mobile.]

**Variation C (Long - 250-500 characters)**:
[Full story or argument format. Hook must be strong since most is hidden behind "see more".]

### Headline (3 Variations)
**Headline A**: [Max 40 characters - clear benefit or offer]
**Headline B**: [Max 40 characters - curiosity or question]
**Headline C**: [Max 40 characters - social proof or urgency]

### Description
**Description**: [Max 30 characters - supports headline, often hidden on mobile]

### CTA Button
**Selected CTA**: [Shop Now / Learn More / Sign Up / Get Offer / Download / Book Now / Apply Now / Contact Us]
**Rationale**: [why this CTA matches the funnel stage]

### Creative Specs - Image
**Format**: Single image
**Aspect ratios**: 1:1 (feed), 4:5 (feed optimized), 9:16 (stories/reels)
**Resolution**: Minimum 1080x1080
**File type**: JPG or PNG
**Max file size**: 30MB
**Text on image**: Keep under 20% for best delivery
**Image concept**: [describe the visual]

### Creative Specs - Video
**Format**: Single video
**Aspect ratios**: 1:1, 4:5, 9:16
**Duration**: 15-60 seconds recommended
**Resolution**: Minimum 1080p
**File type**: MP4 or MOV
**Captions**: Required (burned in or SRT)
**Thumbnail**: Custom recommended

### Creative Specs - Carousel
**Number of cards**: 3-10 (recommend 5)
**Card aspect ratio**: 1:1
**Per card**: Image + headline + description
**Flow**: [story arc / benefit stack / product showcase]

### Placement Considerations
**Feed**: Primary text fully visible; use 1:1 or 4:5
**Stories/Reels**: 9:16 required; add safe zones for UI elements
**Right Column**: Desktop only; small format; strong visual needed
**Audience Network**: Consider brand safety settings
**Advantage+ placements**: Provide all aspect ratios for best optimization

### Ad-Level Settings
**URL**: [landing page URL with UTMs]
**URL parameters**: [UTM string]
**Tracking pixel**: [pixel ID]
**Conversion event**: [event to optimize for]

## Usage Notes
- Always create at least 3 primary text and 3 headline variations for Dynamic Creative Testing.
- Test one variable at a time: copy vs. creative vs. audience.
- Tag each ad using taxonomy-tags.md for performance analysis.

## Example
DTC skincare brand: Short primary text highlighting key benefit, medium version with testimonial quote, long version with problem-agitate-solve structure. All paired with UGC video in 4:5 format.
