## Creative Specifications

### Single Image / Video (Snap Ad)
| Spec | Requirement |
|------|------------|
| **Aspect Ratio** | 9:16 (full screen vertical — obrigatorio) |
| **Resolution** | 1080x1920px |
| **Video Duration** | 3-180s (recomendado: 5-6s) |
| **File Format** | MP4, MOV (video) / PNG, JPG (image) |
| **Max File Size** | 1GB (video) / 5MB (image) |

### Story Ad
| Spec | Requirement |
|------|------------|
| **Tiles** | 3-20 Snap Ads em sequencia |
| **Cover Image** | 360x600px (tile no Discover feed) |
| **Cada tile** | Mesmo spec de Snap Ad (9:16) |

### Collection Ad
| Spec | Requirement |
|------|------------|
| **Top Image/Video** | 9:16 hero creative |
| **Product Tiles** | 4 thumbnails abaixo (160x160px) |
| **Catalogo** | Requer product catalog conectado |

## Creative Guidelines para Snapchat

### Visual Best Practices
- [ ] Full screen vertical (9:16) — NUNCA use landscape
- [ ] Primeiros 2 segundos sao tudo — acao imediata
- [ ] Audio-on por default — use som e musica
- [ ] Estilo lo-fi e autentico > producao cinematografica
- [ ] Movimento constante — Snap e rapido, static nao funciona
- [ ] Mostre o produto nos primeiros 2s

### Copy Best Practices
- [ ] Headline ultra-curto (3-5 palavras)
- [ ] CTA claro e unico — swipe up e a acao principal
- [ ] Linguagem Gen Z quando audience permite
- [ ] Sem jargao corporativo — plataforma casual

### Audience Notes
- Demografico core: 13-34 anos (70%+ dos usuarios)
- Alta afinidade com: moda, beleza, snacks, entertainment, apps
- Snapchat Audience Network amplia reach fora do app
- Custom Audiences via Snap Pixel + listas de email/phone

## Checklist Pre-Launch
- [ ] Creative em formato 9:16 vertical full screen
- [ ] Audio incluido e testado (som ligado por default)
- [ ] Headline dentro do limite de 34 caracteres
- [ ] CTA button selecionado e destination URL testada
- [ ] Snap Pixel instalado e eventos configurados
- [ ] Audience targeting definido (age, geo, interests, custom)
- [ ] Budget e bid strategy configurados
- [ ] Minimo 2 variantes criativas para teste
