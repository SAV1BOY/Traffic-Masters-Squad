## Pin Creative Specifications

### Image Pin
| Spec | Requirement |
|------|------------|
| **Aspect Ratio** | 2:3 (recomendado) / 1:1 / 1:2.1 (max) |
| **Resolution** | 1000x1500px (2:3) minimo |
| **File Format** | PNG, JPG |
| **Max File Size** | 20MB |

### Video Pin
| Spec | Requirement |
|------|------------|

## Copy Elements

### Title (Max 100 caracteres)
`{{PIN_TITLE}}`

> Dica: Use keywords de busca do Pinterest. Usuarios buscam inspiracao — titulo deve ser descobrivel.

### Description (Max 500 caracteres)
`{{PIN_DESCRIPTION}}`

> Dica: Inclua 2-3 keywords relevantes naturalmente. Adicione CTA suave. Pinterest e search engine visual.

### Destination URL
`{{LANDING_PAGE_URL}}`

> Dica: Landing page deve ter continuidade visual com o Pin. Desconexao de estilo = bounce alto.

## Creative Guidelines para Pinterest

### Visual Best Practices
- [ ] Imagem vertical (2:3) — ocupa mais espaco no feed
- [ ] Text overlay minimo — maximo 20% da imagem
- [ ] Branding sutil (logo pequeno, nao dominante)
- [ ] Cores vibrantes e alto contraste
- [ ] Lifestyle imagery > product-only shots
- [ ] Mostrar o produto EM USO no contexto real

### Copy Best Practices
- [ ] Keywords de busca no titulo e descricao
- [ ] Tom aspiracional e inspiracional (nao agressivo)
- [ ] CTA suave: "Descubra como", "Veja mais", "Inspire-se"
- [ ] Evitar linguagem de urgencia excessiva (nao e o tom do Pinterest)
