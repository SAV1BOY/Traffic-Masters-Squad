# Creative Testing Sprint Project

## Objective
Intensive creative testing to find new winning ads and angles.

## Timeline: 2 Weeks

### Day 1: Planning
- [ ] Review current creative performance data
- [ ] Identify top-performing elements (hooks, angles, formats)
- [ ] Define 5-10 creative hypotheses
- [ ] Brief creative production team/creators
- [ ] Set testing budget and structure

### Days 2-5: Production
- [ ] Produce 10-15 new creative variations
- [ ] Mix of hook iterations, angle tests, and format experiments
- [ ] Include at least 2 net-new concepts
- [ ] QA all creative for compliance and quality
- [ ] Score using ad-scoring-rubric.md

### Days 6-10: Testing
- [ ] Launch all creatives in testing structure
- [ ] Equal budget per creative ($50-100/day each)
- [ ] Daily monitoring using decision rules
- [ ] Kill clear losers after minimum data threshold
- [ ] Note early trends and signals

### Days 11-14: Analysis
- [ ] Compile results for all tested creative
- [ ] Declare winners (CPA < target, 50+ conversions)
- [ ] Document learnings for each test
- [ ] Create iteration plan for winners
- [ ] Update creatives-registry.yaml

## Creative Mix Target

| Category | Count | Purpose |
|----------|-------|---------|
| Hook variations (of winner) | 5 | Find better entry point |
| Angle tests | 3 | Discover new messaging |
| Format tests | 2 | Find best format |
| Net-new concepts | 2 | Explore uncharted territory |

## Success Criteria
- Test 10+ creatives
- Find 2+ new winners (CPA at or below target)
- Win rate: 20%+ (2 of 10)
- 5+ documented learnings
- Creative pipeline extended by 4+ weeks
