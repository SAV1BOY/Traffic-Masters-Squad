# Client Onboarding Project

## Objective
Successfully onboard a new client with tracking, strategy, and first campaigns launched.

## Timeline: 2-3 Weeks

### Week 1: Discovery & Setup
- [ ] Kickoff call (goals, KPIs, budget, history)
- [ ] Access to ad accounts, analytics, CRM
- [ ] Account audit (if existing accounts)
- [ ] Avatar/ICP research and documentation
- [ ] Competitor analysis
- [ ] Tracking audit and fix (pixels, CAPI, UTMs)

### Week 2: Strategy & Build
- [ ] Traffic strategy document
- [ ] Campaign structure design
- [ ] Creative brief and first creative batch
- [ ] Landing page review and recommendations
- [ ] Naming conventions applied
- [ ] Audience definitions and targeting plan

### Week 3: Launch & Monitor
- [ ] Pre-launch QA (tracking, creative, compliance)
- [ ] Campaign launch
- [ ] 48-hour monitoring period
- [ ] First performance report
- [ ] Guardrails and alert setup
- [ ] Reporting cadence established

## Deliverables
- Traffic strategy document
- Account structure with naming conventions
- Tracking implementation verified
- First campaigns live
- Reporting dashboard configured
- Weekly scorecard template set up

## Success Criteria
- All tracking verified and functioning
- Campaigns exited learning phase
- First week data collected and reviewed
- Client communication cadence established
- All registries populated with initial data
