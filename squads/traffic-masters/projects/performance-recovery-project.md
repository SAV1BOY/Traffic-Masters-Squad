# Project Template: Performance Recovery

## Project Overview

A structured project for diagnosing and recovering from a significant performance decline in an ad account. Performance declines can be caused by creative fatigue, algorithm changes, tracking issues, competitive shifts, seasonal effects, or market changes. This template provides a systematic approach to diagnosis, stabilization, and recovery.

---

## Objectives

1. Diagnose the root cause(s) of performance decline
2. Stabilize the account (stop the bleeding)
3. Implement targeted fixes for identified causes
4. Recover performance to previous baseline (or establish a new sustainable baseline)
5. Build safeguards to prevent recurrence

---

## Timeline

**Total Duration:** 4-6 weeks

| Phase | Duration | Milestone |
|---|---|---|
| Phase 1: Emergency Assessment | Days 1-3 | Root cause(s) identified |
| Phase 2: Stabilization | Days 3-7 | Bleeding stopped, account stable |
| Phase 3: Recovery Actions | Days 7-21 | Targeted fixes implemented |
| Phase 4: Performance Rebuild | Days 21-35 | Performance trending toward recovery |
| Phase 5: Safeguards and Documentation | Days 35-42 | Prevention measures in place |

## Phases and Deliverables

### Phase 1: Emergency Assessment (Days 1-3)

**Deliverables:**
- [ ] Performance decline quantified:
  - When did the decline start? (exact date if possible)
  - How severe is the decline? (% change in CPA, ROAS, volume)
  - Which platforms are affected? (all or specific)
  - Which campaigns are affected? (all or specific)
  - Which metrics declined first? (leading indicators)
- [ ] Diagnostic checklist completed:

  **Tracking Issues (Check First)**
  - [ ] Pixel still firing correctly?
  - [ ] CAPI events still sending?
  - [ ] Conversion events unchanged in platform?
  - [ ] No website changes that broke tracking?
  - [ ] GA4 data consistent with platform data?
  - [ ] No recent GTM container changes?

  **Platform/Algorithm Issues**
  - [ ] Any platform notifications or policy warnings?
  - [ ] Recent platform updates or algorithm changes?
  - [ ] Account spending limits changed?
  - [ ] Payment method issues?
  - [ ] Ad disapprovals?
  - [ ] Learning phase re-entered?

  **Creative Issues**
  - [ ] Creative fatigue? (declining CTR, rising frequency)
  - [ ] Creative disapprovals?
  - [ ] Recently changed or removed winning creative?

  **Audience Issues**
  - [ ] Audience saturation? (frequency above 5x/week)
  - [ ] Audience changes (lists expired, audiences modified)?
  - [ ] Competitive entry (new advertisers in auction)?

  **External Issues**
  - [ ] Seasonal decline? (compare to industry data)
  - [ ] Competitive changes? (new offers, new entrants)
  - [ ] PR/brand issues? (negative press, social media issues)
  - [ ] Product/pricing changes?
  - [ ] Website/landing page changes? (conversion rate drop)
  - [ ] Market conditions? (economic shifts, regulatory changes)

- [ ] Root cause hypothesis documented:
  - Primary cause identified (or top 2-3 candidates)
  - Supporting evidence for each hypothesis
  - Recommended stabilization actions
- [ ] Client communication:
  - Decline acknowledged and contextualized
  - Diagnostic findings shared
  - Recovery plan timeline communicated
  - Expectations set (recovery takes time, not instant)

**Quality Gate:** Root cause(s) identified with supporting evidence. Stabilization plan approved. Client informed and aligned.

### Phase 2: Stabilization (Days 3-7)

**Deliverables:**
- [ ] Immediate stabilization actions (based on root cause):

  **If tracking issue:**
  - Fix tracking immediately (priority one)
  - Verify fix with test conversions
  - Assess data gap period
  - Re-enable optimization once tracking is confirmed

  **If creative fatigue:**
  - Pause highest-frequency creative
  - Launch any available backup creative
  - Activate emergency creative production
  - Do NOT change audiences or bids simultaneously

  **If audience saturation:**
  - Expand targeting (broader demographics, new interests, broader lookalikes)
  - Reduce budget to match sustainable audience reach
  - Open new audience segments

  **If algorithm/learning phase:**
  - Consolidate campaigns (fewer ad sets with larger budgets)
  - Avoid making additional changes for 7 days
  - Ensure 50+ conversions/week/ad set threshold is met
  - Consider moving to a higher-volume conversion event temporarily

  **If external factors:**
  - Adjust targets to reflect new market reality
  - Modify offer/pricing if competitive positioning has changed
  - Reduce budget if market conditions are temporarily unfavorable
  - Shift budget to channels less affected by the external factor

  **If landing page/website issue:**
  - Revert recent website changes (if possible)
  - Check page load speed (especially mobile)
  - Test conversion flow for broken elements
  - Set up temporary alternative landing page if needed

- [ ] Budget adjusted to sustainable level during recovery
- [ ] Monitoring increased to 2x daily during stabilization
- [ ] Daily stabilization updates to client

**Quality Gate:** Account no longer deteriorating. Spend at a sustainable level. Root cause being addressed. No additional negative changes occurring.

### Phase 3: Recovery Actions (Days 7-21)

**Deliverables:**
- [ ] Root cause resolution:
  - Tracking: fully fixed and verified (allow 7 days for algorithm to recalibrate)
  - Creative: 5-10 new creative assets launched and testing
  - Audience: new audience strategy implemented
  - Algorithm: campaign consolidation completed, learning phase progressing
  - External: strategy adjusted for new market conditions
- [ ] Creative refresh cycle:
  - Emergency creative sprint (5-10 new assets in Week 1)
  - Test across multiple angles (do not just iterate on the old winning concept)
  - Identify 2-3 new winning creative within 2 weeks
  - Begin building creative pipeline for sustained recovery
- [ ] Campaign structure review:
  - Remove underperforming campaigns (reduce auction competition with yourself)
  - Consolidate into fewer, larger campaigns
  - Reset bid strategies if needed (start with "Maximize Conversions" then transition to target CPA/ROAS)
  - Simplify account to give algorithm clearest possible signals
- [ ] Testing program:
  - Test new audiences (2-3 new approaches)
  - Test new creative angles (aligned with new creative sprint)
  - Test new landing pages (if landing page was a factor)
  - Test new offers (if competitive positioning shifted)
- [ ] Weekly recovery progress reports

**Quality Gate:** Performance stabilized and trending upward. New winning creative identified. Account structure simplified and optimized. Weekly improvement visible in key metrics.

### Phase 4: Performance Rebuild (Days 21-35)

**Deliverables:**
- [ ] Scale winning elements:
  - Increase budget on winning creative/audience combinations
  - Follow standard scaling protocol (20-30% every 3-5 days)
  - Monitor marginal CPA during scaling
- [ ] Rebuild full-funnel:
  - Prospecting campaigns performing and scaling
  - Retargeting audiences rebuilt from new traffic
  - Conversion optimization reestablished with fresh data
- [ ] Performance tracking:
  - Compare current performance to pre-decline baseline
  - Track recovery trajectory (weekly CPA/ROAS trend)
  - Identify remaining gaps and areas for improvement
- [ ] Cross-channel rebalancing:
  - Reallocate budget based on post-recovery channel performance
  - Channels that were less affected may have shifted in importance
  - Update channel mix to reflect new performance data
- [ ] Client reporting:
  - Recovery trajectory shared
  - New baseline established (may differ from pre-decline)
  - Forward strategy presented

**Quality Gate:** Performance recovered to within 80-100% of pre-decline baseline (or new sustainable baseline established). Scaling underway. Client aligned on new performance level.

### Phase 5: Safeguards and Documentation (Days 35-42)

**Deliverables:**
- [ ] Root cause analysis document:
  - What happened (timeline of decline)
  - Why it happened (root cause analysis)
  - What was done (stabilization and recovery actions)
  - Results (recovery metrics)
  - What could have been done differently
- [ ] Prevention safeguards implemented:
  - **Monitoring alerts:** Automated alerts for CPA/ROAS threshold breaches
  - **Creative pipeline:** Ongoing production cadence to prevent fatigue
  - **Tracking monitoring:** Weekly tracking verification checks
  - **Performance benchmarks:** Documented benchmarks with trigger thresholds
  - **Change management:** Protocol for documenting and coordinating website/campaign changes
- [ ] Early warning system established:

  | Metric | Warning Threshold | Action |
  |---|---|---|
  | CPA | 20% above 7-day average | Investigate within 24 hours |
  | CTR | 15% below 7-day average | Check creative fatigue |
  | Conversion rate | 20% below 7-day average | Check landing page and tracking |
  | Frequency | Above 4x in 7 days | Plan creative refresh |
  | CPM | 30% above 7-day average | Check competitive landscape |

- [ ] Playbook updated with recovery learnings
- [ ] Team retrospective completed

**Quality Gate:** All safeguards in place. Early warning system active. Documentation complete. Team debriefed on learnings.

## Risk Register

| Risk | Likelihood | Impact | Mitigation |
|---|---|---|---|
| Root cause is external (market shift, not fixable) | Medium | High | Adjust targets and strategy for new reality |
| Multiple simultaneous root causes | Medium | High | Address systematically; fix one variable at a time |
| Client loses confidence during recovery | High | High | Proactive communication; set realistic timelines |
| Recovery takes longer than expected | Medium | Medium | Set expectations for 4-6 weeks; communicate progress |
| Fixes introduce new problems | Medium | Medium | Change one variable at a time; monitor impact of each change |
| Pre-decline performance was unsustainably high | Medium | High | Establish new sustainable baseline; educate client on realistic targets |
