# Platform Expansion Project

## Objective
Add a new advertising platform to the media mix.

## Timeline: 4-6 Weeks

### Week 1: Research & Setup
- [ ] Evaluate platform fit (audience, format, cost)
- [ ] Set up ad account and billing
- [ ] Install tracking pixel/tag
- [ ] Configure conversion events
- [ ] Set up server-side tracking if available
- [ ] Research platform best practices and norms

### Week 2: Creative Adaptation
- [ ] Adapt winning concepts to platform-native format
- [ ] Create platform-specific creative (not just reformat)
- [ ] Write copy following platform conventions
- [ ] Set up audience targeting strategy
- [ ] Apply naming conventions

### Week 3-4: Testing
- [ ] Launch test campaigns ($20-50/day)
- [ ] Test 3-5 creative variations
- [ ] Test 2-3 audience segments
- [ ] Monitor daily and optimize
- [ ] Compare performance to established platforms

### Week 5-6: Validation & Scale
- [ ] Evaluate test results vs benchmarks
- [ ] If positive: increase budget gradually
- [ ] Integrate into cross-platform reporting
- [ ] Establish platform-specific guardrails
- [ ] Document platform-specific learnings

## Platform Evaluation Criteria

| Criteria | Weight | Score (1-5) |
|----------|--------|-------------|
| Audience overlap with ICP | 25% | |
| Cost efficiency (CPM/CPA) | 25% | |
| Creative format capability | 20% | |
| Measurement/tracking quality | 15% | |
| Scaling potential | 15% | |

## Go/No-Go Decision (Week 4)
- **Go:** CPA within 1.5x of primary platform + clear path to target
- **No-Go:** CPA >2x primary platform with no optimization levers remaining
- **Extend Test:** Promising signals but insufficient data

## Success Criteria
- Platform validated as viable (CPA within target range)
- Minimum viable budget committed for ongoing operation
- Tracking and reporting integrated with existing systems
- Platform-specific best practices documented
