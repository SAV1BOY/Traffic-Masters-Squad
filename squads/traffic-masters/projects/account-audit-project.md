# Account Audit Project

## Objective
Comprehensive audit of an ad account to identify issues, opportunities, and optimization priorities.

## Timeline: 1 Week

### Day 1-2: Data Collection
- [ ] Export last 90 days of campaign data
- [ ] Pull search term reports (Google)
- [ ] Export audience and creative performance data
- [ ] Run tracking QA (pixels, events, CAPI)
- [ ] Check account health and policy status

### Day 3-4: Analysis
- [ ] Campaign structure assessment
- [ ] Audience overlap analysis
- [ ] Creative performance tiering
- [ ] Budget efficiency analysis
- [ ] Tracking and attribution review
- [ ] Compliance review
- [ ] Competitive intelligence snapshot

### Day 5: Report & Recommendations
- [ ] Compile audit findings
- [ ] Prioritize issues (critical, important, nice-to-have)
- [ ] Create action plan with timeline
- [ ] Present audit results to stakeholders

## Audit Deliverables
- Account health scorecard (using account-health-rubric.md)
- Issue list with severity and priority
- Opportunity list with estimated impact
- 90-day optimization roadmap
- Quick wins (implementable within 48 hours)

## Scoring Framework
Use `scripts/audit-checklist-runner.md` for standardized scoring.

## Success Criteria
- All critical issues identified
- Action plan with clear priorities
- Quick wins identified for immediate implementation
- 90-day roadmap agreed upon with stakeholders
- Baseline metrics established for measuring improvement
