# Full Funnel Build Project

## Objective
Build a complete TOFU > MOFU > BOFU > Retention advertising funnel.

## Timeline: 4-6 Weeks

### Week 1-2: Foundation
- [ ] Define funnel stages and objectives
- [ ] Create audience definitions for each stage
- [ ] Set up exclusion lists between stages
- [ ] Configure tracking for stage-specific events
- [ ] Build campaign structure per funnel stage
- [ ] Develop creative for each stage

### Week 3: TOFU Launch
- [ ] Launch prospecting campaigns (broad + interest + lookalike)
- [ ] Educational/value-first creative
- [ ] Optimize for reach and traffic initially
- [ ] Build pixel audiences for MOFU retargeting

### Week 4: MOFU + BOFU Activation
- [ ] Activate MOFU retargeting (site visitors, engagers)
- [ ] Activate BOFU retargeting (ATC, leads, high-intent)
- [ ] Testimonial and proof creative for consideration
- [ ] Urgency and offer creative for conversion

### Week 5-6: Optimization + Retention
- [ ] Optimize budget allocation across funnel stages
- [ ] Launch retention campaigns (customers)
- [ ] Cross-sell and upsell creative
- [ ] Full funnel performance review

## Funnel Budget Distribution
| Stage | Budget % | Objective |
|-------|---------|-----------|
| TOFU | 60% | Build audiences and awareness |
| MOFU | 20% | Nurture consideration |
| BOFU | 15% | Drive conversions |
| Retention | 5% | Increase LTV |

## Success Criteria
- All funnel stages active and optimized
- Positive ROAS at funnel level (not per stage)
- Retargeting audiences growing week over week
- Clear attribution path from TOFU to conversion
