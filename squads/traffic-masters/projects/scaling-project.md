# Scaling Project

## Objective
Scale ad spend 2-5x while maintaining acceptable CPA/ROAS.

## Prerequisites
- Validated winning creative (3+ weeks at target CPA)
- Proven audience segments
- Tracking fully operational
- Creative pipeline established

## Timeline: 4-8 Weeks

### Phase 1: Audit & Plan (Week 1)
- [ ] Audit current performance and identify ceiling
- [ ] Calculate marginal CPA curve
- [ ] Set scaling targets and guardrails
- [ ] Plan creative pipeline for scale
- [ ] Identify audience expansion opportunities

### Phase 2: Vertical Scale (Weeks 2-3)
- [ ] Increase budgets 20% every 3-5 days on winners
- [ ] Monitor CPA after each increase
- [ ] Hold when marginal CPA exceeds 1.3x target
- [ ] Document scaling curve data

### Phase 3: Horizontal Scale (Weeks 3-5)
- [ ] Duplicate winners to new audiences
- [ ] Expand lookalike percentages
- [ ] Test new interest segments
- [ ] Launch creative iterations for fresh audiences

### Phase 4: Platform Scale (Weeks 5-8)
- [ ] Adapt winning concepts for new platforms
- [ ] Launch test campaigns on secondary platforms
- [ ] Validate performance before committing budget
- [ ] Optimize cross-platform budget allocation

## Guardrails During Scaling
| Metric | Acceptable | Warning | Pause |
|--------|-----------|---------|-------|
| CPA vs target | <1.2x | 1.2-1.5x | >1.5x |
| Frequency (7d) | <2.5 | 2.5-4.0 | >4.0 |
| Creative age | <3 weeks | 3-5 weeks | >5 weeks |

## Success Criteria
- Spend increased [X]x from baseline
- CPA within 1.3x of pre-scale target
- At least 2 platforms contributing
- Creative pipeline sustaining scale
