# Project Template: Channel Expansion

## Project Overview

Expanding paid advertising to a new channel (e.g., adding TikTok when currently running only Meta and Google, or adding YouTube, LinkedIn, Pinterest, programmatic, etc.). This project covers platform evaluation, setup, creative adaptation, launch, and validation of the new channel's incremental contribution.

---

## Objectives

1. Evaluate and select the optimal new channel based on audience fit and strategic value
2. Set up the new platform with proper tracking and account structure
3. Adapt or create creative assets for the new channel
4. Launch and optimize campaigns to achieve defined performance targets
5. Validate the channel's incremental contribution to overall business growth

---

## Phases and Deliverables

### Phase 1: Channel Evaluation (Days 1-5)

**Deliverables:**
- [ ] Channel evaluation matrix completed:
  | Criteria | Channel A | Channel B | Channel C |
  |---|---|---|---|
  | Audience overlap with target | | | |
  | Audience size (addressable) | | | |
  | Creative format fit | | | |
  | Average CPM in category | | | |
  | Competitor presence | | | |
  | Measurement capabilities | | | |
  | Strategic value (differentiation) | | | |
  | Internal expertise available | | | |
  | Setup complexity | | | |
- [ ] Competitive presence assessed on candidate channels
- [ ] Cost benchmarks researched (CPM, CPC, CPA for the vertical)
- [ ] Audience research completed (does the target audience use this platform?)
- [ ] Creative requirements documented (formats, lengths, style requirements)
- [ ] Minimum viable budget calculated (sufficient for learning phase)
- [ ] Channel recommendation presented and approved

**Quality Gate:** Channel selected based on data-driven evaluation. Budget approved. Team aligned on strategic rationale.

### Phase 2: Setup and Preparation (Days 5-12)

**Deliverables:**
- [ ] Ad account created and configured
- [ ] Business verification completed (if required)
- [ ] Pixel/tag installed and verified
- [ ] Server-side tracking implemented (CAPI/Events API)
- [ ] Conversion events configured and tested
- [ ] Customer list audiences uploaded (for seeding and exclusion)
- [ ] Platform-native creative produced:
  - Minimum 5 creative assets designed for the specific platform
  - Formats match platform requirements (aspect ratios, lengths, style)
  - Ad copy adapted for platform tone and conventions
  - Creative tested against platform content policies
- [ ] Campaign structure planned:
  - Campaign objectives selected
  - Audience strategy defined (broad, interest, lookalike, custom)
  - Budget allocation planned
  - Bidding strategy selected
- [ ] Measurement plan established:
  - Platform attribution settings configured
  - Cross-channel attribution approach defined
  - Incrementality test designed (if budget allows)
  - UTM parameters configured for the new channel

**Quality Gate:** Account fully set up. Tracking verified with test conversions. Minimum 5 native creative assets ready. Campaign structure approved.

### Phase 3: Launch and Learning (Days 12-26)

**Deliverables:**
- [ ] Campaigns launched with planned structure and budget
- [ ] Learning phase monitoring:
  - Day 1: ads delivering, no disapprovals, tracking confirmed
  - Day 3: initial performance data assessed
  - Day 7: learning phase status checked (exiting learning or still learning)
  - Day 14: initial performance assessment vs. benchmarks
- [ ] Creative performance tracked:
  - Which creative formats and styles perform on this platform?
  - Which hooks and angles resonate?
  - Platform-specific engagement metrics (saves, shares, comments)
- [ ] Audience testing:
  - Performance by audience segment
  - Identification of best-performing targeting approach
- [ ] Weekly progress reports during learning phase
- [ ] Initial insights documented (what is different about this platform vs. existing channels?)

**Quality Gate:** Campaigns have exited learning phase. Minimum viable data collected (100+ clicks, 20+ conversions). Initial performance within 150% of target CPA.

### Phase 4: Optimization (Days 26-40)

**Deliverables:**
- [ ] Creative optimization:
  - Underperforming creative paused
  - New creative iterations based on platform-specific learnings
  - Format optimization (which creative types work on this platform)
- [ ] Audience optimization:
  - Winning audiences identified and expanded
  - Losing audiences paused or reduced
  - New audience tests launched based on platform-specific signals
- [ ] Budget optimization:
  - Budget shifted to winning campaigns/ad sets
  - Budget pacing adjusted based on performance patterns
  - Day-of-week and time-of-day analysis (if sufficient data)
- [ ] Bidding optimization:
  - Bid strategy adjusted based on performance data
  - Target CPA/ROAS refined based on actual results
- [ ] Cross-channel impact assessment:
  - Is the new channel cannibalizing existing channels or driving incremental growth?
  - Correlation between new channel spend and branded search volume
  - Total blended ROAS trend since channel launch

**Quality Gate:** CPA/ROAS trending toward target. At least 2 winning creative assets identified. Cross-channel impact directionally positive.

### Phase 5: Validation and Integration (Days 40-56)

**Deliverables:**
- [ ] Incrementality assessment completed:
  - Geographic holdout test results (if conducted)
  - Cross-channel correlation analysis
  - Blended ROAS comparison (before and after channel addition)
  - New customer acquisition contribution from new channel
- [ ] Channel integration plan:
  - New channel role in the overall media plan (prospecting, consideration, retargeting)
  - Budget allocation across all channels (including new)
  - Creative production schedule including new channel requirements
  - Reporting integration (new channel in standard reports)
- [ ] Long-term management plan:
  - Ongoing optimization cadence for the new channel
  - Creative refresh schedule specific to the platform
  - Platform-specific best practices documented
  - Team training needs for ongoing management
- [ ] Final channel expansion report:
  - Performance summary vs. objectives
  - Investment summary
  - Key learnings
  - Recommendation: scale, maintain, or discontinue
  - Next steps

**Quality Gate:** Incrementality directionally proven. Channel demonstrates positive contribution to overall program. Integration plan approved. Management plan established.

## Risk Register

| Risk | Likelihood | Impact | Mitigation |
|---|---|---|---|
| New platform underperforms expectations | Medium | Medium | Set realistic expectations; allow full learning period |
| Creative does not translate to new platform | Medium | High | Produce platform-native creative, not repurposed |
| Cross-channel cannibalization | Medium | High | Run incrementality test; monitor blended metrics |
| Insufficient budget for learning phase | Low | High | Confirm minimum viable budget before launch |
| Team lacks platform expertise | Medium | Medium | Engage platform specialist; use platform resources |
| Platform policy issues (ad disapprovals) | Medium | Medium | Pre-review creative; study platform policies |
| Measurement/attribution conflicts | High | Medium | Establish measurement methodology before launch |
