# Technical Depth Scale

## Purpose
Calibrate technical detail level based on audience.

## Scale Levels

### Level 1 — Executive / Non-Technical
- Metrics: Revenue, ROAS, total spend, profit
- Language: Business outcomes only, no platform jargon
- Detail: High-level summary, visual charts preferred
- Example: "Paid ads generated $120K in revenue on $30K spend (4x return)"

### Level 2 — Marketing Manager
- Metrics: CPA, CTR, CVR, budget pacing, top-line platform data
- Language: Standard marketing terms, minimal platform specifics
- Detail: Platform comparison, funnel performance, key actions
- Example: "Meta CPA improved 18% to $24 after launching new UGC batch"

### Level 3 — Media Buyer / Specialist
- Metrics: CPM, frequency, hook rate, ad set level data, marginal CPA
- Language: Full platform terminology, technical optimization language
- Detail: Campaign structure, bid strategies, audience details
- Example: "CBO campaign ABO outperformed by 22% at ad set level; LAL 1% seed from purchasers 180d"

### Level 4 — Technical / Data Team
- Metrics: Event match quality, pixel health, attribution models, APIs
- Language: Technical implementation, tracking architecture
- Detail: Pixel setup, CAPI configuration, UTM parameters, data flows
- Example: "CAPI event match quality at 7.2/10; EMQ for Purchase improved after adding external_id"

## Calibration Guide

| Audience | Level | Report Type |
|----------|-------|-------------|
| CEO / Founder | 1 | Monthly executive summary |
| VP Marketing | 1-2 | Weekly scorecard |
| Marketing Manager | 2-3 | Weekly detailed report |
| Media Buyer | 3 | Daily optimization notes |
| Dev / Data Team | 4 | Technical documentation |
