# Metrics Language Guide

## Purpose
How to talk about metrics clearly and consistently.

## Formatting Rules
- Percentages: "23%" not "twenty-three percent"
- Currency: "$1,234" with comma separators
- Large numbers: "$1.2M" not "$1,200,000"
- Ratios: "3.2x ROAS" not "320% return"
- Changes: "+15%" or "-8%" with direction sign

## Describing Performance

### Positive Performance
- "CTR improved from 1.2% to 1.8% (+50%)"
- "CPA decreased 22% week-over-week"
- "ROAS exceeded target by 0.5x"

### Negative Performance
- "CPA increased from $25 to $32 (+28%)"
- "CTR declined 15% versus prior week"
- "ROAS fell below the 3.0x guardrail"

### Neutral/Context
- "CPM remained stable at $12.40"
- "Performance was within expected range"
- "Insufficient data to draw conclusions (n=45)"

## Comparison Language

| Context | Good | Avoid |
|---------|------|-------|
| Week-over-week | "CPA improved 15% WoW" | "CPA got better" |
| Vs target | "ROAS 3.2x vs 3.0x target" | "ROAS is good" |
| Vs benchmark | "CTR 2.1% vs 1.5% industry avg" | "CTR is above average" |

## Confidence Qualifiers
- "The data strongly suggests..." (high confidence)
- "Early results indicate..." (moderate confidence)
- "We need more data before concluding..." (low confidence)

## Common Mistakes
1. Reporting relative change without absolute values
2. Cherry-picking favorable timeframes
3. Comparing metrics without context (seasonality, budget changes)
4. Using vanity metrics instead of business metrics
