# Traffic Masters Squad

> **O sistema operacional de paid traffic mais completo do MMOS.**
> 16 agentes | 100+ frameworks | 130+ checklists | Full-funnel acquisition engine.

## O que e este Squad?

O Traffic Masters Squad e um sistema de agentes de IA especializados em **Paid Traffic, Customer Acquisition, Creative Strategy, Tracking, Optimization e Scaling**. Cada agente possui frameworks proprietarios, checklists de qualidade e templates de output — todos interconectados via `config.yaml`.

## Filosofia

1. **Data-first** — Decisoes baseadas em dados, nao em achismo
2. **Test-before-scale** — Validar antes de escalar (Graduation Testing)
3. **Creative-is-targeting** — Na era do broad, o criativo E o targeting
4. **Track-everything** — Se nao mede, nao otimiza
5. **Fix-the-funnel** — O problema pode estar apos o clique

## Como Funciona

1. **Task** chega ao `traffic-chief`
2. `config.yaml` roteia para os **agents** corretos
3. Agents aplicam **frameworks** relevantes
4. Output passa por **checklists** de qualidade
5. Resultado e gerado usando **templates**
6. Dados sao registrados em **data/registries/**
7. Learnings alimentam **data/metrics/**

## Quick Start

1. Leia `ARCHITECTURE.md` para entender o sistema
2. Consulte `config.yaml` para ver o roteamento de tarefas
3. Escolha uma task em `tasks/` e siga o workflow correspondente
4. Use os checklists para garantir qualidade
