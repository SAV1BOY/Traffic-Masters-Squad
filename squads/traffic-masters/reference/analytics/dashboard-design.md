# Dashboard Design Reference
> **Category**: Analytics and Reporting
> **Last Updated**: 2026-03

## Dashboard Design Principles
1. **Answer a question**: Every dashboard should answer a specific business question
2. **Audience-aware**: Executive dashboards differ from analyst dashboards
3. **Hierarchy**: Most important metrics at the top, details below
4. **Comparison**: Always show vs. target, vs. prior period, or vs. benchmark
5. **Actionable**: Every metric should connect to a possible action

## Recommended Dashboard Types

### Executive Overview (Weekly)
- Total spend, revenue, ROAS, CPA (blended)
- Trend line: 4-week rolling performance
- Channel mix: % spend and % revenue by platform
- Top 3 wins and top 3 concerns (text annotations)

### Media Buyer Operational (Daily)
- Campaign-level: spend, CPA, ROAS, frequency, CTR
- Ad set level: delivery, audience saturation, learning phase status
- Creative level: CTR, hook rate, CPA, fatigue indicators
- Budget pacing: daily spend vs target

### Creative Performance
- Creative leaderboard: ranked by primary KPI
- Hook rate (video 3-second views / impressions)
- Creative fatigue chart: performance over time
- Format comparison: static vs video vs carousel

### Funnel Dashboard
- TOFU: reach, CPM, video views, engagement rate
- MOFU: CTR, lead volume, cost per lead
- BOFU: conversions, CPA, ROAS, conversion rate

## Tool Recommendations
- Google Looker Studio (free, good GA4/Google Ads integration)
- Supermetrics (data connectors for multi-platform dashboards)
- Platform native dashboards (Meta Ads Manager, Google Ads)

## Key Takeaways
- Less is more — do not overcrowd dashboards with every metric
- Use color coding: green (on target), yellow (warning), red (off target)
- Include date range selector and comparison period
- Automate data refresh — manual dashboards get abandoned
- Review and update dashboard design quarterly
