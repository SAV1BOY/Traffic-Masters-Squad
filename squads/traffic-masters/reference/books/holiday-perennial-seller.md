# Perennial Seller
> **Author**: Ryan Holiday
> **Year**: 2017
> **Category**: Evergreen Marketing & Long-Term Strategy

## Key Concepts
- Create marketing assets that work for years, not just launch day
- The difference between a flash campaign and a perennial engine
- Evergreen content and ads that compound in value over time
- Platform-building over campaign-thinking
- The long game: consistent effort beats one-time viral moments

## Core Frameworks
1. **Evergreen Asset Creation**: Build content and campaigns that remain relevant
2. **Compounding Marketing**: Small, consistent efforts accumulate massive results
3. **Platform vs Campaign**: Build an audience platform, not just individual campaigns
4. **Word of Mouth Engine**: Create things worth talking about
5. **The Long Game**: Patience and persistence over quick wins

## How It Applies to Traffic Squad
- Evergreen campaigns provide baseline revenue between launches
- Some ad creatives and angles can run for months without fatigue
- Building owned audiences (email, community) is a perennial strategy
- Not everything should be a sprint — some campaigns should run indefinitely

## Key Takeaways for the Squad
1. Build evergreen campaigns alongside launch/seasonal campaigns
2. Some creatives become "workhorse" ads — let winners run
3. Audience building is a long-term compounding investment
4. Not every campaign needs urgency — some need consistency
5. The best traffic strategies combine bursts (launches) with steady-state (evergreen)
6. Document and systematize what works so it can run perpetually
