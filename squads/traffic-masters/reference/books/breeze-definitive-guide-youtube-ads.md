# The Definitive Guide to YouTube Ads
> **Author**: Todd Breeze (Tommie Powers)
> **Year**: 2025
> **Category**: YouTube Advertising (Updated)

## Key Concepts
- Updated YouTube ad strategies for the current algorithm and ad formats
- Shorts ads as a new placement opportunity alongside traditional in-stream
- Performance Max integration with YouTube placements
- Advanced audience signals and AI-powered targeting
- YouTube as both brand-building and direct-response channel

## Core Frameworks
1. **Full YouTube Funnel**: Shorts → In-stream → Discovery → Action campaigns
2. **Creative for Algorithm**: Signals that YouTube's AI uses to match ads to viewers
3. **Audience Signals**: First-party data, custom segments, affinity + intent layering
4. **Measurement Framework**: View-through conversions, engaged views, brand lift studies
5. **Budget Architecture**: Split between prospecting and retargeting on YouTube

## How It Applies to Traffic Squad
- Modernizes YouTube strategy beyond basic in-stream ads
- Shorts ads provide new TOFU opportunities at lower CPMs
- Performance Max YouTube placements need specific creative consideration
- Cross-platform retargeting using YouTube viewer audiences

## Key Takeaways for the Squad
1. YouTube Shorts ads are high-reach, low-CPM opportunities for awareness
2. Combine in-stream with Shorts for full YouTube funnel coverage
3. First-party audience signals dramatically improve YouTube targeting
4. Creative needs to be native to each YouTube format (do not repurpose blindly)
5. View-through attribution window matters — set it correctly
6. YouTube builds consideration that converts on other platforms
