# App Install Traffic Playbook
> **Industry**: Mobile Apps, Games, Utilities
> **Last Updated**: 2026-03

## Key Characteristics
- Install is top-of-funnel; in-app events are the real conversions
- iOS 14+ (ATT) significantly impacted tracking and targeting
- SKAdNetwork and Privacy Sandbox changing attribution models
- User acquisition cost varies dramatically by app category

## Recommended Channel Mix
- **Meta Ads** (30-40%): App install campaigns, AEO, VO optimization
- **Google Ads** (30-40%): App campaigns (UAC/ACe), Search, YouTube
- **TikTok** (10-15%): High engagement for gaming and consumer apps
- **Apple Search Ads** (10-15%): High-intent App Store search placements
- **Ad Networks** (5-10%): ironSource, Unity, AppLovin for gaming

## Campaign Optimization Events
- Install → Registration → Key Activation Event → Purchase/Subscription
- Optimize for downstream events, not just installs (AEO = App Event Optimization)
- Value Optimization (VO): optimize for predicted LTV of installer

## Key Metrics and Benchmarks
- CPI (Cost Per Install): $0.50-5.00 (varies by category and platform)
- D1 Retention: 25-40% (day 1 retention rate)
- D7 Retention: 10-20%
- ROAS D7: varies by monetization model
- LTV:CPI target: 3:1+

## Creative Best Practices
- Show the app in action — screen recordings, UI demonstrations
- Focus on the core value moment (the "aha" experience)
- Video ads outperform static for app installs
- UGC-style "reaction" videos perform well on TikTok
- Playable ads for games (interactive ad format)

## Key Takeaways
- Optimize for post-install events, not just installs — install volume without quality is waste
- iOS tracking requires SKAN compliance and probabilistic modeling
- Creative refresh every 7-14 days due to fast fatigue in app install campaigns
- Retention is the true measure of UA quality — track cohort retention
- Deep linking from ads to specific app content improves conversion
