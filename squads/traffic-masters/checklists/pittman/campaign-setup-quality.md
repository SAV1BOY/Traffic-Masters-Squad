# Campaign Setup Quality Gate (Pittman Standards)

> Quality gate for campaign setup following Molly Pittman's standards. Must pass before any campaign goes live on any paid traffic platform.

## Section 1: Campaign Objective Alignment
- [ ] Campaign objective matches the business goal (do not use Traffic objective for conversion goals)
- [ ] Conversion event is correctly selected and matches the actual desired action
- [ ] Attribution window is set appropriately (7-day click, 1-day view for most campaigns)
- [ ] Campaign buying type is correct (Auction vs. Reservation)

## Section 2: Audience Configuration
- [ ] Audiences align with the traffic temperature strategy (cold/warm/hot separation)
- [ ] Custom audiences are verified as populated and recently updated
- [ ] Lookalike audiences are built from quality seed lists with sufficient size
- [ ] Interest targeting uses validated interests from avatar research
- [ ] Exclusion audiences are applied to prevent audience overlap and wasted spend
- [ ] Geographic, age, and language settings match the avatar documentation

## Section 3: Budget & Bidding
- [ ] Daily or lifetime budget is set according to the documented budget plan
- [ ] Bid strategy aligns with campaign maturity (cost cap for new, bid cap for scaled)
- [ ] Budget is sufficient for the platform to exit learning phase (50 conversions/week rule)
- [ ] Spend limits are set at the account or campaign level as a safety net

## Section 4: Ad Creative & Copy
- [ ] All ad creatives from the Ad Grid are uploaded with correct dimensions and specs
- [ ] Ad copy matches the avatar-hook combination from the Ad Grid cell
- [ ] Headlines are under character limits and frontload the key message
- [ ] CTAs are clear, specific, and match the offer (Learn More, Sign Up, Shop Now)
- [ ] URL parameters (UTMs) are appended for proper attribution tracking

## Section 5: Technical Verification
- [ ] Pixel/CAPI is firing on all funnel pages (landing page, thank you page, purchase page)
- [ ] Conversion events are tested with real test transactions or the platform's test tool
- [ ] Landing page URL is correct, live, and mobile-responsive
- [ ] No broken links in the ad or on the landing page
- [ ] Ad preview looks correct on all placements (Feed, Stories, Reels, Audience Network)

## Section 6: Pre-Launch Review
- [ ] Campaign naming convention follows team taxonomy
- [ ] Ad set and ad names are descriptive and include test variables
- [ ] Schedule is set correctly (start date, end date if applicable, dayparting if used)
- [ ] A teammate or manager has reviewed the campaign setup before publishing

## Approval
- **Minimum pass rate**: 21/25 items (84%)
- **Reviewer**: pittman-traffic-strategist
- **Escalation**: If technical verification items fail, do not launch; fix tracking issues first and resubmit
