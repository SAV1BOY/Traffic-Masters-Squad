# Dynamic Creative Optimization Quality Gate
> **Type**: Quality Gate
> **Domain**: Advanced — Creative
> **Reviewed by**: Media Buyer / Designer

## Purpose
Garante que campanhas com dynamic creative optimization (DCO) estejam configuradas corretamente, com elementos criativos de qualidade e regras de personalizacao bem definidas, maximizando a relevancia e performance dos anuncios.

## Checklist

### Estrategia de DCO
- [ ] Objetivo da DCO claramente definido (personalizacao por audiencia, teste de combinacoes, localizacao)
- [ ] Hipotese documentada sobre quais elementos devem variar e por que
- [ ] Tipo de DCO selecionado (rule-based vs algorithmic) com justificativa
- [ ] Volume de impressoes esperado suficiente para otimizacao automatica
- [ ] KPIs de sucesso definidos para avaliar performance da DCO vs controle

### Elementos Criativos
- [ ] Todas as variacoes de imagem/video atendem as specs da plataforma
- [ ] Variacoes de headline testam angulos genuinamente diferentes
- [ ] Variacoes de description/body copy complementam os headlines
- [ ] CTAs variados e alinhados com diferentes estagios do funnel
- [ ] Numero de combinacoes possivel e gerenciavel (nao excessivo)
- [ ] Cada combinacao possivel revisada para garantir coerencia visual e textual

### Configuracao Tecnica
- [ ] Dynamic creative habilitado corretamente no ad set
- [ ] Elementos marcados como fixos vs dinamicos conforme estrategia
- [ ] Regras de personalizacao por audiencia configuradas quando aplicavel
- [ ] Feed de produtos conectado e atualizado (para catalog ads)
- [ ] Fallback creative definido caso a personalizacao falhe
- [ ] Destination URLs corretas para cada variacao de criativo

### Catalogo e Feed (quando aplicavel)
- [ ] Product feed atualizado com informacoes corretas (preco, disponibilidade, imagem)
- [ ] Product sets segmentados por categoria, faixa de preco ou relevancia
- [ ] Imagens do catalogo em alta qualidade e formato correto
- [ ] Titles e descriptions dos produtos otimizados para ads
- [ ] Deep links para PDPs corretos e funcionais

### Monitoramento e Otimizacao
- [ ] Breakdown de performance por combinacao de elementos configurado
- [ ] Elementos com baixa performance identificados e substituidos na cadencia definida
- [ ] Frequencia por combinacao monitorada para evitar ad fatigue
- [ ] Performance comparada com static ads para validar valor da DCO
- [ ] Refresh de criativos planejado conforme lifecycle documentado

## Pass/Fail Criteria
Todos os itens de elementos criativos e configuracao tecnica devem ser aprovados. Cada combinacao possivel deve ser coerente — combinacoes nonsensicais invalidam o checklist.

## If Failed
Pausar a campanha de DCO. Revisar e corrigir elementos problematicos. Validar todas as combinacoes antes de reativar.
