# Kaizen Kreative Process Quality Gate

> Quality gate for Charley T. Burns' Kaizen Kreative continuous improvement process for ad creative. Must pass before each creative iteration cycle is considered complete.

## Section 1: Data Collection Before Iteration
- [ ] Previous creative performance data is exported and analyzed (CTR, CPC, CPA, thumbstop ratio, hold rate)
- [ ] Top-performing creatives are identified with at least 1,000 impressions per variant
- [ ] Underperforming creatives are identified and root cause is hypothesized
- [ ] Creative fatigue signals are checked (rising frequency, declining CTR over time)
- [ ] Audience-level creative performance is cross-referenced (which creative works for which audience)

## Section 2: Incremental Improvement Identification
- [ ] Winning elements are isolated (which hook, visual, CTA, or format drove results)
- [ ] One specific improvement hypothesis is documented per new creative iteration
- [ ] The improvement is incremental, not a complete overhaul (Kaizen principle)
- [ ] New iteration preserves the winning core while changing one variable
- [ ] Improvement hypothesis is falsifiable with a clear pass/fail metric

## Section 3: Creative Production Standards
- [ ] New creative variations are produced at platform-native quality (not over-produced)
- [ ] Video creatives have captions/subtitles for sound-off viewing
- [ ] Static creatives have a clear visual hierarchy (headline, visual, CTA)
- [ ] UGC-style content is authentic and not overly scripted
- [ ] All creatives meet platform specs (dimensions, file size, duration limits)

## Section 4: Testing Protocol
- [ ] New iterations are tested against the current control (champion vs. challenger)
- [ ] Test budget is sufficient to reach statistical significance within 5-7 days
- [ ] Only one variable changes per iteration to maintain test validity
- [ ] A/B test structure isolates the creative variable from audience and placement variables
- [ ] Test duration is predefined (minimum 3 days, maximum 7 days before decision)

## Section 5: Learning Documentation
- [ ] Results of each iteration cycle are documented in the creative log
- [ ] Winning insights are added to the team's creative playbook
- [ ] Losing iterations are analyzed for learnings (not just discarded)
- [ ] Creative performance trends are tracked over time (not just point-in-time snapshots)
- [ ] Next iteration cycle is scheduled before the current one concludes

## Approval
- **Minimum pass rate**: 20/25 items (80%)
- **Reviewer**: burns-performance-strategist
- **Escalation**: If data collection is incomplete or testing protocol is violated, invalidate the cycle and restart with proper controls
