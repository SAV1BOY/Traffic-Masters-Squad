# Creative Lab Testing Quality Gate

> Quality gate for Charley T. Burns' Creative Lab testing framework. Must pass before creative test results are declared valid and winners are scaled.

## Section 1: Test Hypothesis Design
- [ ] Each creative test has a written hypothesis ("If we change X, we expect Y because Z")
- [ ] The variable being tested is clearly isolated (hook, format, thumbnail, CTA, copy length)
- [ ] The hypothesis is based on prior data or a documented strategic rationale
- [ ] Success criteria are defined before the test launches (improvement in CTR, CPA, ROAS)
- [ ] Test naming convention identifies the variable, date, and iteration number

## Section 2: Test Structure
- [ ] Control (current champion) is included in every test round
- [ ] Challenger variants number between 2-5 per test round (not too few, not too many)
- [ ] Each variant is placed in an identical ad set to control for audience variables
- [ ] Budget is split evenly across variants (or managed via platform's A/B test tool)
- [ ] Placements are consistent across variants (all Advantage+, or all manual with identical selections)

## Section 3: Creative Formats in Rotation
- [ ] Static image creatives are tested (single image, carousel)
- [ ] Video creatives are tested (short-form 15s, mid-form 30-60s)
- [ ] UGC-style creatives are included in the test rotation
- [ ] Text-heavy vs. visual-heavy variants are compared
- [ ] Platform-native formats are prioritized (Reels, Stories dimensions)

## Section 4: Data Collection Standards
- [ ] Tests run for a minimum of 3 days before any decisions are made
- [ ] Each variant accumulates at least 1,000 impressions before evaluation
- [ ] For conversion-optimized campaigns, each variant needs at least 10-15 conversions
- [ ] Cost metrics are compared at the ad level, not aggregated at the ad set level
- [ ] External factors are noted (holidays, competitor activity, platform outages)

## Section 5: Winner Declaration & Next Steps
- [ ] Winner is declared based on the predefined success metric, not gut feeling
- [ ] Statistical confidence is assessed (even if informally, the margin must be meaningful)
- [ ] Winning creative is promoted to the main campaign as the new control
- [ ] Losing creatives are archived with notes on why they underperformed
- [ ] Next Creative Lab test round is planned based on insights from the current round
- [ ] All results are logged in the Creative Lab tracker for longitudinal analysis

## Approval
- **Minimum pass rate**: 20/25 items (80%)
- **Reviewer**: burns-performance-strategist
- **Escalation**: If test structure is compromised (uncontrolled variables, insufficient data), void the results and redesign the test
