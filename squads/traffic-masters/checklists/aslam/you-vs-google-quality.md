# You vs Google Philosophy Quality Gate

> Quality gate for Kasim Aslam's "You vs Google" philosophy of maintaining advertiser control over Google's automation. Must pass before any Google Ads account structure is finalized.

## Section 1: Manual Control Foundations
- [ ] Account structure is designed by the advertiser, not defaulted to Google's recommendations
- [ ] Google Ads rep recommendations are evaluated critically, not blindly accepted
- [ ] Auto-apply suggestions are reviewed and disabled where they conflict with strategy
- [ ] Optimization score is treated as directional input, not as a mandate to follow
- [ ] Smart campaigns and fully automated setups are avoided for accounts with sufficient data

## Section 2: Bidding Control
- [ ] Bid strategy starts with Manual CPC to establish baseline data (per Aslam's methodology)
- [ ] Automated bidding is only introduced after sufficient conversion data exists (30+ conversions)
- [ ] Target CPA or Target ROAS values are set based on actual business economics, not platform suggestions
- [ ] Bid adjustments for device, location, time, and audience are set manually based on performance data
- [ ] Maximum CPC limits are applied when using automated bidding to prevent bid runaway

## Section 3: Audience & Targeting Control
- [ ] Keyword match types are deliberately chosen (not all broad match by default)
- [ ] Negative keyword lists are comprehensive and regularly updated
- [ ] Audience targeting uses observation mode before targeting mode (data collection first)
- [ ] Placement exclusions are applied for Display and YouTube campaigns
- [ ] Search partner and Display Network opt-ins are conscious decisions, not defaults

## Section 4: Budget & Spend Control
- [ ] Daily budgets are set with understanding of Google's 2x daily overspend allowance
- [ ] Shared budgets are used only when strategically appropriate (not as a default)
- [ ] Budget allocation across campaigns follows strategic priorities, not equal distribution
- [ ] Spend pacing is monitored daily to prevent month-end budget exhaustion
- [ ] Account-level spend alerts are configured for anomaly detection

## Section 5: Data Ownership & Transparency
- [ ] All conversion tracking is owned by the advertiser (not reliant solely on Google's modeling)
- [ ] Search term reports are reviewed weekly to identify wasted spend and new opportunities
- [ ] Auction insights are monitored to understand competitive dynamics
- [ ] Google's "insights" and "recommendations" tabs are used for intelligence, not as action items
- [ ] Third-party analytics (GA4, CRM) validate Google's reported conversions
- [ ] Change history is audited regularly to catch unauthorized auto-applied changes

## Approval
- **Minimum pass rate**: 19/23 items (83%)
- **Reviewer**: aslam-google-ads-strategist
- **Escalation**: If Google's automation has been applied without strategic review, audit and revert changes before optimizing further
