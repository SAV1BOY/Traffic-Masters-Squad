# 4 Passos para Aprender Trafego Quality Gate

> Quality gate for Pedro Sobral's 4 Passos (4 Steps) framework for learning and implementing traffic management. Must pass before a traffic manager is considered competent to manage campaigns independently.

## Section 1: Passo 1 - Entender a Ferramenta (Understand the Tool)
- [ ] Platform interface is navigated confidently (campaign creation, reporting, settings)
- [ ] All campaign objectives are understood with correct use cases for each
- [ ] Audience creation tools are mastered (custom audiences, lookalikes, interest targeting)
- [ ] Pixel/tracking setup can be completed independently (installation, event configuration, testing)
- [ ] Billing, account limits, and policy basics are understood
- [ ] Platform updates and changes are monitored through official channels

## Section 2: Passo 2 - Entender a Estrategia (Understand the Strategy)
- [ ] Traffic temperature concept is understood and applied (cold, warm, hot)
- [ ] Funnel stages are mapped to campaign objectives (awareness > consideration > conversion)
- [ ] Budget allocation strategy is understood (how to distribute across funnel stages)
- [ ] Creative strategy fundamentals are grasped (hook, story, offer framework)
- [ ] Audience segmentation strategy is applied correctly (exclusions, layering, testing)
- [ ] The relationship between offer quality and traffic success is understood

## Section 3: Passo 3 - Praticar (Practice)
- [ ] At least 3 campaigns have been set up and launched end-to-end
- [ ] Campaign optimization has been performed with documented decision-making
- [ ] A/B testing has been conducted with proper variable isolation
- [ ] Performance reports have been created and shared with stakeholders
- [ ] Budget management has been practiced (pacing, reallocation, scaling)
- [ ] At least one campaign has been taken from launch through optimization to scaling

## Section 4: Passo 4 - Analisar e Melhorar (Analyze and Improve)
- [ ] Performance analysis goes beyond surface metrics (understanding why, not just what)
- [ ] Funnel drop-off analysis is performed to identify conversion bottlenecks
- [ ] Audience quality analysis identifies which segments drive the best results
- [ ] Creative performance analysis informs future creative production
- [ ] Competitive awareness includes monitoring competitor ads and strategies
- [ ] Continuous learning plan is documented (courses, communities, testing schedule)

## Section 5: Competency Validation
- [ ] Traffic manager can explain their strategy to a non-technical stakeholder
- [ ] Traffic manager can diagnose a underperforming campaign and propose solutions
- [ ] Traffic manager understands the business model and how traffic impacts revenue
- [ ] Traffic manager can set up tracking independently without assistance
- [ ] Traffic manager maintains organized documentation of all campaigns and learnings

## Approval
- **Minimum pass rate**: 20/25 items (80%)
- **Reviewer**: sobral-br-traffic-strategist
- **Escalation**: If Passo 1 (tool understanding) or Passo 2 (strategy understanding) fail, additional training is required before managing live campaigns with real budget
