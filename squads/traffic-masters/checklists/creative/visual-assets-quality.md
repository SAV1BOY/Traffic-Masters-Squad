# Visual Asset Specifications Quality Gate

> Quality gate for visual asset quality and platform compliance. Must pass before images or graphics are uploaded to any advertising platform.

## Section 1: Resolution and Dimensions
- [ ] All images meet minimum resolution requirements per platform (1080px on shortest side)
- [ ] Feed images are provided in required ratios: 1:1 (1080x1080), 4:5 (1080x1350), 1.91:1 (1200x628)
- [ ] Stories/Reels/Shorts images are provided in 9:16 (1080x1920) with safe zones clear
- [ ] Display banner sizes are provided: 300x250, 728x90, 160x600, 320x50, 300x600
- [ ] Images are not upscaled from lower resolution sources (no visible pixelation or blur)

## Section 2: File Format and Size
- [ ] Static images are delivered in JPG (for photos) or PNG (for graphics with transparency)
- [ ] File sizes are optimized: under 30MB for social platforms, under 150KB for display banners
- [ ] Color profile is sRGB (not CMYK, which is for print)
- [ ] No compression artifacts are visible (banding, blocky areas, or color loss)
- [ ] Layered source files (PSD, AI, Figma) are archived for future iterations

## Section 3: Visual Composition
- [ ] Primary subject/product is clearly visible and centered (or intentionally positioned using rule of thirds)
- [ ] Key visual elements are not obscured by platform UI overlays (profile picture, CTA button, text areas)
- [ ] Text overlay is minimal and legible at mobile viewing size (minimum 16pt equivalent)
- [ ] Color contrast between text and background meets WCAG AA accessibility standards (4.5:1 ratio)
- [ ] White space is used effectively; the image is not cluttered or visually overwhelming

## Section 4: Brand Consistency
- [ ] Logo is placed according to brand guidelines (size, position, clear space)
- [ ] Brand colors are accurately represented (hex values match the style guide)
- [ ] Typography matches the approved brand fonts (or closest web-safe alternative)
- [ ] Visual style is consistent across all ad variants within the same campaign
- [ ] Photography style matches the brand aesthetic (lifestyle, product-focused, flat lay, etc.)

## Section 5: Platform-Specific Requirements
- [ ] Meta: images avoid excessive text overlay (though the 20% rule is no longer enforced, less text performs better)
- [ ] Google Display: images do not contain misleading interactive elements (fake play buttons, close buttons)
- [ ] LinkedIn: images are professional and appropriate for B2B audiences
- [ ] TikTok: images (for Spark Ads thumbnails) feel native and not overly polished
- [ ] All images have been previewed in each platform's ad preview tool at actual serving size

## Approval
- **Minimum pass rate**: 20/24 items (83%)
- **Reviewer**: creative-strategist-agent
- **Escalation**: Resolution failures, brand guideline violations, or missing platform sizes are hard blocks; assets must be revised before upload
