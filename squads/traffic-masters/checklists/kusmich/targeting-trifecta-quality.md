# Targeting Trifecta Methodology Quality Gate

> Quality gate for Nicholas Kusmich's Targeting Trifecta approach to Facebook audience targeting. Must pass before audience targeting is finalized for any campaign.

## Section 1: Trifecta Layer 1 - Interest Targeting
- [ ] Interest categories are derived from avatar research (not guesswork)
- [ ] Interests include specific authors, tools, publications, and thought leaders the avatar follows
- [ ] Interest audiences are large enough to sustain the campaign budget (minimum 500K per interest group)
- [ ] Interests are layered (stacked) to narrow audiences to the most relevant segments
- [ ] At least 5 distinct interest-based audiences are prepared for testing
- [ ] Broad interest categories are avoided in favor of specific, niche interests

## Section 2: Trifecta Layer 2 - Lookalike Audiences
- [ ] Lookalike seed audiences are built from the highest-value customer segments
- [ ] Seed audience size meets platform minimum (typically 100+ source users, ideally 1,000+)
- [ ] Multiple lookalike percentages are created for testing (1%, 1-2%, 2-5%)
- [ ] Lookalike source data is recent (updated within the last 90 days)
- [ ] Separate lookalikes are built from distinct value events (purchasers, leads, top spenders)

## Section 3: Trifecta Layer 3 - Custom Audiences
- [ ] Website visitor custom audiences are segmented by page/intent (not just "all visitors")
- [ ] Video viewer custom audiences are built at multiple view thresholds (25%, 50%, 75%, 95%)
- [ ] Engagement custom audiences include page/profile engagers and ad engagers
- [ ] Customer list custom audiences are uploaded with high match rates (above 50%)
- [ ] Custom audience recency windows are set strategically (shorter for hot, longer for warm)

## Section 4: Trifecta Integration
- [ ] All three layers are represented in the campaign structure (not just one approach)
- [ ] Each layer targets a different stage of the customer journey
- [ ] Exclusion audiences prevent overlap between the three layers
- [ ] Budget is allocated across layers based on performance potential (proven layers get more)
- [ ] Cross-layer performance comparison is built into the reporting structure

## Section 5: Targeting Validation & Iteration
- [ ] Initial audience performance is evaluated after 1,000 impressions and 48 hours
- [ ] Underperforming audiences are paused or refined, not left running indefinitely
- [ ] Top-performing audiences are expanded (broader lookalikes, additional interests)
- [ ] Audience saturation is monitored (frequency > 3 in 7 days signals saturation)
- [ ] Targeting Trifecta is refreshed monthly with new interests, updated lookalikes, and fresh custom audiences

## Approval
- **Minimum pass rate**: 19/24 items (79%)
- **Reviewer**: kusmich-social-advertising-strategist
- **Escalation**: If any Trifecta layer is missing entirely, the targeting strategy is incomplete; add the missing layer before launch
