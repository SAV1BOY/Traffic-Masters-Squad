# Landing Page Quality
> **Type**: Quality Gate
> **Domain**: Conversion Optimization
> **Reviewed by**: Funnel Architect

## Purpose
Ensures every landing page is optimized for conversion, speed, and message congruence before receiving paid traffic. A poor landing page nullifies even the best ad creative.

## Checklist

### Headline Match
- [ ] Landing page headline directly reflects the ad copy promise
- [ ] Visitor immediately understands they are in the right place
- [ ] Keyword or phrase consistency between ad and headline is maintained
- [ ] No bait-and-switch between ad messaging and page content
- [ ] Subheadline expands on the main headline with specificity

### Above-the-Fold CTA
- [ ] A clear call-to-action is visible without scrolling on all devices
- [ ] CTA button text is action-oriented and specific (not generic "Submit")
- [ ] CTA button color contrasts with the page background
- [ ] Only one primary CTA is presented above the fold
- [ ] Supporting microcopy near the CTA reduces friction

### Mobile-First Design
- [ ] Page is designed mobile-first and tested on multiple devices
- [ ] Touch targets are minimum 44px and easy to tap
- [ ] Text is readable without pinching or zooming
- [ ] Images scale correctly and do not break layout on mobile
- [ ] Forms use appropriate mobile input types (tel, email, number)

### Page Speed
- [ ] Page loads in under 3 seconds on mobile connections
- [ ] Images are optimized, compressed, and properly sized
- [ ] Unnecessary third-party scripts are removed or deferred
- [ ] Core Web Vitals scores are in the green range
- [ ] CDN is configured for fast global delivery

### Proof Stack
- [ ] Testimonials with names, photos, or details are present
- [ ] Quantitative proof (numbers, percentages, results) is displayed
- [ ] Logos, badges, or certifications build credibility
- [ ] Case studies or before-and-after examples are included where relevant
- [ ] Proof is placed near the CTA to reduce hesitation

### Form Optimization
- [ ] Only essential fields are included (minimal friction)
- [ ] Field labels are clear and positioned for easy scanning
- [ ] Form validation provides real-time helpful error messages
- [ ] Auto-fill is enabled for standard fields
- [ ] Multi-step forms show progress indicators

### Privacy and Compliance
- [ ] Privacy policy link is visible and accessible
- [ ] Terms of service are linked where required
- [ ] Cookie consent banner is implemented for applicable regions
- [ ] Data collection practices are transparent to the user

### Tracking Implementation
- [ ] Pixel fires correctly on page load
- [ ] Conversion events fire on form submission or purchase
- [ ] UTM parameters are captured and stored
- [ ] Heatmap or session recording tools are active for optimization insights

### Ad Scent Congruence
- [ ] Visual style of the page matches the ad creative
- [ ] Color scheme is consistent between ad and landing page
- [ ] Imagery used in ads appears on or is consistent with the landing page
- [ ] The emotional tone of the page matches the ad promise

## Pass/Fail Criteria
A minimum of 8 out of 9 sections must pass. Page Speed and Tracking Implementation are mandatory sections that cannot be the failing item.

## If Failed
Document specific failures with screenshots and device information. Prioritize fixes by impact on conversion. Retest on all target devices before resubmitting.
