# Google Keyword Research and Match Type Strategy Quality Gate

> Quality gate for keyword research, selection, and match type strategy. Must pass before keywords are uploaded to Google Ads campaigns.

## Section 1: Keyword Research Completeness
- [ ] Keyword research covers all product/service categories in the campaign scope
- [ ] Primary keyword tools used are documented (Google Keyword Planner, SEMrush, Ahrefs, Search Console)
- [ ] Competitor keyword analysis has been completed for at least 3 direct competitors
- [ ] Long-tail keywords (3+ words) represent at least 40% of the keyword list
- [ ] Search volume data is filtered by the correct geographic market and language

## Section 2: Keyword Categorization
- [ ] Keywords are categorized by intent: informational, navigational, commercial, transactional
- [ ] Branded keywords are separated from non-branded keywords into distinct campaigns
- [ ] Keywords are grouped into tightly themed ad groups (max 15-20 keywords per ad group)
- [ ] Each ad group has a clear primary keyword that drives the ad copy and landing page
- [ ] Keyword grouping avoids mixing head terms and long-tail terms in the same ad group

## Section 3: Match Type Strategy
- [ ] Match type selection is documented with strategic rationale (Broad, Phrase, Exact for each keyword)
- [ ] Exact match is used for high-intent, high-volume keywords with proven conversion history
- [ ] Phrase match is used for keywords where word order and intent matter
- [ ] Broad match is used only with Smart Bidding strategies (Target CPA, Target ROAS, Maximize Conversions)
- [ ] No single ad group mixes all three match types for the same keyword (to preserve data clarity)
- [ ] Modified broad match has been migrated to phrase match (deprecated since 2021)

## Section 4: Negative Keywords
- [ ] A shared negative keyword list is created at the account or campaign level
- [ ] Negative keywords include obvious irrelevant terms: "free", "jobs", "salary", "DIY" (unless relevant)
- [ ] Competitor brand names are added as negatives (unless running a competitor conquest strategy)
- [ ] Cross-campaign negatives prevent keyword cannibalization between campaigns
- [ ] A process is documented for weekly search term review and negative keyword additions

## Section 5: Keyword Performance Projections
- [ ] Estimated CPC, impressions, and clicks are documented from Keyword Planner
- [ ] Budget sufficiency is validated: daily budget supports top impression share for priority keywords
- [ ] Expected Quality Score factors are assessed: landing page relevance, expected CTR, ad relevance
- [ ] Low Quality Score keywords (below 5) have an improvement plan (ad copy revision, landing page update)
- [ ] Keyword list has been reviewed by a second team member before upload

## Approval
- **Minimum pass rate**: 19/23 items (83%)
- **Reviewer**: media-buyer-agent
- **Escalation**: Missing negative keyword strategy or mixed match types without justification require revision before launch
