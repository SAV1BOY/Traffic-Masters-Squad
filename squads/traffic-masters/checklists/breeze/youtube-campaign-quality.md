# YouTube Campaign Setup Quality Gate

> Quality gate for Tom Breeze's YouTube campaign setup standards. Must pass before any YouTube campaign goes live in Google Ads.

## Section 1: Campaign Configuration
- [ ] Campaign type is correct (Video campaign with appropriate sub-type)
- [ ] Campaign goal aligns with business objective (Sales, Leads, Website Traffic, Awareness)
- [ ] Bid strategy is appropriate for the campaign phase (Manual CPV for testing, tCPA/Max Conversions for scaling)
- [ ] Budget type (daily vs. total) and amount are set per the Master Ad Plan
- [ ] Start and end dates are configured correctly (or set to run indefinitely with monitoring)

## Section 2: Ad Group Targeting
- [ ] Ad groups are organized by a single targeting theme (one audience type per ad group)
- [ ] Custom intent audiences use relevant keywords with sufficient search volume
- [ ] Affinity/in-market audiences are validated against the target avatar
- [ ] Placement targeting excludes irrelevant channels and controversial content
- [ ] Topic targeting is used sparingly and only when contextually relevant
- [ ] Demographics (age, gender, parental status, household income) are refined based on avatar data
- [ ] Content exclusion settings block ads from appearing alongside inappropriate content

## Section 3: Video Ad Setup
- [ ] Video ads are uploaded to YouTube (unlisted or public, not private)
- [ ] Ad format is selected correctly (skippable in-stream, non-skippable, bumper, in-feed, Shorts)
- [ ] Companion banner is uploaded (300x60px for desktop display)
- [ ] Final URL points to the correct landing page with UTM parameters
- [ ] Display URL is clean and branded
- [ ] CTA overlay text is concise and action-oriented
- [ ] Headline (for in-feed ads) is compelling and under character limits

## Section 4: Tracking & Attribution
- [ ] Google Ads conversion tracking tag is verified on all conversion pages
- [ ] Enhanced conversions are enabled for improved attribution accuracy
- [ ] Google Analytics 4 is linked to the Google Ads account
- [ ] YouTube channel is linked to the Google Ads account for earned metrics
- [ ] View-through conversion window matches the sales cycle length
- [ ] Cross-device tracking is enabled

## Section 5: Quality Assurance
- [ ] Ad preview is reviewed across all devices (desktop, mobile, tablet, TV)
- [ ] Landing page loads correctly from the ad click-through on mobile and desktop
- [ ] All links in the ad and landing page are functional (no 404s)
- [ ] Video plays correctly with and without sound
- [ ] Captions/subtitles display properly on the video

## Approval
- **Minimum pass rate**: 22/25 items (88%)
- **Reviewer**: breeze-youtube-strategist
- **Escalation**: If tracking and attribution items fail, do not launch; fix all measurement issues before spending any budget
