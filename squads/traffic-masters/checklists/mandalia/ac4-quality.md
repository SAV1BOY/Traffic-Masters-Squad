# AC-4 Framework Quality Gate

> Quality gate for Depesh Mandalia's AC-4 (Ad Creative 4-Part) framework. Must pass before any ad creative is approved for launch.

## Section 1: Part 1 - Attention (The Hook)
- [ ] The first 3 seconds of video (or the dominant visual in static) commands attention
- [ ] Hook disrupts the scroll pattern with an unexpected or emotionally charged element
- [ ] Hook is relevant to the target audience (not clickbait that attracts the wrong people)
- [ ] At least 3 different hook variations are prepared for testing
- [ ] Hook directly addresses the audience's primary pain point or desire

## Section 2: Part 2 - Connection (The Story)
- [ ] The ad establishes an emotional connection after the hook (empathy, shared experience)
- [ ] Storytelling element makes the viewer feel understood ("I've been there too")
- [ ] The narrative bridges from the viewer's current state to the desired future state
- [ ] Specific details are used instead of generic claims (numbers, timelines, situations)
- [ ] Connection element matches the audience's awareness level (problem-aware vs. solution-aware)

## Section 3: Part 3 - Credibility (The Proof)
- [ ] Social proof is included (testimonials, reviews, case studies, user count)
- [ ] Authority signals are present (credentials, media mentions, partnerships, awards)
- [ ] Specificity replaces vagueness ("847 customers" not "hundreds of customers")
- [ ] Before/after or transformation evidence is shown
- [ ] Credibility elements are verifiable and authentic (no fabricated claims)

## Section 4: Part 4 - Action (The CTA)
- [ ] CTA is clear and tells the viewer exactly what to do next
- [ ] CTA creates a reason to act now (urgency, scarcity, limited availability)
- [ ] CTA matches the traffic temperature (soft CTA for cold, hard CTA for hot)
- [ ] The transition from credibility to CTA feels natural, not jarring
- [ ] CTA language matches the offer (Learn More for content, Shop Now for products, Sign Up for leads)

## Section 5: AC-4 Integration Quality
- [ ] All four parts flow seamlessly in sequence (Attention > Connection > Credibility > Action)
- [ ] Total ad duration is appropriate for the platform and placement (15-60s for feed, 6-15s for Stories)
- [ ] The AC-4 structure is adapted per format (video script, static carousel, long-form copy)
- [ ] Each part's relative weight is appropriate (hook is concise, story has room to breathe)
- [ ] The complete ad has been reviewed as a whole, not just individual parts in isolation

## Approval
- **Minimum pass rate**: 19/24 items (79%)
- **Reviewer**: mandalia-scaling-strategist
- **Escalation**: If Attention or Action parts are weak, prioritize reworking those before launch as they have the highest impact on performance
