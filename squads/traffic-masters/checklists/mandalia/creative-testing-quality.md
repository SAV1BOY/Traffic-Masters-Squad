# Creative Testing Methodology Quality Gate

> Quality gate for Depesh Mandalia's structured creative testing methodology. Must pass before test results are used to make scaling or kill decisions.

## Section 1: Test Design
- [ ] A single variable is isolated per test (hook, body, CTA, format, thumbnail, or offer)
- [ ] Test hypothesis is written before launch ("Changing X will improve Y because Z")
- [ ] Control creative (current best performer) is included in every test batch
- [ ] Challenger creatives number 3-5 per test round
- [ ] All test creatives maintain the same offer and landing page to isolate creative impact

## Section 2: Test Environment Controls
- [ ] All creatives run in the same ad set to ensure identical audience delivery
- [ ] Budget is equally distributed across all test variants
- [ ] Placements are consistent across all variants (same Advantage+ or manual selections)
- [ ] Campaign objective is identical for all variants within the test
- [ ] Geographic targeting and scheduling are identical across all test variants

## Section 3: Data Thresholds
- [ ] Minimum 1,000 impressions per creative before any evaluation begins
- [ ] Minimum 10 conversions per creative for conversion-optimized campaigns
- [ ] Test runs for at least 72 hours before declaring winners
- [ ] Maximum test duration is 7 days to prevent creative fatigue from distorting results
- [ ] Cost per result variance between variants exceeds 20% to declare a meaningful winner

## Section 4: Analysis Protocol
- [ ] Primary metric for winner declaration is defined pre-launch (CPA, ROAS, or CPL)
- [ ] Secondary metrics are analyzed for diagnostic insight (CTR, hook rate, hold rate, CPC)
- [ ] Performance is analyzed by placement to identify placement-specific winners
- [ ] Demographic breakdowns are reviewed to identify audience-specific creative preferences
- [ ] Day-over-day trends within the test are analyzed (improving, stable, or declining)

## Section 5: Post-Test Actions
- [ ] Winner is promoted to the main campaign structure at the winning budget level
- [ ] Winner becomes the new control for the next test cycle
- [ ] Losing creatives are archived with documented reasons for underperformance
- [ ] Key learnings are extracted and added to the creative insights database
- [ ] Next test cycle is planned based on insights (what to test next, informed by what was learned)

## Section 6: Testing Cadence & Governance
- [ ] Creative tests run on a regular schedule (weekly or bi-weekly cycles)
- [ ] Testing budget is a fixed percentage of total spend (typically 15-25%)
- [ ] Test results log is maintained with dates, variants, metrics, and outcomes
- [ ] No scaling decisions are made based on untested creatives
- [ ] Quarterly review of testing methodology to ensure process is still yielding insights

## Approval
- **Minimum pass rate**: 21/25 items (84%)
- **Reviewer**: mandalia-scaling-strategist
- **Escalation**: If test environment controls are violated, void the test results entirely and rerun with proper isolation
