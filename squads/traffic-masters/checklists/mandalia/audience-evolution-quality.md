# Audience Evolution Matrix Quality Gate

> Quality gate for Depesh Mandalia's Audience Evolution Matrix mapping audience progression from cold stranger to loyal advocate. Must pass before the audience strategy is finalized.

## Section 1: Audience Mapping Foundation
- [ ] Complete audience universe is mapped from coldest (never heard of brand) to hottest (repeat buyer/advocate)
- [ ] Minimum 5 audience stages are defined (stranger, aware, engaged, customer, advocate)
- [ ] Each stage has specific behavioral triggers that define entry (e.g., "visited pricing page" = engaged)
- [ ] Audience sizes are estimated for each stage using platform and analytics data
- [ ] Audience flow rates between stages are estimated (what % move from aware to engaged?)

## Section 2: Stage-Specific Messaging
- [ ] Each audience stage has a tailored messaging strategy (not one message for all stages)
- [ ] Stranger-stage messaging focuses on broad education and awareness
- [ ] Aware-stage messaging introduces the brand and its unique point of view
- [ ] Engaged-stage messaging presents the offer with proof and urgency
- [ ] Customer-stage messaging focuses on retention, upsell, and community
- [ ] Advocate-stage messaging activates referrals and user-generated content

## Section 3: Audience Building Mechanics
- [ ] Custom audiences are created for each evolution stage using platform tools
- [ ] Engagement-based audiences use appropriate lookback windows per stage
- [ ] Website visitor audiences are segmented by page depth and intent signals
- [ ] CRM data is synced for customer and advocate stage identification
- [ ] Lookalike audiences are built from the highest-value stages (customers, advocates)

## Section 4: Evolution Acceleration
- [ ] Content strategy includes assets designed to move people between stages
- [ ] Lead magnets bridge the gap between aware and engaged stages
- [ ] Retargeting sequences are designed as stage-progression campaigns
- [ ] Email/SMS nurture sequences complement ad-based stage progression
- [ ] Time-based escalation exists (if someone stays in a stage too long, messaging changes)

## Section 5: Matrix Monitoring & Optimization
- [ ] Audience stage sizes are tracked weekly (are pools growing or shrinking?)
- [ ] Stage-to-stage conversion rates are monitored
- [ ] Bottlenecks are identified (stages where people stall or drop off)
- [ ] Matrix is visualized in a dashboard for team visibility
- [ ] Quarterly matrix review assesses whether stages and triggers need updating

## Approval
- **Minimum pass rate**: 19/24 items (79%)
- **Reviewer**: mandalia-scaling-strategist
- **Escalation**: If audience stages are undefined or messaging is not differentiated by stage, return to audience research and rebuild the matrix
