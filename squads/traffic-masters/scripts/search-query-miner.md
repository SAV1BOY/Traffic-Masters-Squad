# Search Query Miner — Script Guide

## Purpose
Extract insights from Google Ads search term reports to optimize campaigns.

## Mining Process

### Step 1: Export Search Terms
- Google Ads > Campaign > Keywords > Search Terms
- Date range: Last 30 days (minimum)
- Export to spreadsheet

### Step 2: Categorize Queries

| Category | Action | Example |
|----------|--------|---------|
| High Intent, Converting | Add as exact match keyword | "buy [product] online" |
| High Intent, Not Converting | Optimize landing page or bid | "[product] pricing" |
| Relevant, Low Intent | Add as phrase match, monitor | "how to [related topic]" |
| Irrelevant | Add as negative keyword | "[competitor name] jobs" |
| Brand Terms | Separate to brand campaign | "[brand name] reviews" |

### Step 3: Negative Keyword Mining
- Identify wasted spend on irrelevant queries
- Group negatives by theme (jobs, free, DIY, competitor names)
- Add to negative keyword lists (campaign or account level)

### Step 4: Keyword Expansion
- Find converting queries not in keyword list
- Add as exact or phrase match
- Create new ad groups for high-volume themes

## Analysis Metrics Per Query
| Metric | Purpose |
|--------|---------|
| Impressions | Search volume indicator |
| Clicks | Interest level |
| CTR | Relevance of ad to query |
| Conversions | Revenue potential |
| Cost/Conv | Efficiency |
| Conv Rate | Landing page/offer relevance |

## Frequency
- Weekly: Quick negative keyword sweep
- Monthly: Full search term analysis and expansion
- Quarterly: Keyword strategy overhaul

## Negative Keyword Lists to Maintain
1. Universal negatives (jobs, salary, free, DIY, Wikipedia)
2. Competitor negatives (unless running competitor campaigns)
3. Industry negatives (irrelevant subcategories)
4. Campaign-specific negatives
