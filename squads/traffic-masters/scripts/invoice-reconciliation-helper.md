# Invoice Reconciliation Helper — Script Guide

## Purpose
Reconcile ad platform invoices with budget allocations and accounting records.

## Reconciliation Process

### Step 1: Collect Invoices
- [ ] Meta: Business Settings > Payment Settings > Transaction History
- [ ] Google: Billing > Transactions
- [ ] TikTok: Payment > Transaction History
- [ ] LinkedIn: Billing Center > Transaction History

### Step 2: Match to Budget
| Platform | Invoice Amount | Budgeted Amount | Variance | Variance % |
|----------|---------------|-----------------|----------|-----------|
| Meta | | | | |
| Google | | | | |
| TikTok | | | | |
| LinkedIn | | | | |
| **Total** | | | | |

### Step 3: Identify Discrepancies
- Platform spend vs invoice (timing differences)
- Currency conversion adjustments
- Tax and fee additions
- Refunds or credits applied

### Step 4: Document
- Record all variances with explanations
- Note any credits or refunds pending
- Flag unexpected charges for investigation

## Common Discrepancies

| Issue | Cause | Resolution |
|-------|-------|-----------|
| Invoice > dashboard spend | Tax/VAT added | Account for tax in budget |
| Invoice < dashboard spend | Billing cycle timing | Wait for next invoice |
| Unexpected charges | Account fees, penalties | Investigate with platform |
| Currency variance | Exchange rate fluctuation | Document rate used |

## Monthly Reconciliation Checklist
- [ ] All platform invoices collected
- [ ] Matched to budget allocations
- [ ] Discrepancies identified and explained
- [ ] Accounting records updated
- [ ] Any credits/refunds tracked
- [ ] Tax documentation filed (BR: nota fiscal)

## For Brazil Operations
- Track IOF on international payments
- Document exchange rates (BRL/USD)
- Ensure nota fiscal issued for client billing
- Track ISS obligations on service fees
