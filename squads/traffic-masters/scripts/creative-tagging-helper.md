# Creative Tagging Helper — Script Guide

## Purpose
Systematically tag ad creatives for performance analysis and pattern recognition.

## Tag Categories

### Format Tags
- `format:video` | `format:static` | `format:carousel` | `format:ugc` | `format:animated`

### Hook Tags
- `hook:question` | `hook:bold-claim` | `hook:curiosity` | `hook:authority` | `hook:social-proof` | `hook:pattern-interrupt` | `hook:story`

### Angle Tags
- `angle:pain` | `angle:desire` | `angle:proof` | `angle:mechanism` | `angle:objection`

### Funnel Tags
- `funnel:tofu` | `funnel:mofu` | `funnel:bofu` | `funnel:retention`

### Visual Style Tags
- `style:ugc` | `style:studio` | `style:screen-capture` | `style:animated` | `style:lifestyle` | `style:product-shot`

### CTA Tags
- `cta:soft` | `cta:direct` | `cta:two-step` | `cta:urgency`

### Copy Length Tags
- `copy:short` | `copy:medium` | `copy:long`

## Tagging Process
1. Create or identify creative
2. Apply one tag from each category
3. Add tags to creative card and registry
4. Use tags for performance analysis

## Analysis Using Tags
- Filter creatives by tag to find patterns
- Compare CPA by hook type, angle, format
- Identify winning combinations (e.g., `ugc` + `curiosity` + `pain`)
- Track tag performance over time

## Example
Creative: UGC video, question hook, pain angle, TOFU
Tags: `format:ugc, hook:question, angle:pain, funnel:tofu, style:ugc, cta:soft, copy:medium`
