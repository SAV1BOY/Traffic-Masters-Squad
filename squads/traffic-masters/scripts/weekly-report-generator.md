# Weekly Report Generator — Script Guide

## Purpose
Step-by-step process for generating the weekly traffic performance report.

## Data Collection (30 min)

### Step 1: Platform Data
- [ ] Export Meta Ads Manager: Campaign-level, last 7 days
- [ ] Export Google Ads: Campaign-level, last 7 days
- [ ] Export TikTok Ads: Campaign-level, last 7 days
- [ ] Export LinkedIn Ads: Campaign-level (if running)

### Step 2: Analytics Data
- [ ] GA4 acquisition by source/medium
- [ ] GA4 conversion data by campaign
- [ ] Landing page performance (conversion rate, bounce rate)

### Step 3: Comparison Data
- [ ] Prior week metrics for WoW comparison
- [ ] Monthly targets for pacing comparison
- [ ] Benchmark data for context

## Report Assembly (30 min)

### Section 1: Executive Summary
- 2-3 sentences: Overall performance headline
- Use report-insight-phrases.md for language

### Section 2: Key Metrics Table
| Metric | This Week | Last Week | WoW | Target | Status |
|--------|-----------|-----------|-----|--------|--------|
| Spend | | | | | |
| ROAS | | | | | |
| CPA | | | | | |
| Conversions | | | | | |

### Section 3: Wins (Top 2-3)
- What worked, why, with supporting data

### Section 4: Challenges (Top 2-3)
- What underperformed, cause, and action taken

### Section 5: Experiments
- Active tests and preliminary results

### Section 6: Next Week Plan
- Priority actions for the coming week

## Distribution
- Send via email (see email-traffic-comms.md)
- Post summary in Slack (see slack-traffic-comms.md)
- Archive in reports folder
