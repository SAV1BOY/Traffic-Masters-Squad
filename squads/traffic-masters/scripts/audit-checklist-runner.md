# Audit Checklist Runner — Script Guide

## Purpose
Comprehensive ad account audit checklist for periodic health reviews.

## Account Structure Audit
- [ ] Campaign structure follows recommended pattern
- [ ] No more than 10 active campaigns (unless justified)
- [ ] Clear separation by objective and funnel stage
- [ ] Naming conventions followed consistently
- [ ] No duplicate or redundant campaigns

## Audience Audit
- [ ] Audience overlap analysis completed (<30% overlap)
- [ ] Exclusion lists properly configured
- [ ] Retargeting windows appropriate for business cycle
- [ ] Lookalike audiences refreshed (last 90 days)
- [ ] Customer lists updated in last 30 days

## Creative Audit
- [ ] Minimum 3 active creatives per ad set
- [ ] No creatives with frequency > 4.0 (7-day)
- [ ] Creative last launched within 14 days
- [ ] Mix of formats (video, static, carousel)
- [ ] Mix of angles and hooks being tested

## Tracking Audit
- [ ] All pixels firing correctly
- [ ] Server-side tracking active
- [ ] Event match quality > 6.0 (Meta)
- [ ] UTM parameters consistent and working
- [ ] GA4 data matches platform data (within 15%)

## Budget & Bidding Audit
- [ ] Budget pacing within 90-110%
- [ ] No campaigns stuck in learning phase > 14 days
- [ ] Bid strategies appropriate for objectives
- [ ] 70-20-10 allocation maintained
- [ ] Guardrails set and monitored

## Compliance Audit
- [ ] No active policy violations
- [ ] Ad copy reviewed for policy safety
- [ ] Landing pages compliant
- [ ] Privacy and consent mechanisms working
- [ ] Special ad categories properly declared

## Scoring
- Total items: 25
- Score = (items passed / 25) x 100
- 90%+ = Healthy | 75-89% = Needs Attention | <75% = Urgent Action
