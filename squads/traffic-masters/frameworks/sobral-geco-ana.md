# GECO-ANA Daily Loop Framework
> **Author**: Pedro Sobral / Daily Traffic Management
> **Domain**: Paid Traffic, Daily Operations, Campaign Management
> **Used by agents**: media-buyer-agent, optimization-agent, daily-ops-agent

## Overview
A daily operational loop for traffic managers. GECO (Geracao + Coleta) handles creation
and data collection. ANA (Analise + Otimizacao) handles analysis and optimization. Run
EVERY day without exception. Consistency in daily operations wins over sporadic brilliance.
The framework turns traffic management into a disciplined daily practice.

## When to Use
- Every single day that campaigns are running
- As the daily operating procedure for traffic managers
- Training new traffic managers on daily workflow
- When campaign performance is inconsistent due to irregular management

## The Framework
### GECO — Morning Block
#### GE — Geracao (Generation)
- Create new ad variations, copy, and creative assets
- Launch new tests (audiences, placements, hooks)
- Build new campaigns or ad sets as needed
- Goal: Always have fresh creative and tests in the pipeline
- Time: Dedicate 30-60 minutes to generation activities

#### CO — Coleta (Collection)
- Gather data from all active campaigns and platforms
- Pull reports: spend, impressions, clicks, conversions, ROAS
- Check for anomalies: sudden drops, spikes, errors
- Document everything in a tracking spreadsheet or dashboard
- Time: 15-30 minutes of structured data collection

### ANA — Afternoon Block
#### AN — Analise (Analysis)
- Review the data collected in the CO phase
- Compare current performance to benchmarks and targets
- Identify winners and losers across campaigns, ad sets, and ads
- Look for patterns: time-of-day, audience, placement trends
- Time: 20-40 minutes of focused analysis

#### A — Otimizacao (Optimization)
- Take action based on analysis: scale winners, pause losers
- Adjust budgets, bids, audiences, and creative based on data
- Apply learnings from analysis to future GECO activities
- Document decisions and rationale for each change
- Time: 20-40 minutes of deliberate optimization

## Key Concepts
- GECO-ANA runs EVERY day — no exceptions, no weekends off
- Morning creates and collects; afternoon analyzes and optimizes
- The loop compounds: daily small improvements create massive results over time
- Documentation is critical — decisions without records cannot be learned from
- Consistency beats talent: "medio com consistencia vence talento sem disciplina"

## Decision Rules
- IF a day is missed → do double collection (CO) the next day to catch anomalies
- IF analysis reveals a clear winner → scale it in the optimization phase
- IF analysis reveals a clear loser → pause it immediately
- IF no clear signal → continue collecting data, do not make premature changes
- IF all campaigns are stable → use GECO time for testing new ideas

## Common Mistakes
- Skipping days and letting campaigns run unsupervised
- Doing only analysis without generation (pipeline dries up)
- Doing only generation without analysis (waste multiplies)
- Making optimization decisions without sufficient analysis
- Not documenting changes — impossible to learn from past decisions
