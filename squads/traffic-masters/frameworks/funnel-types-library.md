# Funnel Types Library
> **Author**: Universal / Funnel Architecture
> **Domain**: Funnel Strategy, Conversion Architecture, Campaign Planning
> **Used by agents**: funnel-architect-agent, strategist-agent, campaign-planner-agent

## Overview
A reference library of proven funnel types, each with its stages, conversion expectations,
and best-fit use cases. Not every business needs the same funnel. Choosing the right
funnel type for the offer, audience, and price point is a strategic decision that
determines campaign structure, creative needs, and budget requirements.

## When to Use
- Selecting a funnel type for a new product or offer launch
- Comparing funnel architectures during strategy sessions
- Diagnosing underperformance — is it the funnel type or the execution?
- When a client asks "what kind of funnel should we build?"

## The Framework
### 1. Lead Gen Funnel
- Stages: Ad → Landing Page → Lead Magnet → Thank You → Email Nurture
- CVR: LP 20-40%, Lead-to-sale 2-10%
- Best for: Service businesses, B2B, consultants, coaches

### 2. Webinar Funnel
- Stages: Ad → Registration Page → Webinar → Offer Page → Checkout
- CVR: Reg page 20-35%, Show-up 25-40%, Offer 5-15%
- Best for: Courses, coaching, high-ticket services ($500-$5000)

### 3. Tripwire Funnel
- Stages: Ad → Low-ticket Offer ($7-$47) → Upsell → Core Offer
- CVR: Tripwire 3-8%, Upsell 10-25%
- Best for: Self-liquidating acquisition, building buyer lists

### 4. High-Ticket Funnel
- Stages: Ad → Application Page → Call Booking → Sales Call → Enrollment
- CVR: Application 5-15%, Call booking 30-50%, Close 15-30%
- Best for: Programs, consulting, services ($3000+)

### 5. E-commerce Funnel
- Stages: Ad → Product Page → Cart → Checkout → Post-Purchase Upsell
- CVR: Product page 2-5%, Cart-to-checkout 50-70%
- Best for: Physical products, D2C brands

### 6. App Install Funnel
- Stages: Ad → App Store Page → Install → Onboarding → In-App Action
- CVR: Install 5-15%, Onboarding completion 30-60%
- Best for: Mobile apps, SaaS with mobile-first experience

### 7. Challenge Funnel
- Stages: Ad → Challenge Registration → 5-7 Day Challenge → Offer
- CVR: Registration 15-30%, Completion 20-40%, Offer 5-15%
- Best for: Community-driven offers, courses, memberships

### 8. Book Funnel
- Stages: Ad → Free+Shipping Book Offer → Upsell → Core Offer Nurture
- CVR: Book offer 8-15%, Upsell 15-30%
- Best for: Authority building, audience acquisition, thought leadership

### 9. VSL Funnel
- Stages: Ad → Video Sales Letter Page → Order Form → Checkout
- CVR: VSL view 20-50%, Order form 3-8%
- Best for: Direct response, supplements, info products ($47-$297)

## Key Concepts
- Funnel type must match price point, audience sophistication, and offer type
- Higher price points require more trust-building stages
- Simpler funnels have fewer leak points but may convert less
- Every funnel needs a traffic source matched to its entry point
- Conversion rate expectations are ranges — actual results depend on execution
- Most businesses need 1-2 funnel types, not all nine

## Decision Rules
- IF price < $50 → Tripwire, E-commerce, or VSL funnel
- IF price $50-$500 → Lead Gen, Webinar, or VSL funnel
- IF price $500-$5000 → Webinar or Challenge funnel
- IF price > $5000 → High-Ticket funnel
- IF building audience → Book or Challenge funnel
- IF e-commerce → E-commerce funnel (always)

## Common Mistakes
- Using a lead gen funnel for a $7 product (overkill)
- Using an e-commerce funnel for a $5000 service (insufficient trust)
- Building multiple funnel types before mastering one
- Blaming the funnel type when the problem is execution or traffic quality
- Not matching ad creative to the funnel entry point experience
