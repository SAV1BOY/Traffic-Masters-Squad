# Creative Testing Framework
> **Type**: Creative Optimization Framework
> **Used by agents**: Ad Midas, Creative Analyst, Media Buyer

## Overview
A four-level creative testing hierarchy that moves from big conceptual tests to granular element tests. Level 1 tests the concept, Level 2 tests the format, Level 3 tests the hook, Level 4 tests individual elements. Always test big before small. Budget follows the 70/20/10 rule.

## When to Use
- Planning creative testing roadmaps for campaigns
- When creative fatigue is causing performance decline
- Structuring creative production to feed a testing pipeline
- When unsure which creative variable to test next

## The Framework

### Level 1: Concept Testing (Biggest Impact)
- Test completely different angles, messages, or value propositions
- Example: "Save money" vs "Save time" vs "Reduce stress"
- Budget allocation: 10% of total (experimental)
- Goal: Find the winning concept before optimizing details
- Test 3-5 concepts, each as a distinct ad with different messaging

### Level 2: Format Testing
- Test different ad formats within the winning concept
- Example: Static image vs video vs carousel vs UGC vs animation
- Budget allocation: 20% of total (promising)
- Goal: Find the format that best delivers the winning concept

### Level 3: Hook Testing
- Test different opening hooks within the winning concept + format
- Example: Question hook vs statistic hook vs story hook vs bold claim
- Budget: Allocated from the 20% promising budget
- Goal: Maximize thumb-stop rate and initial engagement
- Test 4-6 hooks, keeping everything else identical

### Level 4: Element Testing (Smallest Impact)
- Test individual elements: CTA button, colors, thumbnail, headline, body copy
- Budget: Allocated from the 70% proven budget (small variations)
- Goal: Incrementally improve the proven creative
- Test 2-3 variations of one element at a time

### Budget Allocation: 70/20/10
- **70%**: Proven creative — current best performers
- **20%**: Promising variations — iterations on winners (Level 2-3 tests)
- **10%**: Experimental concepts — new Level 1 concepts

## Key Concepts
- Always test top-down: Concept then Format then Hook then Elements
- The biggest performance gains come from Level 1 and Level 2 tests
- Level 4 tests provide incremental improvements, not breakthroughs
- Creative fatigue is inevitable — the testing pipeline must always be active
- One winning concept can generate dozens of format, hook, and element variations

## Decision Rules
- IF starting fresh — begin at Level 1 concept testing
- IF concept is proven — move to Level 2 format testing
- IF format is proven — move to Level 3 hook testing
- IF all levels are optimized — return to Level 1 with new concepts
- IF creative fatigue hits — test new Level 3 hooks first (fastest to produce)
- IF performance drops >20% — check if fatigue or external factors

## Integration
- Feeds into: Experimentation OS (testing methodology)
- Pairs with: Creative Iteration Loop (iterating on test winners)
- Source data: ICP and Avatar documents (creative concepts rooted in audience insights)

## Output
- Four-level creative testing roadmap with priorities
- Budget allocation across proven, promising, and experimental creative
- Test briefs for each level with hypothesis and success criteria
- Creative performance database tracking results by level
