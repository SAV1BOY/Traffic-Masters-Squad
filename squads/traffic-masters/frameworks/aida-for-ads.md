# AIDA for Ads Framework
> **Author**: Universal / Advertising Copywriting
> **Domain**: Ad Creative, Copywriting, Persuasion Structure
> **Used by agents**: copywriter-agent, creative-strategist-agent, video-script-agent

## Overview
The classic AIDA model (Attention, Interest, Desire, Action) adapted specifically for
advertising creative. Maps each AIDA phase to specific ad elements across formats
(static, video, carousel, text). The most foundational persuasion framework — every
ad, regardless of format, should move through these four phases.

## When to Use
- Writing any ad copy (social, search, display, video)
- Reviewing ads that are underperforming to diagnose which phase is broken
- Training copywriters on fundamental ad structure
- Quick-reference framework when more complex frameworks feel like overkill

## The Framework
### A — Attention (The Hook)
- Job: Stop the scroll, interrupt the pattern, earn the first second
- Static ads: Bold visual, contrasting colors, provocative headline
- Video ads: First 3-5 seconds — callout, question, bold claim, motion
- Search ads: Headline that matches search intent exactly
- Carousel: First card must hook — no logos or brand names
- Test: Would YOU stop scrolling for this? Be honest.

### I — Interest (The Relevance)
- Job: Make the viewer think "this is for me" and keep consuming
- Demonstrate understanding of their specific situation or problem
- Connect the hook to something personally relevant
- Use their language: words, phrases, and framing they would use
- Bridge from the hook to the deeper message
- Test: Does the viewer see themselves in this ad?

### D — Desire (The Benefits + Proof)
- Job: Make the viewer want what you are offering
- Paint the transformation: current state → desired state
- Stack benefits (outcomes they want, not features you have)
- Add proof: testimonials, data, demonstrations, before/after
- Handle the top 1-2 objections preemptively
- Test: Does the viewer believe this result is possible for them?

### A — Action (The CTA)
- Job: Tell the viewer exactly what to do next
- Be specific: "Click to download the free guide" > "Learn More"
- Create a reason to act now (urgency, scarcity, momentum)
- Reduce friction: make the next step feel easy and low-risk
- Match the CTA to the traffic temperature (cold=soft, hot=direct)
- Test: Is it crystal clear what happens when they click?

## Key Concepts
- Every ad is a sequence of micro-decisions: stop → read → want → act
- If any phase fails, the phases after it never fire
- Most ad failures are Attention failures (the ad was never seen)
- The second most common failure is Desire (seen but not wanted)
- AIDA applies to every format — the execution differs, the structure does not
- Advanced frameworks (ADUCATE, 3 Acts, PAS) are variations of AIDA

## Decision Rules
- IF CTR is low → the Attention phase is failing (fix the hook)
- IF CTR is good but CVR is low → Interest or Desire is failing
- IF engagement is good but no clicks → Action/CTA is weak or missing
- IF everything looks good but no sales → the landing page is the problem
- IF ad is for cold traffic → extend Interest phase, soften Action
- IF ad is for hot traffic → compress Interest, strengthen Desire and Action

## Common Mistakes
- No clear hook — the ad looks like every other ad in the feed
- Interest phase talks about the brand instead of the viewer's problem
- Desire phase lists features instead of painting transformation
- CTA is vague, buried, or missing entirely
- Treating AIDA as sequential text blocks instead of a flowing experience
- Same AIDA execution for cold and hot audiences (temperature mismatch)

## Integration
- Feeds into: Breeze ADUCATE (expanded AIDA for video ads)
- Pairs with: Breeze 3 Acts (narrative version of AIDA)
- Complements: Kusmich Feel-Felt-Found (emotional AIDA execution)
- Foundation for: All copywriting and creative frameworks

## Output
- An ad copy or script structured through all four AIDA phases
- Diagnostic checklist to identify which AIDA phase is underperforming
- Phase-specific improvement recommendations based on performance data
- AIDA-mapped creative brief for production teams
