# Creative Iteration Loop
> **Type**: Creative Optimization Framework
> **Used by agents**: Ad Midas, Creative Analyst, Breeze

## Overview
A continuous loop for improving ad creative performance: Create, Test, Analyze, Learn, Iterate on winners. Rather than starting from scratch when creative fatigues, this framework extracts learnings from performance data and applies them systematically to produce better-performing iterations. Track learnings as institutional knowledge.

## When to Use
- After initial creative tests produce winners and losers
- When creative fatigue causes performance decline
- As a continuous process during active campaign management
- When building a creative testing pipeline for scale

## The Framework

### The Loop: 5 Steps

#### Step 1: Create
- Produce creative based on hypothesis, avatar insights, or angle matrix
- Brief must specify: angle, hook, format, target audience, CTA
- Ensure creative follows the Creative Testing Framework levels

#### Step 2: Test
- Launch creative in structured test (Experimentation OS methodology)
- Isolate one variable per test when possible
- Run for minimum 7 days or until statistical significance
- Use proper budget allocation (70/20/10 rule)

#### Step 3: Analyze
- Review performance data: CTR, CPC, CVR, CPA, ROAS, hook rate (3-second view)
- Compare against control and historical benchmarks
- Identify which specific element drove the difference
- Segment analysis: which audiences responded best

#### Step 4: Learn
- Document the insight, not just the result
- Example: "Statistic hooks outperform question hooks by 23% CTR for cold audiences"
- Add to the learning log and creative intelligence database
- Share learnings with the team for cross-pollination

#### Step 5: Iterate on Winners
- Take winning creative and iterate at the next level down
- Apply learnings to create new variations

### Iteration Levels
1. **Hook Iteration**: Keep winning body/format, test new hooks (fastest to produce)
2. **Angle Iteration**: Keep winning format, test new messaging angles
3. **Format Iteration**: Keep winning message, test new creative formats
4. **CTA Iteration**: Keep everything, test different calls to action

### Creative Lifespan Management
- Monitor frequency and performance trend weekly
- Creative fatigue typically sets in at 2.5+ frequency
- Begin iterating on winners BEFORE fatigue — proactive, not reactive
- Maintain a pipeline of 3-5 ready-to-launch iterations at all times

## Key Concepts
- Iteration is not random — it is informed by data and documented learnings
- Winners contain clues about what works; losers contain clues about what does not
- The learning log is the most valuable asset over time
- Speed of iteration determines speed of improvement
- Never abandon a winning angle — exhaust all iteration levels first

## Decision Rules
1. Every test produces a learning log entry, regardless of outcome
2. Winners get iterated at the next level down before being replaced
3. Begin iteration when creative approaches 2.5 frequency
4. Maintain minimum 3 iterations in pipeline at all times
5. Review learning log before creating any new creative brief

## Integration
- Feeds into: Creative Testing Framework (Level 3-4 tests)
- Pairs with: Experimentation OS (testing methodology)
- Source data: Performance dashboards, platform creative reports

## Output
- Updated creative with iterated elements
- Learning log entry with insight and supporting data
- Creative pipeline status (in production, ready, testing, retired)
- Monthly creative performance trend report
- Quarterly learning log review and pattern identification
