# Creative Velocity System
> **Type**: Production Framework
> **Used by agents**: Creative Strategist, Media Buyer, Traffic Chief

## Overview
Sistema para produzir, testar e iterar criativos publicitarios em alta velocidade. Em plataformas com AI-driven delivery (Advantage+, PMax), creative e o lever mais impactante de performance. Este framework transforma creative production de bottleneck em vantagem competitiva.

## When to Use
- Accounts com creative fatigue recorrente (CTR declining, CPM rising)
- Scaling de spend que exige volume de creative proporcional
- Quando a equipe produz menos de 5 novos criativos por semana
- Qualquer account usando Advantage+ ou Performance Max

## The Framework

### O Principio Core
> Volume de creative de qualidade > Perfeicao de poucos criativos.
> O algoritmo precisa de opcoes. Sua velocidade de producao define seu teto de performance.

### Creative Velocity Benchmarks
| Account Spend/Mes | Criativos Novos/Semana | Formatos Minimos |
|-------------------|------------------------|------------------|
| < R$30k | 3-5 | 2 (static + video) |
| R$30k-R$100k | 5-10 | 3 (static + video + carousel) |
| R$100k-R$500k | 10-20 | 4+ (todos os formatos) |
| R$500k+ | 20-50 | Todos os formatos, todas as plataformas |

### Layer 1: Creative Strategy (O Que Produzir)

#### Concept Matrix
- **Eixo X:** Angles (dor, beneficio, social proof, urgency, story, contrarian)
- **Eixo Y:** Formatos (static, video curto, video longo, carousel, UGC)
- **Cada celula** = um conceito unico para produzir
- Priorizar celulas nao testadas no ultimo mes

#### Hook Rotation
- Cada conceito deve ter 3-5 variantes de hook
- Hook e o elemento com maior impacto no thumb-stop rate
- Testar hooks independentemente do body/CTA

### Layer 2: Production Pipeline

#### Sprint Semanal de Creative
```
Segunda: Review de performance -> Brief de novos conceitos
Terca-Quarta: Producao (design, video editing, copy)
Quinta: Review e QA
Sexta: Upload e lancamento dos novos criativos
```

#### Modular Creative System
- Produzir MODULOS, nao pecas inteiras
- Modulos: hooks (5), bodies (3), CTAs (3), backgrounds (3)
- Combinar modulos = 5 x 3 x 3 x 3 = 135 variantes de UM conceito
- AI tools (Advantage+ Creative) fazem combinacoes automaticamente

### Layer 3: Testing Protocol

#### Creative Testing Framework
1. **Test Budget:** 10-15% do budget total reservado para testes
2. **Sample Size:** Minimo R$150-300 por creative antes de decidir
3. **Decision Metrics:** Hook rate (3s views / impressions), CTR, CPA
4. **Kill Criteria:** Se hook rate < 20% ou CTR < 0.8% apos budget minimo -> pause
5. **Scale Criteria:** Se CPA < target por 3+ dias -> mover para scaling campaign

#### Hierarchy de Testes
1. Testar CONCEITOS primeiro (mensagem macro)
2. Depois testar HOOKS dentro do conceito vencedor
3. Depois testar FORMATOS do hook vencedor
4. Depois testar CTAs e body variations

### Layer 4: Iteration e Learning

#### Post-Test Analysis
- Categorizar winners e losers por angle, formato, hook type
- Identificar patterns: "UGC video com hook de pergunta converte 2x melhor que static"
- Alimentar proxima sprint com learnings — iteracao > inovacao

#### Creative Fatigue Monitoring
| Sinal de Fatigue | Threshold | Acao |
|-----------------|-----------|------|
| CTR cai 20%+ em 7 dias | Alert | Introduzir novo hook |
| CPM sobe 15%+ sem change em auction | Alert | Refresh visual |
| Frequency > 3.0 | Critico | Pausar e substituir creative |
