# MAP: Master Ad Plan Framework
> **Author**: Tom Breeze / Campaign Strategy
> **Domain**: YouTube Ads, Campaign Planning, Strategic Sessions
> **Used by agents**: strategist-agent, campaign-planner-agent, media-buyer-agent

## Overview
MAP stands for Message + Audience + Plan. It is a strategic planning session conducted
before launching any YouTube ad campaign. The output is a complete campaign blueprint
that aligns messaging to audience segments with a clear execution plan. Prevents the
common mistake of jumping straight into ad creation without strategic foundation.

## When to Use
- Before launching any new YouTube ads campaign
- When entering a new market or targeting a new audience segment
- When existing campaigns have plateaued and need strategic reset
- During quarterly planning to realign campaign strategy

## The Framework
### M — Message
- What is the core promise or transformation?
- What is the unique mechanism that delivers the result?
- What proof exists to support the claim?
- What is the one thing the viewer must remember?
- Message hierarchy: Primary message → Supporting messages → Proof points
- Test: Can you state the message in one clear sentence?

### A — Audience
- Who is the ideal viewer for this ad?
- What are they searching for, watching, or interested in on YouTube?
- What stage of awareness are they in (unaware → most aware)?
- Audience layers: Demographics → Psychographics → Behaviors → Intent signals
- Targeting options: Custom intent, affinity, in-market, placements, topics
- Test: Would this person stop scrolling and watch?

### P — Plan
- Campaign structure: how many campaigns, ad groups, and creatives?
- Budget allocation across testing and scaling phases
- Timeline: Week 1-2 testing, Week 3-4 optimization, Month 2+ scaling
- KPIs and success metrics per phase
- Creative testing roadmap: which variables to test first
- Contingency: what to do if Phase 1 does not hit targets

## Key Concepts
- MAP is done before any creative work begins — strategy before execution
- Message and Audience must align — a great message to the wrong audience fails
- The Plan phase prevents reactive decision-making during the campaign
- MAP should be revisited monthly during active campaigns
- One MAP session typically produces 4-8 weeks of campaign direction
- The output is a living document, not a one-time deliverable

## Decision Rules
- IF Message is unclear → do not proceed to Audience or Plan
- IF Audience targeting is too broad → narrow using intent signals
- IF Plan has no contingency → add fallback strategies before launch
- IF MAP reveals weak offer → address offer before advertising it
- IF multiple audience segments → create separate MAP for each segment

## Common Mistakes
- Skipping MAP and jumping straight into ad production
- Defining the Message without referencing the Audience's language
- Over-complicating the Plan with too many simultaneous tests
- Not documenting the MAP — losing strategic context during execution
- Treating MAP as a one-time exercise instead of a living strategy
