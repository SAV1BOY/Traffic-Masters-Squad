# Kaizen Kreative - Iterative Creative Testing Process

> **Author**: Ralph Burns
> **Domain**: Creative Testing & Optimization
> **Used by agents**: creative-strategist, media-buyer, ad-copywriter
> **Checklists**: kaizen-kreative-cycle-checklist, creative-testing-log

## Overview

Kaizen Kreative is Ralph Burns' iterative creative testing process, inspired by the Japanese manufacturing philosophy of continuous improvement (Kaizen). The core insight: most ads fail. That is not a problem -- it is the expected outcome. The system is designed to test many concepts, identify the rare winners (unicorns), and multiply them through iteration. You do not need every ad to work. You need a system that reliably finds the 1-3% that outperform everything else.

## When to Use

- Running ongoing creative testing for active campaigns
- Creative performance is declining due to ad fatigue
- Launching a new offer and need to find winning creative fast
- Scaling spend and need a pipeline of fresh high-performers
- Transitioning from ad-hoc creative production to a systematic process

## The Framework

### Phase 1: Creative Lab (Days 1-14)

Deep research before creating a single ad. This phase is separate and detailed in burns-creative-lab.md.

**Activities**:
- Customer research (interviews, reviews, forums, support tickets)
- Competitor creative analysis (Meta Ad Library, spy tools)
- Market narrative research (what conversations are happening now)
- Angle mining (pain, desire, objection, proof angles)
- Hook ideation based on research findings

**Output**: A creative brief loaded with real customer language, proven angles, and prioritized hook concepts.

### Phase 2: Sandbox Testing (Days 15-21)

Small budget, many concepts. The sandbox is where you test raw ideas without risking significant spend.

**Rules**:
- Test 5-15 new ad concepts per week
- Allocate $20-50 per concept per day (minimum for statistical signal)
- Run each concept for 3-5 days before evaluation
- Test against your control (current best performer)
- Meaningful variation only -- each concept must test a different hook, angle, or format

**Structure**:
- Dedicated testing campaign separate from scaling campaigns
- Broad audience targeting (let the algorithm find the right people)
- Optimize for the primary conversion event (not link clicks or impressions)
- Standard naming convention: [Date]-[Concept]-[Hook Type]-[Format]

### Phase 3: Identify Patterns (Days 22-28)

After each sandbox cycle, analyze results to find patterns, not just winners.

**Questions to answer**:
- Which hook types performed best? (Average Day, Emotion, Logic)
- Which angles resonated? (pain, desire, objection, proof)
- Which formats won? (static, video, UGC, carousel)
- Which opening seconds/lines had the best hook rate?
- Did any audience segments respond differently?

**Pattern analysis template**:
- Top 3 performers: What do they have in common?
- Bottom 3 performers: What do they have in common?
- Surprising results: What contradicted your assumptions?

### Phase 4: Iterate on Winners (Days 29-42)

Do not create entirely new concepts. Take what won and make variations.

**Iteration types**:
- **Hook swap**: Same body and CTA, different opening hook
- **Format swap**: Same message, different format (turn winning copy into video)
- **Angle variation**: Same hook, explore the angle further (more specific, different proof)
- **Audience variation**: Same ad, test with different audience segments
- **Length variation**: Same concept, test short vs. long versions

**Rule**: For every winner, create 3-5 iterations before moving to new concepts. Iteration has a higher success rate than net-new creation.

### Phase 5: Scale Unicorn Ads (Ongoing)

The 1-3% of ads that dramatically outperform everything else are unicorns. These get scaled aggressively.

**Unicorn criteria**:
- CPA at least 30% below account average
- Sustained performance for 7+ days
- Works across multiple audience segments
- High hook rate AND high conversion rate (not just clicks)

**Scaling approach**:
- Move unicorns from sandbox to scaling campaigns
- Increase budget gradually (20-30% every 3-5 days)
- Expand to new audiences (lookalikes, broad, new platforms)
- Protect unicorns: do not edit them. Create duplicates for iteration.
- Monitor for fatigue: when frequency exceeds 3, prepare replacements

### Phase 6: Repeat (Continuous)

Kaizen means continuous improvement. The cycle never ends.

- Return to Phase 1 every 30-60 days for fresh research
- Run Phase 2 sandbox testing weekly
- Conduct Phase 3 pattern analysis bi-weekly
- Phase 4 iteration runs alongside sandbox testing
- Phase 5 scaling is ongoing with fatigue monitoring

## Key Concepts

- **Most ads fail -- and that is okay**: The system expects failure and is designed to find winners despite it
- **Unicorns carry the account**: 1-3% of ads typically generate 50-80% of results
- **Iterate, don't reinvent**: Variations of winners outperform brand-new concepts most of the time
- **Continuous improvement**: Creative is not a one-time project; it is an ongoing operational process
- **Separate testing from scaling**: Sandbox campaigns protect your budget while you experiment

## Decision Rules

- IF an ad has spent 2x the target CPA with no conversions THEN kill it
- IF an ad is within 20% of target CPA after 3 days THEN let it run for 2 more days
- IF a winner is identified THEN create 3-5 iterations before testing new concepts
- IF all sandbox ads fail in a cycle THEN return to Phase 1 and do more research
- IF a unicorn's CPA rises 30% above its average THEN check frequency and prepare a replacement
- IF creative refresh rate drops below 5 new concepts per week THEN the pipeline is stalling

## Common Mistakes

- Testing 1-2 ads and declaring "Facebook doesn't work" when they fail
- Never iterating on winners -- moving to entirely new concepts instead of multiplying what works
- Testing superficial variations (color, font) instead of meaningful variations (hook, angle, format)
- Mixing testing and scaling in the same campaign -- corrupts learning and wastes budget
- Not tracking patterns across cycles -- repeating mistakes instead of building on learnings
- Editing live unicorn ads -- this resets the algorithm. Always duplicate, never edit.
