# The Ad Grid - 7-Step Creative Variation System

> **Author**: Molly Pittman
> **Domain**: Ad Creative Strategy & Systematic Testing
> **Used by agents**: creative-strategist, media-buyer, ad-copywriter
> **Checklists**: ad-grid-worksheet, creative-testing-checklist

## Overview

The Ad Grid is Molly Pittman's systematic method for generating high volumes of ad variations without relying on guesswork or "inspiration." By crossing avatar segments with hook types and creative formats, you produce a structured matrix of ad concepts that can be tested methodically. This replaces the common approach of creating one or two ads and hoping they work.

## When to Use

- Launching a new campaign and need a diverse set of ad concepts
- Current ads are fatiguing and you need fresh creative at scale
- Testing a new offer and want to find the best messaging angle
- Expanding to new avatar segments within an existing campaign
- Creative performance has plateaued and you need systematic variation

## The Framework

### Step 1: Define Your Avatar Segments

Break your broader audience into 2-5 distinct segments. Each segment has different motivations, pain points, and language.

Example for an online course:
- Segment A: Career changers wanting new skills
- Segment B: Freelancers wanting to charge more
- Segment C: Employees wanting side income

### Step 2: List Hooks Per Segment

For each segment, generate hooks using three categories:

- **Average Day**: Paint a picture of their daily experience. "You wake up, check your phone, and see another client request you can't fulfill..."
- **Emotion**: Lead with a feeling. "Tired of watching others succeed while you're stuck in the same role?"
- **Logic**: Lead with data or rational argument. "73% of marketers who learned this skill doubled their income within 6 months."

Generate 3-5 hooks per category per segment.

### Step 3: Map Creative Formats

Identify which formats you will produce:
- Static image (single image with text overlay)
- Video (talking head, b-roll, animation, UGC)
- Carousel (multi-image swipe format)
- Collection (product-focused, e-commerce)

### Step 4: Cross-Reference to Generate Variations

Build the grid: Avatar Segment x Hook Type x Creative Format = Ad Variations.

Example: 3 segments x 3 hook types x 3 formats = 27 unique ad concepts.

You do not produce all 27 at once. The grid gives you the map; prioritization tells you where to start.

### Step 5: Prioritize by Temperature

- Cold traffic: Start with Emotion and Average Day hooks (these build connection)
- Warm traffic: Start with Average Day and Logic hooks (these deepen trust)
- Hot traffic: Start with Logic hooks and direct offers (these close the sale)

Prioritize the grid cells that match your current campaign temperature.

### Step 6: Produce Top-Priority Variations

Create the top 6-10 ad variations first. Write copy, design creative, record video. Each variation should be meaningfully different -- not just a word swap but a genuinely different angle or format.

### Step 7: Test in Structured Batches

Launch ads in structured test batches:
- Test 3-5 ads per ad set
- Give each ad sufficient budget to reach statistical significance
- Run for 3-7 days before making decisions
- Kill losers, iterate on winners, return to the grid for the next batch

## Key Concepts

- **Systematic variation beats random guessing**: The grid ensures you are not just testing what "feels right" but covering meaningful creative territory
- **Hooks are the variable**: The hook (first 3 seconds of video or first line of copy) is the #1 predictor of ad performance
- **Volume matters**: The more variations you test, the more likely you are to find a winner. But volume must be structured, not chaotic.
- **Meaningful difference**: Each variation must test a genuinely different angle. Changing a background color is not a meaningful variation.

## Decision Rules

- IF you have fewer than 3 avatar segments defined THEN do more customer research
- IF a hook type consistently wins across segments THEN double down on that hook type with more variations
- IF a format consistently loses THEN deprioritize it and reallocate budget
- IF no ads in a batch hit benchmarks THEN revisit the offer before creating more ads
- IF one ad dramatically outperforms THEN create 5 variations of that winner (iterate, don't reinvent)

## Common Mistakes

- Creating only 1-2 ads and scaling immediately -- you need volume to find winners
- Testing superficial variations (color changes, font swaps) instead of hook and angle changes
- Ignoring the temperature layer -- a perfect ad for cold traffic will underperform on hot audiences
- Not killing losers fast enough -- poor ads waste budget and pollute data
- Producing all grid cells at once -- start small, learn, then expand
- Forgetting to return to the grid -- after each test batch, the grid tells you what to try next
