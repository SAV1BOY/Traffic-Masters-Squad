# Creative Layer
> **Type**: Stack Layer
> **Used by agents**: Ad Midas, Creative Analyst, Breeze

## Overview
The Creative Layer is where strategy becomes tangible. This layer governs the production of all advertising assets — from concept development through final QA. Creative is the single largest lever in modern paid media: platforms have commoditized targeting and bidding, making creative quality the primary differentiator. Duration: 1-2 weeks.

## When to Use
- Following completion of Strategy Layer (standard workflow)
- Monthly creative refresh cycles
- When creative fatigue is detected (CTR decline, frequency increase)
- Scaling phases requiring increased creative volume
- New platform or format expansion

## The Framework

### Phase 1: Angle Development (Days 1-3)
- Review strategy brief and discovery documents
- Populate creative angle matrix with angle-segment combinations
- Prioritize top 10-15 concepts based on audience insight depth
- Map angles to traffic temperature levels (cold, warm, hot)
- Assign format recommendations per angle

### Phase 2: Hook Development (Days 2-4)
- Generate 3-5 hooks per prioritized angle
- Cross-reference hook library for proven patterns
- Classify hooks by type (question, statement, statistic, story open)
- Score hooks for policy risk
- Select top 2-3 hooks per concept for production

### Phase 3: Script and Copy Writing (Days 3-6)
- Video: Full scripts with hook, body, CTA. Minimum 3 hook takes per script.
- Static/Carousel: 3 primary text variations, 5 headline variations, 3 descriptions
- UGC: Creator briefs with talking points and hook requirements
- Timing targets: 15s, 30s, 60s versions where applicable

### Phase 4: Asset Production (Days 5-10)
- Video production, static design, carousel creation, UGC content
- All assets in required aspect ratios: 1:1, 4:5, 9:16, 16:9

### Phase 5: Variations and Adaptations (Days 9-12)
- Format adaptations across aspect ratios
- Hook swaps: same body with different opening hooks
- CTA variations, text overlay variations
- Platform-specific adjustments (Meta vs YouTube vs TikTok)

### Phase 6: Quality Assurance (Days 11-13)
- Policy compliance review
- Brand guideline adherence
- Technical specification verification
- Copy proofreading, mobile rendering check
- Sound-off comprehension test for video
- UTM and tracking parameter verification

### Testing Methodology
1. **Angle Test**: Which persuasion angle resonates?
2. **Hook Test**: Which opening captures attention?
3. **Format Test**: Which format delivers?
4. **Copy Test**: Which supporting text converts?
5. **CTA Test**: Which call-to-action drives action?
- Test in this order. Do not test CTA before finding a winning angle.

## Key Concepts
- Creative decay: average lifespan 2-4 weeks. Production must be continuous.
- 80/20 rule: 80% of performance comes from 20% of creative assets
- Format diversity reaches different people — maintain video + static + UGC
- Every frame earns the next frame (Breeze methodology)

## Decision Rules
1. No campaign launch without minimum 3 distinct creative concepts
2. Creative testing budget is protected — never reallocate to scaling
3. QA stage cannot be bypassed, even under time pressure
4. Winning creative scaled for max 4 weeks before mandatory fresh variation
5. Creative Analyst reviews performance data weekly, flags fatigue within 24 hours

## Integration
- Receives strategy brief from Strategy Layer
- Finished assets delivered to Media Buying Layer for campaign build
- Testing results feed Optimization Layer for performance improvement
- Angle and hook development uses creative angle matrix and hook library

## Output
- Complete creative asset package per production cycle
- Creative testing plan with hypothesis, structure, and success criteria
- QA certification for all assets before handoff
- Creative performance tracker updated weekly
- Next-cycle production brief based on current learnings
